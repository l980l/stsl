# STSL — Game Design Document

> 버전: 0.1 (기획 초안)
> 최종 수정: 2026-04-11
> 플랫폼: 모바일 (Android / iOS)
> 엔진: Godot 4.6
> 수익화: 유료 앱

---

## 1. 게임 개요

### 한 줄 설명
세계 역사 속 인물들로 팀을 구성하고, 세계 각국 신화의 존재들을 상대하며 덱을 빌드하는 로그라이크 턴제 카드게임.

### 핵심 차별점
- **덱빌딩 + 팀빌딩 하이브리드**: 팀원을 영입할수록 덱에 사용할 수 있는 카드 풀이 넓어짐
- **팀원 = 카드 소유자**: 카드를 플레이하면 해당 카드의 팀원이 직접 행동함. 팀원의 생사가 덱 전략에 직결
- **역사 vs 신화**: 아군은 세계 역사 인물(나폴레옹, 클레오파트라 등), 적은 세계 각국 신화 속 존재들. 챕터마다 다른 신화 세계관

### 참고 게임
- Slay the Spire (핵심 구조)
- Monster Train (팀 빌딩 요소)
- Balatro (콤보/시너지 설계 방향)
- Fights in Tight Spaces (팀 전투 구조)

## 2. 핵심 게임 루프

```
맵 탐험 → 룸 선택 → 전투 or 이벤트 → 카드/보상 획득 → 반복 → 챕터 보스
```

### 런(Run) 구조
- **3~4챕터** + 최종 보스
- 챕터마다 고유한 신화 세계관 (적/보스/이벤트 테마가 챕터별로 다름)
- 챕터마다 일반 전투 룸, 엘리트 룸, 이벤트 룸, 상점, 휴식 룸, 챕터 보스로 구성
- 최종 보스 처치 시 런 클리어

### 챕터별 신화 테마 (초안)
| 챕터 | 신화 | 예시 적 |
|---|---|---|
| 1 | 그리스 신화 | 메두사, 미노타우로스, 사이클롭스, 히드라 |
| 2 | 이집트 신화 | 아누비스 전령, 스핑크스, 세트의 화신, 미이라 |
| 3 | 북유럽 신화 | 드라우그르, 펜리르, 발키리, 요르문간드르 |
| 4 | 동아시아 신화 | 한국: 저승사자·처용, 일본: 오니·텐구, 중국: 나타·사대천왕 |
| 최종 | 혼합 | 각 신화권 최강 신격 |

## 3. 맵 시스템

### 맵 구조 (확장형)
Slay the Spire 방식의 분기형 맵. 층마다 여러 갈림길 존재.

### 룸 타입

| 룸 | 내용 |
|---|---|
| 일반 전투 | 기본 적과 전투 |
| 엘리트 전투 | 강한 적, 더 많은 보상 |
| 이벤트 룸 | 선택지 기반 이벤트 (동료 영입, 부활, 저주, 보상 등) |
| 상점 | 카드 구매, 카드 제거, 릴릭 구매 |
| 휴식 룸 | 팀원 HP 회복 또는 카드 강화 선택 |
| 보스 룸 | 챕터 보스 전투 |
| 비밀 룸 | 숨겨진 경로, 특수 보상 |
| 저주 경로 | 강력한 적 + 강력한 보상, 고위험 고보상 |

## 4. 팀 시스템

### 팀원 구성
- 런 시작 시 초기 팀원 1명 고정 선택
- 이벤트 룸에서 추가 팀원 영입 (랜덤 후보 중 선택)
- 최대 팀원 수: 미정 (MVP는 최대 4명)

### 팀원 상태
- **생존**: 전투 참여 가능, 해당 팀원 카드 사용 가능
- **사망(시체)**: 전투 참여 불가, 해당 팀원 카드는 덱에 남아 있지만 사용 시 효과 없음 (또는 패널티)
- **부활**: 특정 이벤트 룸에서만 부활 가능

### 팀원 데이터 구조
```
HeroResource:
  - name: String
  - historical_figure: String       # 역사 인물명
  - max_hp: int
  - card_pool: Array[CardResource]  # 해당 팀원 전용 카드 목록
  - passive_ability: EffectResource # 고유 패시브
  - portrait: Texture2D
```

## 5. 덱 시스템

### 공유 덱
- 팀원 전체의 카드가 섞인 덱 1개
- 플레이어가 직접 덱 구성 (어떤 팀원 카드를 몇 장 넣을지 결정)
- Slay the Spire와 동일한 드로우/디스카드/소진 순환

### 카드 선택 (전투 후 보상)
- 팀원당 카드 3장씩 보여주고 **전체 중 1장만** 선택
- **일반 전투**: 1장 선택
- **엘리트 전투**: 2장 선택
- **보스 전투**: 2장 선택 + 카드 강화 1회

### 카드 데이터 구조
```
CardResource:
  - card_name: String
  - owner: HeroResource         # 카드 소유 팀원
  - cost: int                   # 에너지 비용
  - card_type: Enum             # ATTACK / SKILL / POWER
  - effects: Array[EffectResource]
  - upgraded: bool
  - description: String
  - art: Texture2D
```

### 카드 강화 시스템
- 휴식 룸 또는 보스 보상에서 강화 가능
- 강화 시 수치 상승 또는 추가 효과 부여
- 카드 1장당 1회만 강화 가능

---

## 6. 전투 시스템

### 전투 흐름
```
플레이어 턴 시작 → 카드 드로우(5장) → 에너지 충전(3)
→ 카드 플레이 (해당 팀원이 행동) → 턴 종료
→ 몬스터 턴 (의도 실행) → 반복
```

### 타겟팅
- **플레이어 → 적**: 공격/디버프 카드 사용 시 타겟 지정 (단일/전체는 카드 명시)
- **몬스터 → 아군**: 몬스터별 고유 패턴
  - 약체 사냥꾼형: HP 가장 낮은 팀원 공격
  - 보복형: 직전 턴에 자신을 공격한 팀원 공격
  - 랜덤형: 무작위 팀원 공격
  - 기타 고유 패턴
- **도발(Taunt)**: 일부 카드 사용 시 모든 몬스터의 어그로를 해당 팀원에게 집중

### 몬스터 의도 표시
Slay the Spire 방식으로 다음 턴 행동을 아이콘으로 미리 공개.

## 7. 카드 설계 철학

### 캐릭터 아이덴티티 원칙
- 각 캐릭터는 **고유 메카닉(전용 자원/상태)** 1개를 보유
- 캐릭터당 **아키타입 3개** — 서로 다른 덱 방향을 지원
- **공통 키워드**를 통해 파티 간 시너지 연결

### 공통 키워드 (상태이상)
| 키워드 | 설명 |
|---|---|
| **방어도(Block)** | 해당 수치만큼 피해 흡수. 턴 종료 시 초기화 |
| **독(Poison)** | 매 턴 시작 시 스택 수만큼 피해. 1씩 감소 |
| **약화(Weak)** | 공격 피해 25% 감소 |
| **취약(Vulnerable)** | 받는 피해 50% 증가 |
| **도발(Taunt)** | 모든 몬스터 어그로를 해당 팀원에게 집중 |
| **강화(Strength)** | 공격 카드 피해량 증가 |
| **사기(Morale)** | 나폴레옹 전용. 연속 공격 시 축적, 강력한 카드 발동 조건 |
| **진형(Formation)** | 이순신 전용. 팀 배치에 따라 카드 효과 변화 |
| **매혹(Charm)** | 클레오파트라 전용. 적에게 부여 시 조건부 아군 전환 |

### MVP 캐릭터 — 3인

---

#### 나폴레옹 (Napoleon Bonaparte)
- **포지션**: 공격형 지휘관
- **고유 메카닉**: 사기(Morale) — 연속 공격 또는 적 처치 시 축적. 소모해서 강력한 효과 발동
- **아키타입**
  - ① **돌격(Blitz)**: 저비용 공격 카드를 연속으로 플레이해 사기를 빠르게 쌓고 폭발적 피해
  - ② **군단(Legion)**: 병사 토큰을 소환해 전장을 채우는 광역 전략
  - ③ **지휘(Command)**: 다른 팀원의 카드를 강화하거나 추가 발동시키는 파티 시너지 특화
- **파티 시너지**: 사기 스택이 이순신 진형 카드 발동 조건에 사용됨

---

#### 이순신 (Yi Sun-sin)
- **포지션**: 방어형 역공
- **고유 메카닉**: 진형(Formation) — 팀원 생존 수에 따라 카드 효과 변화. 팀이 많을수록 강해짐
- **아키타입**
  - ① **거북선(Turtle Ship)**: 방어도를 쌓으면서 방어도 비례 반격 피해
  - ② **학익진(Crane Wing)**: 진형 카드로 팀 전체에 방어도/버프 부여
  - ③ **필사즉생(Do or Die)**: 팀원 HP가 낮을수록 카드 효과 강화, 역경 극복형
- **파티 시너지**: 진형 버프가 나폴레옹 병사 토큰 수에 따라 증폭

---

#### 클레오파트라 (Cleopatra)
- **포지션**: 디버프/조종형
- **고유 메카닉**: 매혹(Charm) — 적에게 부여 시 해당 적이 아군 편에서 1턴 행동. 스택 소모
- **아키타입**
  - ① **독살(Venom)**: 독 스택을 빠르게 쌓아 지속 피해
  - ② **조종(Manipulation)**: 매혹으로 강적을 일시 아군 전환, 적끼리 싸우게 함
  - ③ **저주(Curse)**: 적에게 디버프를 중첩해 약화·취약 상태로 만들고 팀 전체 피해 증폭
- **파티 시너지**: 독 상태 적에게 이순신 반격 카드가 추가 피해 / 나폴레옹 사기 소모 시 매혹 스택 추가 부여

---

### 크로스 시너지 요약
| 조합 | 시너지 |
|---|---|
| 나폴레옹 + 이순신 | 사기 축적 → 진형 발동 조건 충족, 병사 토큰이 진형 버프 증폭 |
| 나폴레옹 + 클레오파트라 | 사기 소모 시 매혹 스택 부여, 연속 공격으로 독 폭발 트리거 |
| 이순신 + 클레오파트라 | 독 상태 적에게 거북선 반격 추가 피해, 취약 부여 후 방어도 반격 극대화 |
| 3인 파티 | 나폴레옹 사기 → 클레오파트라 매혹 → 이순신 반격의 연쇄 콤보 가능 |

## 8. 릴릭 시스템

- 전투 외 지속 효과를 주는 유물 아이템
- 이벤트, 상점, 보스 드롭으로 획득
- 팀 전체 또는 특정 팀원에게 효과 적용

---

## 8. 이벤트 시스템

### 주요 이벤트 종류
- **동료 영입**: 랜덤 역사 인물 후보 중 1명 선택
- **부활**: 사망한 팀원 부활 (비용 또는 선택지)
- **카드 변형**: 카드 강화/변환/저주
- **저주**: 덱에 저주 카드 추가 (패널티)
- **릴릭 발견**: 희귀 유물 획득
- **기타**: HP 회복, 골드 획득, 카드 제거 등

---

## 9. 기술 설계

### 아키텍처
- **패턴**: 상태 머신 + Resource 기반 데이터
- **게임 상태**: `MAP` → `BATTLE` → `CARD_PICK` → `EVENT` → `SHOP` → `REST`
- **Autoload**: `GameManager` (런 상태), `DeckManager` (덱/핸드), `TeamManager` (팀원 상태)
- **데이터**: `CardResource`, `HeroResource`, `EnemyResource`, `RelicResource` (.tres 파일)
- **시그널 기반 통신**: 씬 간 직접 참조 최소화

### 헤드리스 테스트
- `tests/` 폴더에 GDScript 테스트 작성
- 카드 효과, 전투 로직, 덱 순환 자동 검증

### 타겟 해상도
- 기준: 1080 x 1920 (세로 모드)
- UI 앵커 기반 다중 해상도 대응

---

## 10. MVP 범위

### 포함
- 1챕터 + 챕터 보스
- 역사 인물 3명 (각 카드 풀 10장 내외)
- 카드 40~50장
- 몬스터 5~8종 (그리스 신화 테마)
- 이벤트 5종
- 릴릭 10종
- 기본 맵 생성 및 진행

### 제외 (이후 추가)
- 비밀 룸 / 저주 경로
- 부활 이벤트
- 상점
- 카드 강화
- 챕터 2~4 및 최종 보스
- 아트 / 사운드 최종본
