# 하스스톤 2017 메타 분석 — 정수와 영웅 교체

> 작성일: 2026-05-20

## 1. 2017 타임라인

| 시점 | 릴리스 | 카드 수 | 신규 메커니즘 | 핵심 변화 |
|---|---|---|---|---|
| 2017.4.6 | 운고로를 향한 여정 (Journey to Un'Goro) | 135장 | 정수(Quest), 적응(Adapt), 원소(Elemental) | 직업별 대안 승리 조건 |

2017은 하스스톤이 "카드 한 장의 효과"를 넘어 **게임 규칙 자체를 건드리는 카드**를 본격 도입한 해다. 정수(Quest)는 대안 승리 경로를, 죽음의 기사는 영웅·영웅 능력 교체를, 전설 무기는 직업별 결정적 도구를 제공했다.

## 2. 핵심 신규 메커니즘 (2017의 정체성)

### 정수 (Quest) — 대안 승리 조건
- 1코스트 카드, 게임 시작 시 항상 손패에 등장
- 특정 조건(예: "하수인 6기 소환", "주문 6회 시전")을 달성하면 강력한 **보상 카드**로 교체
- 직업마다 1종 — 도적 "The Caverns Below"(하수인 4기 반복 소환 → Crystal Core: 모든 하수인 5/5), 마법사 "Open the Waygate"(추가 턴 획득), 전사 "Fire Plume's Heart"(도발 7회 → 영웅 능력 강화)
- *핵심*: "보드를 이기는 것"이 아닌 **"퀘스트를 완수하는 것"** 자체가 승리 경로

### 죽음의 기사 영웅 카드 (Death Knight)
- 9코스트 전설, **영웅을 통째로 교체** — 새 영웅 능력 + 방어도 + 즉발 효과
- 직업마다 1종 — 사냥꾼 Deathstalker Rexxar(영웅 능력: 짐승 2기 합성 제작), 마법사 Frost Lich Jaina(주문에 생명력 흡수), 흑마법사 Bloodreaver Gul'dan(죽은 악마 전부 부활)
- *핵심*: 카드가 "효과"가 아니라 **"게임 후반의 새 정체성"**을 부여 — 한 장으로 덱의 후반 플랜이 완전히 바뀜

### 보충 (Recruit)
- 덱에서 하수인을 뽑지 않고 **직접 전장에 소환**
- 드로우를 건너뛰어 거대 하수인을 일찍 등장 — 자원 운용의 새 축

### 적응 (Adapt)
- 10개 강화 옵션 중 3개 발견 → 1택 (Discover 의 변형, 하수인 강화 버전)

## 3. 메타 3시대 구분

### 운고로기 (2017.4~8) — Quest 와 Jade Druid
- **Quest Rogue** 악명: 5코 미만 하수인을 반복 소환 → Crystal Core 후 모든 하수인이 영구 5/5. 4턴 만에 보드를 5/5 군단으로 — 너프 대상
- **Jade Druid**: 2016 비취 + 운고로 Ultimate Infestation(10코 — 5뎀 + 5드로우 + 5/5)로 후반 무한 가치
- **Elemental 원소 종족**: "지난 턴에 원소를 냈으면" 조건부 시너지 — 턴 연속성을 자원화

### KFT기 (2017.8~12) — 죽음의 기사와 Razakus
- **Razakus Priest(하이랜더 사제)**: Raza the Chained(하이랜더 시 영웅 능력 0코) + Shadowreaper Anduin(죽음의 기사 — 카드 사용 시 영웅 능력 리셋) → **한 턴에 영웅 능력 무한 발동**으로 OTK
- 죽음의 기사 영웅 카드가 거의 모든 컨트롤 덱의 후반 핵심으로
- **생명력 흡수(Lifesteal)** 키워드 — 어그로 대항 라이프게인 보강

### K&C기 (2017.12~) — 큐브록과 전설 무기
- **Cubelock(큐브 흑마법사)**: Carnivorous Cube(하수인 1기를 먹고 죽으면 그 하수인 2기 소환) + Voidlord(공허군주, 죽으면 도발 악마 3기) → 거대 악마를 복제. Bloodreaver Gul'dan DK 로 전부 부활
- **전설 무기**: 직업마다 1종의 강력한 무기 전설
- **던전 런(Dungeon Run)**: PvE 싱글플레이어 모드 — 로그라이크식 8연전. *stsl 과 직접적으로 닮은 모드*

## 4. 5대 아키타입 + Quest 축 — 2017 진화형

```
빠름 ←────────────────────────────────→ 느림
어그로         템포          컨트롤
Aggro Druid    Tempo Rogue   Jade Druid
Pirate계열     Tempo Mage    Cubelock / Control
                       Razakus Priest (콤보 — 영웅능력 OTK)
            Quest 덱 (대안 승리 — 속도 무관)
```

### 4-1. 콤보의 진화 — Razakus Priest

2014 Miracle Rogue, 2015 Patron Warrior 를 잇는 2017의 콤보 — **영웅 능력 자체를 콤보 엔진으로**.

| 항목 | 내용 |
|---|---|
| 승리 조건 | Raza + Anduin DK 로 영웅 능력(2뎀)을 한 턴에 무한 발동 → OTK |
| 핵심 카드 | Raza the Chained(사슬에 묶인 라자), Shadowreaper Anduin(죽음의 기사), Kazakus, 하이랜더(중복 0) 구성 |
| 카드 상호작용 | **Raza(하이랜더면 영웅 능력 0코) + Shadowreaper Anduin(카드 1장 쓸 때마다 영웅 능력 사용 가능 횟수 리셋)**: 영웅 능력이 0코 + 무제한 → 카드를 던질수록 2뎀씩 무한 누적 / **하이랜더 제약**: Raza·Kazakus 둘 다 "덱 중복 0" 요구 — 2015 Reno 의 하이랜더 패러다임 계승 |
| 약점 | 콤보 부품(Raza·Anduin)이 둘 다 필요. 하나라도 제거/분실 시 OTK 불가 |

*기획 교훈*: Razakus 는 "영웅 능력"이라는 평소 부차적 자원을 콤보 축으로 끌어올렸다. **게임의 상시 시스템(영웅 능력)을 콤보 엔진으로 전환**하는 설계 — 새 카드 없이도 기존 시스템의 재해석으로 콤보를 만들 수 있다.

### 4-2. 컨트롤의 진화 — Cubelock & Jade Druid

| 덱 | 승리 전략 | 핵심 상호작용 |
|---|---|---|
| Cubelock | 거대 악마를 복제·부활해 압도적 보드 | **Carnivorous Cube(하수인 먹고 죽으면 2기 소환) + Voidlord(9/9 상당 도발 악마)**: 큐브로 공허군주를 먹음 → 큐브를 죽임 → 공허군주 2기 / **Bloodreaver Gul'dan DK**: 죽은 악마 전부 부활 — 큐브·공허군주가 죽었어도 한 번에 복귀 |
| Jade Druid | 비취 골렘 누적 + 폭발 드로우로 무한 후반 | **Ultimate Infestation(10코: 5뎀+5드로우+5/5+5방어)** — 단일 카드로 4자원 동시 / 비취 골렘이 게임이 길수록 거대 |

### 4-3. Quest 축 — 대안 승리 조건

5대 아키타입과 별개로, 2017은 **"보드 게임이 아닌 퀘스트 완수로 이기는"** 덱이 새 축이 됐다.

| Quest 덱 | 승리 경로 | 기획 분석 |
|---|---|---|
| Quest Rogue | 하수인 4기 반복 소환 → 모든 하수인 5/5 | 보드 우위가 아닌 "특정 행동 반복"이 승리 — 상대는 보드를 비워도 막을 수 없음 |
| Quest Mage | 추가 턴 확보 → 번 주문 연쇄 OTK | 퀘스트 보상이 곧 콤보 부품 |
| Quest Warrior | 도발 7회 → 영웅 능력 강화 | 퀘스트 자체가 미드레인지 플레이를 보상 |

*기획 교훈*: Quest 는 **"덱에 항상 손패에 있는 1코 카드"** — 게임 시작부터 명확한 목표를 준다. 단점: 퀘스트 완수에만 집중하면 보드를 무시하게 되어 게임이 "솔리테어(상대와 상호작용 없는 1인 플레이)"화 된다. Quest Rogue 가 너프된 이유 — 상대가 개입할 여지가 너무 적었다.

## 5. 메타 이론 — 2017의 디자인 진화

### 5-1. 대안 승리 조건의 명암
정수(Quest)는 "보드를 이겨라" 외의 승리 경로를 공식화했다. 장점: 덱 다양성·플레이 목표의 선명함. **단점: 상대와의 상호작용 감소** — 퀘스트 완수는 내 손 안에서만 일어나므로, 상대가 막을 방법이 적으면 게임이 "누가 먼저 솔리테어를 끝내나" 경쟁이 된다. *대안 승리 조건은 반드시 "상대가 개입할 창(window)"을 남겨야 한다.*

### 5-2. 정체성 교체 카드 — 죽음의 기사
죽음의 기사는 "영웅·영웅 능력"이라는 가장 근본적인 게임 요소를 카드로 교체했다. 이는 **"게임 후반에 덱의 정체성이 통째로 바뀌는"** 경험을 준다 — 전반은 컨트롤, 9코 이후는 새 영웅으로 어그로/콤보로 변신. *카드가 효과가 아니라 "단계(phase) 전환"을 제공*하는 설계.

### 5-3. 상시 시스템의 콤보화
Razakus 는 영웅 능력을, Quest Mage 는 "턴" 자체를 콤보 자원으로 썼다. **신규 콤보는 새 카드보다 "기존 상시 시스템의 재해석"에서 나온다** — 영웅 능력, 턴, 마나, 덱 같은 시스템 요소를 비틀면 새 콤보 공간이 열린다.

### 5-4. 단일 카드 다자원 (Power Creep 가속)
Ultimate Infestation(10코에 5뎀+5드로우+5/5+5방어 = 4가지)은 "한 장이 여러 장 몫"의 극단. 2014 Dr. Boom 에서 시작된 파워 크리프가 2017엔 "단일 카드 멀티 자원"으로 진화. 편리하지만 카드 디자인 공간을 잠식 — 이후 카드는 전부 이 기준과 비교당함.

## 6. 확장이 메타에 미친 영향

### 운고로 — "직업별 대안 승리 조건의 일괄 도입"
9개 직업 모두에 Quest 1종씩. **"모든 직업에 같은 종류의 새 메커니즘을 1개씩"** 주는 방식 — 직업 간 형평성을 유지하며 신규 시스템을 도입하는 깔끔한 패턴. 단 직업별 Quest 강도 편차가 커서(Rogue 강세, 다수 약세) 동일 메커니즘도 직업별 밸런싱이 별도 필요함을 보여줌.

### KFT — "직업별 정체성 전설의 일괄 도입"
죽음의 기사도 9직업 1종씩. 운고로 Quest 와 같은 "직업당 1장" 패턴. 다만 이번엔 9코 후반 카드라 메타 속도엔 영향이 적고 "후반 플랜의 다양화"에 기여.

### K&C — "PvE 던전 런 — 로그라이크의 하스스톤판"
던전 런은 8연전 PvE 로그라이크 모드 — 매 전투 후 카드/보물 보상으로 덱을 강화. **stsl 의 구조와 본질적으로 동일**. 하스스톤이 PvP 카드게임에 로그라이크 싱글플레이어를 결합한 첫 시도이자, 이후 시리즈(주술 전쟁, 용병단)로 이어진 성공 모델.

## 7. stsl 적용 시사점

### 7-1. 던전 런 = stsl 의 직접 레퍼런스
K&C 던전 런은 stsl 과 가장 닮은 모드 — **8연전 + 전투 후 카드/보물 보상 + 점증 난이도**. 던전 런의 설계 디테일(보스 다양성, 보물 등급, 패시브 시너지, 분기 선택)을 stsl 의 맵/보상/렐릭 시스템과 직접 비교 분석할 가치가 큼. (별도 심층 문서 권장)

### 7-2. 대안 승리 조건 — "개입 창" 필수
Quest 의 솔리테어화 교훈 — stsl 에 "특정 조건 달성 시 승리/강력 보상" 류 카드를 넣을 때, **상대(적)가 방해할 수 있는 여지**를 반드시 설계. 카운터 카드가 좋은 예 — 적의 차지를 끊는 "상호작용"이 핵심.

### 7-3. 정체성 교체 — 영웅 단계 전환
죽음의 기사처럼 "후반에 영웅/덱 정체성이 바뀌는" 카드를 stsl 에 검토. 로그라이크는 런이 길어질수록 빌드가 강해지므로, "런 후반부에 영웅 변신/각성" 같은 단계 전환 메커니즘과 궁합이 좋음.

### 7-4. 상시 시스템 재해석으로 콤보 만들기
Razakus 교훈 — stsl 의 상시 시스템(에너지, 턴, 병사 토큰, 카운터)을 비틀면 새 콤보 공간이 열린다. 새 카드를 추가하기 전에 "기존 시스템을 콤보 축으로 쓸 수 있나" 먼저 검토.

### 7-5. 직업별 1종 패턴 — stsl 영웅별 형평
운고로 Quest·KFT 죽음의 기사의 "직업당 1장" 패턴 — stsl 도 신규 메커니즘 도입 시 **영웅 6인 모두에게 1종씩** 주면 형평성 유지. 단 강도 편차 밸런싱은 별도 필수 (운고로 Quest 강도 편차 교훈).

### 7-6. 단일 카드 다자원 경계
Ultimate Infestation 교훈 — stsl 신규 카드가 "한 장에 4가지 효과"로 가면 이후 카드 디자인 공간이 좁아진다. 카드는 1~2개의 명확한 역할에 집중.
