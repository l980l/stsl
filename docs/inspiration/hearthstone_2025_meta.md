## 2. 핵심 신규 요소 (2025의 정체성)

### Heroes of StarCraft — 첫 IP 크로스오버
- 하스스톤 최초의 외부 IP 크로스오버 카드 세트 (49장, 역대 최대 미니셋)
- 9개 직업을 StarCraft 3진영으로 재편성:
  - **저그(Zerg)**: 죽음의 기사·악마사냥꾼·사냥꾼·흑마법사 — 물량 어그로
  - **프로토스(Protoss)**: 드루이드·마법사·사제·도적 — 고코스트 카드를 게임 중 점점 싸게
  - **테란(Terran)**: 성기사·주술사·전사
- *핵심*: 직업을 "외부 IP 의 진영"으로 재해석. 2024 여행자가 직업 경계를 흐렸다면, 크로스오버는 직업에 **완전히 새로운 정체성 레이어**를 덧씌움

### 주입 (Imbue) — 영웅 능력 누적 강화
- Imbue 카드를 처음 내면 **새 영웅 능력** 획득
- 이후 Imbue 카드를 낼 때마다 새 영웅 능력의 모든 수치를 +1 강화
- 드루이드·사냥꾼·마법사·성기사·사제·주술사 6직업
- *핵심*: 2014년부터 고정값이던 "영웅 능력"을 **게임 내내 성장하는 자원**으로 전환. 영웅 능력의 10년 만의 근본적 재해석

### 어둠의 선물 (Dark Gift) — 발견 강화
- 발견(Discover) 시 3개 하수인 선택지 각각에 **랜덤 보너스 효과** 부착
- 죽음의 기사·악마사냥꾼·도적·흑마법사·전사 5직업
- *핵심*: 2017 발견의 강화판. 발견의 "선택" 위에 "랜덤 보너스" 레이어를 추가

### 혈족 (Kindred) — 조건부 보너스
- 특정 조건 충족 시 추가 효과 발동
- *핵심*: 2021 명예 처치, 2023 합주(Finale) 를 잇는 "조건 충족 보상" 계열의 범용화

### 되감기 (Rewind) — 재시도
- 랜덤 효과 카드를 다시 플레이 — "역사를 다시 쓸" 기회
- *핵심*: 랜덤성에 "재굴림(re-roll)" 안전망을 부여 — 랜덤의 분산을 플레이어가 통제

### 전설적 (Fabled) — 패키지 전설 카드
- 전설적 키워드를 가진 전설 카드는 덱 빌딩 시 **연관 카드 2장을 덱에 자동 추가**
- 과거·미래·평행세계의 워크래프트 아이콘들
- *핵심*: 2023 E.T.C. 사이드보드가 "플레이어가 지정하는 패키지"였다면, 전설적은 "카드 자체가 정의하는 패키지"

## 4. 아키타입 진화 — 2025

```
빠름 ←──────────────────────────────────→ 느림
어그로            미드            컨트롤
Zerg 물량         Kindred 덱      Imbue 장기전
Dark Gift 어그로  Fabled 패키지   Protoss 고코스트
              되감기(Rewind) — 랜덤 통제 (전 구간 침투)
```

### 4-1. 영웅 능력의 10년 만의 재해석 — 주입

| 시기 | 영웅 능력의 위상 |
|---|---|
| 2014~2024 | **고정** — 직업마다 1개, 2마나, 값 불변. 게임의 상수 |
| 2016 | 가젯잔 — 일부 카드가 영웅 능력을 임시 교체/강화 (예외적) |
| 2025 | 주입(Imbue) — 영웅 능력 자체가 게임 내내 **성장하는 변수** |

*기획 분석*: 영웅 능력은 11년간 하스스톤의 "변하지 않는 상수"였다 — 매 게임 같은 출발점. 주입은 이 상수를 변수로 만들었다. 의미: **장수 게임은 "건드리지 않던 기둥"을 언젠가 재해석해 신선함을 얻는다.** 단, 기둥일수록 신중하게 — 주입은 전 직업이 아닌 6직업 한정으로 리스크를 분산.

### 4-2. 랜덤성의 성숙 — 되감기

하스스톤의 랜덤성 디자인은 12년에 걸쳐 진화했다:

| 연도 | 랜덤 디자인 | 플레이어 통제 |
|---|---|---|
| 2014 | Dr. Boom, 매드 봇 — 순수 랜덤 | 없음 (논쟁 유발) |
| 2017 | 발견(Discover) — 3개 중 택1 | 선택권 부여 |
| 2025 | 되감기(Rewind) — 랜덤 결과 재굴림 | 재시도권 부여 |

*기획 분석*: 2014 GvG 의 "순수 랜덤"은 거센 논쟁을 낳았다(2014 문서 참조). 발견(2017)은 랜덤에 "선택"을 더했고, 되감기(2025)는 "재시도"를 더했다. **랜덤성은 제거 대상이 아니라 "플레이어 통제 레이어를 덧붙여 성숙시키는" 대상이다.**

### 4-3. 패키지 카드의 계보 — 전설적

E.T.C. 사이드보드(2023, 플레이어 지정 패키지) → 전설적(2025, 카드 정의 패키지). "한 장을 넣으면 연관 카드가 따라온다"는 **테마적 묶음 빌딩**. 덱 빌딩의 단위를 "낱장"에서 "패키지"로 확장.

## 5. 메타 이론 — 2025의 디자인 진화

### 5-1. 불변의 기둥을 재해석하기 — 주입
영웅 능력은 11년간 손대지 않은 상수였다. 주입은 그것을 변수로 만들었다. *장수 게임의 신선함은 "새 메커니즘 추가"뿐 아니라 "오래된 상수의 재해석"에서도 나온다 — 단, 기둥일수록 범위를 좁혀 리스크를 관리.*

### 5-2. 랜덤성 = 통제 레이어를 쌓아 성숙시키는 것
순수 랜덤(2014) → 선택(2017) → 재시도(2025). 랜덤은 "흥미로운 분산"을 주지만 통제 없으면 불공정하게 느껴진다. *해법은 랜덤 제거가 아니라 통제 레이어 추가.*

### 5-3. IP 크로스오버 = 정체성 레이어 덧씌우기
StarCraft 크로스오버는 기존 직업을 지우지 않고 "진영"이라는 레이어를 덧씌웠다. *크로스오버는 원본 정체성을 보존하며 새 렌즈를 추가할 때 성공한다.*

### 5-4. 회귀 = 향수의 정밀 타격
2017 운고로 → 2025 운고로, 정확히 8년. 충분히 그리워질 만큼 멀고, 기억할 만큼 가까운 간격. *콜백은 "주기"가 핵심 — 너무 잦으면 식상, 너무 드물면 잊힌다.*

## 6. 확장이 메타에 미친 영향

### Heroes of StarCraft — "크로스오버의 안전한 실험"
크로스오버를 본편이 아닌 미니셋(49장)으로 — 실패해도 메타 충격이 제한적. *새 시도는 작은 단위로 먼저 실험.*

### 에메랄드의 꿈 — "기둥 재해석의 직업 분할"
주입(6직업) / 어둠의 선물(5직업)으로 분할 — 한 메커니즘을 전 직업에 주지 않음. *근본적 변화일수록 적용 범위를 나눠 밸런싱.*

### 운고로의 잃어버린 도시 — "회귀가 만드는 안정 메타"
검증된 운고로 메커니즘(퀘스트) 부활 — 안정적 메타. *회귀 확장은 실험적 신규 요소가 적어 메타가 차분.*

### 시간의 길 — "랜덤·패키지의 종합"
되감기(랜덤 성숙) + 전설적(패키지 빌딩) — 12년 디자인 학습의 집약. *마지막 확장은 그해 학습의 종합.*

## 7. stsl 적용 시사점

### 7-1. 영웅 능력 누적 강화 — Imbue 형 런 progression
주입은 stsl 과 직결된다. stsl 은 로그라이크 — 런 진행 중 영웅이 성장한다. **"특정 카드/행동을 반복하면 영웅 고유 능력이 누적 강화"** 되는 Imbue 형 시스템은 stsl 의 빌드 성장감과 완벽히 맞는다. 2023 발굴·2016 Jade 의 점증 보상 계보의 "영웅 능력판".

### 7-2. 랜덤성 — 통제 레이어를 반드시 동반
stsl 에 랜덤 요소(보물 추첨, 카드 발견 등)를 넣을 때 2014→2017→2025 교훈 적용: 순수 랜덤은 불만을 낳는다. **선택지 제공(발견형) 또는 재굴림(되감기형) 통제 레이어를 함께 설계.** 카운터 시스템도 일종의 "랜덤(적 의도)에 대한 통제 레이어".

### 7-3. 패키지 빌딩 — 렐릭/카드 묶음
전설적(Fabled)의 "카드 한 장이 연관 카드를 데려온다" → stsl 렐릭/카드에 응용. 특정 렐릭 획득 시 테마 카드 패키지가 덱에 추가 — 빌드 방향성을 단위로 제공.

### 7-4. 회귀 콘텐츠의 주기 — 8년 법칙의 stsl 버전
운고로 8년 회귀 교훈 — stsl 도 운영이 길어지면 초반 챕터/적/이벤트를 후속 업데이트에서 부활. 단 "주기"가 핵심 — 적절한 간격을 두고.

### 7-5. 크로스오버 — 정체성 레이어 덧씌우기
StarCraft 크로스오버 교훈 — stsl 이 향후 IP 협업/스킨을 한다면 영웅 6인의 원본 정체성을 지우지 말고 "레이어를 덧씌우는" 방식으로. 작은 단위(미니셋형)로 먼저 실험.

## 8. 시리즈 종합 — 2014~2025 카드게임 디자인 12년사

12편의 문서를 관통하는 핵심 교훈을 stsl 설계 원칙으로 압축한다.

### 8-1. 12년의 메커니즘 계보 (한눈에)

| 축 | 계보 | 핵심 교훈 |
|---|---|---|
| **점증 보상** | Jade Golem(16) → 기수(21) → 발굴(23) → 주입(25) | 반복 행동에 누적 보상 — 후반 보장 + 성취감 |
| **거대 카드 분할** | 콜로사스(22·공간) → 타이탄(23·시간) → 우주선(24·조립) | 강력함을 분할할수록 + 플레이어 관여↑ = 전략 깊이↑ |
| **직업 경계** | 가젯잔(16) → 이중직업(20) → 여행자(24) → 크로스오버(25) | 경계는 단계적으로 완화 — 정체성 훼손 측정하며 |
| **랜덤성** | 순수랜덤(14) → 발견(17) → 되감기(25) | 랜덤은 제거가 아니라 통제 레이어로 성숙시킨다 |
| **조건부 보상** | 콤보(14) → 명예처치(21) → 합주(23) → 혈족(25) | "조건 충족"은 플레이 정밀도를 보상 |
| **패키지 빌딩** | 사이드보드(23) → 전설적(25) | 덱 빌딩 단위를 낱장→묶음으로 확장 |

### 8-2. stsl 설계 원칙 6箇条 (시리즈 결론)

1. **아키타입 다양성** (2014) — 어그로/템포/미드/컨트롤/콤보 5축이 공존해야 메타가 건강하다. stsl 영웅/덱이 이 스펙트럼을 고르게 덮는지 점검.
2. **가위바위보 상성** (2014) — 모든 전략을 이기는 전략은 없어야 한다. stsl 적 패턴·영웅 구성에 의도된 상성 삼각형.
3. **분할 전개 보스** (2022~24) — 거대 위협은 "한 방"이 아니라 공간/시간/조립으로 분할 — 대응 창과 의사결정을 만든다.
4. **점증 보상** (2016~25) — 반복 행동에 누적 보상. stsl 런 progression·렐릭·영웅 능력 강화에 적용.
5. **통제된 랜덤** (2014~25) — 랜덤은 선택·재시도 레이어와 함께. 카운터 시스템이 그 예.
6. **콘텐츠 주기** (2023~25) — 대형 챕터 + 미니셋형 소규모 갱신 + 주기적 회귀로 메타가 고이지 않게.

### 8-3. 가장 중요한 한 줄

> **카드게임 디자인은 "강력한 것을 어떻게 흥미롭게 만드는가"의 12년이었다.**
> 강력한 카드를 분할하고(콜로사스), 강력한 랜덤에 통제를 더하고(발견), 강력한 보상을 반복에 묶고(발굴), 불변의 강력함(영웅 능력)을 변수로 풀었다(주입).
> stsl 도 "강력함"을 그냥 주지 말고 — 분할하고, 통제를 붙이고, 조건을 걸고, 성장시켜라.
