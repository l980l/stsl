# 클레르 옵스퀴르: Expedition 33 — 주요 빌드 및 조합 분석

> 작성일: 2026-05-20
> 목적: stsl 기획 영감 자료. 2025 GOTY 급 턴제 RPG 의 빌드 시스템(Picto/Lumina)과 캐릭터별 빌드·파티 조합을, stsl 의 영웅·렐릭·팀빌딩 설계 관점에서 분석한다.
> 범위: 본편 + 패치 1.5.0(2025.12) 기준. 빌드 수치는 패치로 변동.
> 선행 문서: `clair_obscur_bosses.md`(보스 분석), `slay_the_spire_archetypes.md`(StS 아키타입)

## 0. 왜 이 게임을 보는가

클레르 옵스퀴르: Expedition 33 은 2025년 최고 화제작 중 하나인 턴제 RPG다. stsl 에 주는 가치는 두 가지:
1. **빌드 시스템(Picto/Lumina)** — "어디서 능력을 얻고, 어떻게 공유하는가" 의 모범 설계. stsl 렐릭 시스템의 직접 참고.
2. **파티 조합** — 6인 중 3인 액티브. 한 캐릭터가 상태를 걸고 다른 캐릭터가 소비하는 **교차 캐릭터 콤보**가 엔드게임의 전부 — stsl "팀빌딩" 의 완성형 사례.

즉 이 문서는 stsl 의 `렐릭 + 영웅 + 팀빌딩` 세 축을 한 게임에서 한꺼번에 검증하는 작업이다.

## 1. 빌드 시스템의 핵심 — Picto & Lumina

이 게임 빌드의 90%는 이 시스템 하나로 설명된다. **반드시 이해할 핵심.**

### 1-1. Picto(피크토) — 장착 아이템
- 각 캐릭터는 Picto 3개 슬롯 보유
- Picto 는 ① 능력치(Vitality/Agility/Defense/Luck) ② 패시브 효과 1개 를 제공
- 슬롯이 3개뿐 → "어떤 Picto 를 끼는가" 가 능력치 빌드의 핵심 제약

### 1-2. Lumina(루미나) — 숙련으로 해방되는 능력
- Picto 를 장착하고 **전투 4회 승리** → 그 Picto 의 패시브가 **Lumina 로 "마스터"** 됨
- 마스터된 Lumina 는 **어느 캐릭터든** Lumina 포인트(공유 예산) 한도 내에서 자유 장착 가능
- *핵심 설계*: **능력치(Picto, 슬롯 3개 제약)** 와 **능력(Lumina, 마스터 후 자유)** 을 **분리**. 한 캐릭터에서 갈고닦은 능력을 파티 전체가 공유.

### 1-3. 이 설계가 천재적인 이유
- "사용해서 마스터" — 능력은 사거나 줍는 게 아니라 **써서 익힌다**. 플레이 기반 성장.
- 능력치는 슬롯 제약(3개)으로 희소성 유지, 능력은 마스터 후 풀려 자유 조합 → **제약과 자유의 분리**.
- 한 캐릭터의 성장이 파티 전체 자산이 됨 → 캐릭터 교체·실험을 장려.
- **Painted Power**: 9,999 데미지 상한을 깨는 Lumina. 엔드게임 빌드 필수 — "규칙 파괴" 한 장(StS Barricade 와 동일 원리).

## 2. 전투 시스템 토대

| 시스템 | 내용 | 빌드에 주는 영향 |
|---|---|---|
| AP(Action Point) | 스킬 비용. 기본 공격·패리로 충전 | AP 수급 Lumina(Energising 계열)가 로테이션 좌우 |
| 패리·닷지·프리에임 | 액션성 — 타이밍 방어/조준 사격 | 패리 성공 시 AP·카운터 — 반응형 빌드 가능 |
| Gradient 게이지 | 파티 공유 게이지 → Gradient Attack(파티 필살기) | 게이지 충전 속도가 "원샷 빌드" 의 엔진 |
| 능력치 | Vitality/Agility/Defense/Luck 4종 + 무기 스케일링 | 무기마다 스케일 속성이 달라 무기가 빌드 방향 결정 |
| 상태 효과 | Burn(화상)·Mark(표식)·Break(브레이크) 등 누적형 | 상태 누적 → 소비 콤보가 최강 빌드의 뼈대 |

**핵심 원리**: 능력치(raw stat)만 올리는 빌드는 약하다. 게임은 **Burn·Mark·Break 누적 + 턴 순서 설계 + Gradient 운용**을 보상한다.

## 3. 캐릭터 6인 — 고유 메커니즘과 빌드

> 로스터: Gustave / Maelle / Lune / Sciel / Verso / Monoco. 액티브 파티는 3인.
> **각 캐릭터가 서로 다른 "충전형 게이지"를 가진 게 핵심** — 정체성이 메커니즘으로 분리돼 있다.

### 3-1. Gustave — Overcharge(과충전)
- **고유 메커니즘**: 기계팔에 Overcharge 스택을 쌓아 강력한 과충전 공격으로 방출.
- **빌드**: Vitality + Agility (생존+행동 빈도). Strike Storm 으로 Overcharge 를 빠르게 축적(+2/회), Marking Shot 으로 Mark 부여.
- **역할**: 디버프·Mark 셋업 enabler. 파티의 표식을 깔아 딜러의 폭딜을 준비.

### 3-2. Maelle — Stance(자세)
- **고유 메커니즘**: 4가지 자세.
  - Stanceless(기본, 효과 없음) / Defensive(받피 −50%, 패리·닷지마다 +1AP) / Offensive(주는 피해 +50%, 받는 피해 +50%) / **Virtuose(주는 피해 +200%)**
  - 자세 진입 시 +1AP. 턴 종료 시 자세 안 바꾸면 Stanceless 로 복귀. **같은 자세 2턴 연속 불가**(연속 시도 시 Stanceless 가 됨 — 안티-디제너러시 규칙)
- **빌드**: 게임 최강 딜러. **Burn 빌드**(공격 대부분이 화염 속성), Virtuose 자세 원샷. Medalum 무기, Defense+Agility.
- **역할**: 메인 딜러. 아군이 깐 Burn·Mark 를 Virtuose 에서 한 방에 환산(보스에게 10억+ 데미지 사례).

### 3-3. Lune — Stain(스테인, 원소)
- **고유 메커니즘**: 4종 원소 Stain 을 생성/소비. 프리에임·스킬로 Stain 적립 → Mayhem 으로 소비해 폭발 원소 피해. **Elemental Genesis**(궁극기)는 서로 다른 4 Stain 필요.
- **빌드**: Choralim 무기, Agility+Defense. Burn 시너지 — 화염 Stain 으로 Maelle 의 Burn 빌드 지원.
- **역할**: 만능 — 딜 + 힐. 원소 셋업과 유틸.

### 3-4. Sciel — Foretell / Sun·Moon / Twilight(황혼)
- **고유 메커니즘**: **닫힌 루프**.
  - Sun 스킬 → 적에게 Foretell(누적 디버프, 상한 10) 적립
  - Sun 충전 1 + Moon 충전 1 보유 → **Twilight 진입**(2턴: Foretell 상한 20으로 2배, 적립률↑, 진입 시 총 충전량 기반 데미지 배율 획득)
  - Moon 스킬 → Foretell 소비해 폭딜
- **빌드**: Charnon 무기, Luck+Agility(크리티컬). 로테이션: Sun 적립 → Twilight 진입 → Moon 정산.
- **역할**: 누적형 폭딜러. Foretell·Mark 셋업으로 메인 딜러를 지원하기도.

### 3-5. Verso — Perfection(완벽도)
- **고유 메커니즘**: 등급제 게이지 D→C→B→A→**S**.
  - 공격·패리·닷지 성공 시 등급↑. 피격 시 등급 −1(적 턴당 1회).
  - 등급이 높을수록 피해↑ + 스킬의 추가 효과 해방. S 도달 시 Gradient 충전 획득.
- **빌드**: 기본 공격·프리에임 스팸. Combo Attack 1/2/3 으로 4회 타격, Charging Attack Lumina 로 Gradient 추가 충전.
- **역할**: **Gradient 엔진**. 빠르게 S 등급 → 파티 게이지 충전 → "원샷 빌드" 의 발전기.

### 3-6. Monoco — Bestial Wheel(야수의 수레바퀴)
- **고유 메커니즘**: 5개 마스크가 도는 회전 휠.
  - Heavy(실드·탱킹) / Agile(속도·추가 턴) / Balanced(순수 딜) / Caster(AP 생성·힐) / Almighty(파티 전체 버프)
  - Monoco 는 적(몬스터)의 능력을 학습해 사용 — Gestral 종족 특성.
- **빌드**: Ballaro 무기(역방향 휠 회전 → Heavy·Caster 마스크 접근 용이). Agility+Defense, Break 특화.
- **역할**: AP 배터리 + 브레이커. Caster/Almighty 마스크로 파티에 AP·버프 공급.

## 4. 핵심 빌드·조합

### 4-1. Burn(화상) 빌드 — 누적 도트 폭딜
- **원리**: 화염 스킬이 Burn 부여. Burn 은 매 턴 피해 + 스택이 많을수록 피해 가속.
- **핵심**: Maelle(화염 위주 키트) 가 중심, Lune 의 화염 Stain 이 보조.
- **콤보**: Lune·Sciel 이 Burn·Mark 를 대량 적립 → Maelle 이 Virtuose 자세로 누적분을 한 번에 정산.
- **위력**: 게임 최강 보스(Simon)에게 11억+ 데미지 커뮤니티 검증 사례.

### 4-2. Mark(표식) 빌드 — 증폭 소비
- **원리**: Mark 가 걸린 적은 받는 피해 증폭. Gustave·Sciel·Lune 이 Mark 적립.
- **콤보**: 표식을 깐 뒤 메인 딜러가 단일 폭딜로 정산. Burn 빌드와 자연 결합.

### 4-3. Gradient 원샷 빌드 ("Delete Key") — 선공 처형
- **원리**: 적이 행동하기 전에 Gradient Attack 한 방으로 처치.
- **엔진**: Verso 가 프리에임 스팸 + Combo Attack 1/2/3(4회 타격) + Charging Attack 으로 Gradient 충전을 초고속 적립, S 등급으로 추가 충전.
- **정산**: 충전된 Gradient 를 메인 딜러가 거대 Gradient Attack 으로 방출 → 1억~10억+ 데미지.
- **핵심**: "셋업 전담(Verso) + 정산 전담(딜러)" 의 분업.

### 4-4. Lumina 코어 패키지 — 거의 모든 빌드 공용
| Lumina | 효과 |
|---|---|
| Cheater | 캐릭터가 연속 2회 행동하고도 턴 이득 유지 — **최강 Lumina** |
| Painted Power | 9,999 데미지 상한 돌파 — 엔드게임 필수 |
| Augmented Attack / Combo Attack 1·2·3 | 기본 공격 강화·다단화 |
| Energising Attack / Energising Turn | 턴·공격에서 AP 추가 수급 |
| Augmented Counter | 패리·카운터 피해 증폭(중첩 가능) |
| Warming Up | 턴 시작 시 몇 라운드간 공격력↑ |

### 4-5. 리스크/리워드 Lumina — 하이리스크 빌드
- **Confident**: 받피 감소, 단 회복 불가(부활 제외)
- **Glass Cannon**: 방어력↓ ↔ 공격력↑
- **Immaculate**: 피격당하지 않으면 피해↑
- *의미*: 안정 빌드 대신 "완벽 플레이 시 보상" — 숙련 보상 레이어.

### 4-6. 파티 조합 원칙
- 표준 3인 = **셋업(Sciel/Lune/Gustave) + 메인 딜러(Maelle) + 엔진/유틸(Verso/Monoco)**
- 모든 최강 빌드는 "한 명이 상태를 깔고, 다른 명이 소비" 하는 **교차 캐릭터 콤보** — 단일 캐릭터 완결 빌드는 상위 티어에 없음.

## 5. 기획자 관점 분석

### 5-1. 능력치와 능력의 분리 (Picto / Lumina)
빌드 시스템의 정수. **능력치는 슬롯 제약(희소)**, **능력은 마스터 후 자유(공유)**. 한 시스템이 "제약" 과 "자유" 를 동시에 충족 — 빌드 다양성과 의사결정 긴장을 양립시킨다.

### 5-2. 캐릭터마다 다른 게이지 = 메커니즘으로 분리된 정체성
Overcharge / Stance / Stain / Twilight / Perfection / Bestial Wheel — 6인이 6개의 전혀 다른 "충전·소비" 메커니즘을 가진다. 정체성을 스토리·외형이 아니라 **시스템**으로 분리. (StS 4캐릭터, 하스스톤 직업과 동일 철학)

### 5-3. 교차 캐릭터 콤보 = 팀빌딩의 본질
엔드게임 빌드는 전부 "A가 깔고 B가 소비". 이건 StS 문서(§7-2)에서 stsl 시사점으로 도출한 **"영웅 간 엔진+페이오프"** 의 완성형 실물. 클레르 옵스퀴르는 그 설계로 GOTY 급 평가를 받았다.

### 5-4. 안티-디제너러시 규칙의 내장
Maelle 의 "같은 자세 2턴 연속 불가" 는 무한 루프를 원천 차단하는 규칙. **강력한 메커니즘에는 처음부터 남용 방지 규칙을 끼워 설계.** (하스스톤 문서의 "강력함은 분할·조건으로 통제" 와 같은 교훈)

### 5-5. 반응형 전투 — 패리/닷지
턴제임에도 패리·닷지·프리에임으로 액션성을 부여, 방어가 수동이 아닌 능동. 패리 성공이 AP·카운터로 환산 — 방어 자체가 자원 생산.

## 6. stsl 적용 시사점

### 6-1. 렐릭 시스템에 "마스터 후 공유" 모델 검토
클레르 옵스퀴르 Lumina 의 핵심 — **한 영웅이 써서 마스터한 능력을 팀 전체가 공유**. stsl 렐릭이 "획득 즉시 한 영웅 귀속" 이라면, "한 영웅에서 숙련 → 팀 공유 풀로 해방" 모델은 팀빌딩 깊이를 극적으로 키운다. 능력치 슬롯은 제약, 능력은 공유 — 이 분리 구조를 stsl 렐릭/카드에 적용 가능.

### 6-2. 영웅별 고유 게이지 — 메커니즘으로 정체성 분리
stsl 영웅 6인이 각자 다른 "충전형 자원"(Overcharge/Stance/Twilight 류)을 가지는가? 모두 같은 자원·같은 패턴이면 정체성이 약하다. **영웅마다 다른 게이지 메커니즘**이 StS·하스스톤·클레르 옵스퀴르가 공통으로 쓰는 정체성 설계법.

### 6-3. 교차 영웅 콤보를 엔드게임 설계 목표로
클레르 옵스퀴르 최강 빌드 = 전부 교차 캐릭터 콤보. stsl 도 후반 빌드가 "한 영웅으로 완결" 되면 팀빌딩이 장식이 된다. **"A 영웅이 상태를 깔고 B 영웅이 소비"** 를 엔드게임 빌드의 명시적 설계 목표로 삼을 것. (Burn·Mark 같은 누적→소비 상태 효과가 그 매개)

### 6-4. 누적→소비 상태 효과 축
Burn(도트)·Mark(증폭)·Foretell(누적 디버프)·Break(스태거) — 4종의 서로 다른 누적 상태가 교차 콤보의 매개. stsl 에 "한 영웅이 적립하고 다른 영웅이 소비하는" 상태 효과가 충분히 있는가? 카운터 시스템 외에 Burn·Mark 류 누적 축을 점검.

### 6-5. 안티-디제너러시 규칙 내장
Maelle "같은 자세 2턴 연속 불가" 처럼, stsl 의 강력한 카드·렐릭·영웅 능력에는 **설계 시점에 남용 방지 규칙을 함께** 넣을 것. 사후 너프보다 사전 규칙이 깔끔.

### 6-6. 규칙 파괴 한 장 (Painted Power 형)
9,999 상한을 깨는 Painted Power 처럼, stsl 에도 "기본 규칙을 깨는" 희귀 렐릭/카드 슬롯을 의식적으로 둘 것. (StS 문서 §7-5 와 동일 — 규칙 파괴 카드 = 빌드 다양성 생성기)

### 6-7. 카운터 시스템 = stsl 의 패리
클레르 옵스퀴르의 패리/닷지(능동 방어 → AP·카운터 환산)는 stsl 카운터 시스템의 사촌. stsl 카운터를 "방어가 곧 자원·반격이 되는" 능동 시스템으로 키우면 클레르 옵스퀴르 패리만큼 전투를 능동적으로 만든다.

### 6-8. 리스크/리워드 모디파이어
Glass Cannon·Confident·Immaculate 처럼 "대가를 치르는 강화" 렐릭/카드를 stsl 에. 안정 빌드와 하이리스크 빌드의 선택지가 런 다양성을 만든다. (StS 인챈트 시사점과 연결)

### 7-2. 빌드 우선순위 (stsl 백로그 후보)
1. **렐릭 "마스터 후 팀 공유" 모델** (§6-1) — 채택 가치 최상. 팀빌딩 깊이 직결
2. **교차 영웅 콤보를 엔드게임 목표화** (§6-3) — 팀빌딩 존재 이유
3. **영웅별 고유 게이지 점검** (§6-2) — 정체성 분리
4. **누적→소비 상태 효과 축** (§6-4) — Burn·Mark 류
5. **안티-디제너러시 규칙 내장** (§6-5) — 강력 카드 설계 원칙
