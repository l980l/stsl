# 하스스톤 2019 메타 분석 — 하이랜더 전성기와 게임 모드 확장

> 작성일: 2026-05-20
> 목적: stsl 기획 영감 자료. 하스스톤 2019년 — "용의 해". 하이랜더 페이오프가 정점에 달하고, 카드게임 밖으로 게임 모드를 확장한 해.
> 범위: 2019.4 어둠의 반격 ~ 2019.12 용의 강림. + 전장(Battlegrounds) 출시.

## 1. 2019 타임라인

| 시점 | 릴리스 | 카드 수 | 신규 메커니즘 | 핵심 변화 |
|---|---|---|---|---|
| 2019.4.9 | 어둠의 반격 (Rise of Shadows) | 135장 | 도제(Lackey), 음모(Scheme), 쌍둥이 주문(Twinspell) | EVIL 무리 — 카드 생성 본격화 |
| 2019.8.6 | 울둠의 구원자 (Saviors of Uldum) | 135장 | 정수(Quest) 부활, 재생(Reborn) | 하이랜더 페이오프 집결 |

2019는 "용의 해(Year of the Dragon)" — 3개 확장이 하나의 스토리(EVIL 무리 vs 탐험가 연맹)로 연결됐다. 핵심: ① **하이랜더(중복 0) 덱이 전성기**를 맞고 ② **전장(Battlegrounds)** 출시로 하스스톤이 단일 게임 모드를 벗어났다.

## 2. 핵심 신규 메커니즘 (2019의 정체성)

### 도제 (Lackey)
- 1코 1/1 토큰 하수인 — 5종(효과 다양)이 무작위 생성
- EVIL 진영 카드들이 "도제 1기 생성" 효과를 다수 보유
- *핵심*: 2015 Discover 가 "덱 밖 카드 1장"이었다면, Lackey 는 **"무작위 미니 카드를 끊임없이 생성"** — 카드 생성(generation)의 일상화

### 음모 (Scheme)
- 손에 있을수록 매 턴 강해지는 카드 (예: 적 하수인 N기 파괴 — N이 매 턴 +1)
- *핵심*: "카드를 언제 쓸지" 타이밍 자체가 자원 — 들고 있을수록 강해지지만 자리를 차지

### 재생 (Reborn)
- 하수인이 죽으면 체력 1로 1회 부활
- 죽음의 메아리의 변형 — 보드 지속력 ↑

### 침공 (Invoke) — Galakrond 강화
- "침공" 효과를 발동할 때마다 손/덱의 Galakrond 가 강해짐
- Galakrond 를 쓰기 전에 미리 강화하는 빌드업 메커니즘

### 쌍둥이 주문 (Twinspell)
- 시전하면 복사본 1장이 손에 — 같은 주문을 2번
- 카드 1장의 가치를 2배로 (단 마나는 2번)

## 3. 메타 3시대 구분

### 어둠의 반격기 (2019.4~8) — 도제와 EVIL
- **Tempo/Lackey 덱**: EVIL 카드의 도제 생성으로 끊임없는 미니 위협. Tempo Rogue 등
- **Bomb Warrior**: 상대 덱에 폭탄을 섞어 드로우 시 폭발 — 간접 번
- **Mech Hunter / Token Druid** 등 기존 아키타입 잔존

### 울둠기 (2019.8~12) — 하이랜더 전성기
- **Quest 전 직업 부활**: 2017 운고로 이후 9직업 Quest 재도입
- **하이랜더(Highlander) 덱 정점**: 울둠이 하이랜더 페이오프 카드를 집결시킴
  - **Zephrys the Great(위대한 제프리스)**: 하이랜더면 — "지금 이 순간 최적의 기본 카드 3장"을 발견. 사실상 항상 정답 카드
  - Dinotamer Brann(하이랜더 사냥꾼 → 거대 야수), Reno the Relicologist 등
  - Highlander Hunter / Highlander Mage 가 메타 최상위

### 용의 강림기 (2019.12~) — Galakrond 와 용족
- **Galakrond 영웅 카드**: 5개 직업(도적/주술사/전사/사제/흑마법사)이 공유 — 침공으로 강화 후 영웅 교체. 직업마다 효과가 다름
- **용족(Dragon) 시너지 폭발**: 용의 강림은 용족 테마 확장
- Galakrond Rogue/Shaman/Priest 가 메타 장악

## 4. 아키타입 진화 + 신규 축 — 2019

```
빠름 ←──────────────────────────────────→ 느림
어그로        템포            컨트롤
Aggro 계열    Tempo Rogue     Highlander Mage/Hunter
              Galakrond Rogue Control / Quest 덱
                       Galakrond 빌드업 (영웅 강화 축)
            하이랜더 (중복 0 — 컨트롤~미드 페이오프 축)
```

### 4-1. 하이랜더 축의 정점 — Highlander 덱

2015 Reno 에서 시작된 하이랜더(덱 중복 0)가 2019 울둠에서 **페이오프 카드 다수**를 얻어 정점에 달했다.

| 항목 | 내용 |
|---|---|
| 승리 전략 | 덱 중복 0 → Zephrys·Reno·Dinotamer Brann 등 하이랜더 페이오프로 압도적 일관성 |
| 핵심 카드 | Zephrys the Great(최적 카드 발견), Reno(체력 회복), Dinotamer Brann(거대 야수), Dragonqueen Alexstrasza(용족 2장 생성) |
| 카드 상호작용 | **하이랜더 제약 + Zephrys**: "중복 0" 제약을 충족하면 Zephrys 가 매번 "지금 필요한 정답 카드"를 제공 → 일관성 부족(중복 0의 약점)을 완벽히 보완 / 여러 하이랜더 페이오프가 한 덱에 — 제약 1개로 보상 다수 |
| 약점 | 중복 0이라 같은 답을 2번 못 씀. 단 Zephrys·Discover 로 거의 무력화 |

*기획 분석*: 하이랜더는 2015~2019에 걸쳐 **제약 1개(중복 0)에 페이오프가 매년 누적**된 사례. Reno(체력)→Kazakus(주문 제작)→Zephrys(최적 카드)로 보상이 쌓이며 "중복 0의 약점(일관성 부족)"이 거의 사라졌다. *제약형 메커니즘은 페이오프가 누적될수록 강해진다 — 장기적으로 제약이 무의미해지지 않도록 관리 필요.*

### 4-2. 영웅 강화 축 — Galakrond

Galakrond 는 2017 죽음의 기사(영웅 교체)의 발전형 — **"미리 강화한 만큼 강해지는 영웅 카드"**.

| 항목 | 내용 |
|---|---|
| 메커니즘 | 침공(Invoke) 효과를 발동할 때마다 Galakrond 가 1단계씩 성장. 강화된 Galakrond 를 내면 그만큼 강한 영웅으로 교체 |
| 직업 공유 | 5개 직업이 같은 Galakrond 를 쓰되 침공 효과·강화 결과가 직업마다 다름 |
| 카드 상호작용 | **침공 카드 다수 + Galakrond**: 게임 내내 침공을 쌓아두면 후반 Galakrond 가 폭발적 가치 / 강화는 손/덱 어디서든 적용 — 2016 C'Thun 의 "어디서든 버프" 계승 |
| 기획 분석 | 죽음의 기사(고정 효과)와 달리 Galakrond 는 "플레이어가 빌드업한 만큼" 보상 — 능동적 빌드업을 보상하는 영웅 카드 |

### 4-3. 카드 생성의 일상화 — 도제(Lackey)

2015 Discover, 2016 Kazakus 를 거쳐 2019 Lackey 는 **카드 생성을 "특별 이벤트"가 아닌 "매 턴 일어나는 일"**로 만들었다. EVIL 덱은 도제를 끊임없이 뽑아 손패가 마르지 않는다. *생성이 일상화되면 "덱에 든 카드"의 중요도가 낮아진다 — 양날의 검.*

## 5. 메타 이론 — 2019의 디자인 진화

### 5-1. 제약형 메커니즘의 장기 관리
하이랜더는 5년에 걸쳐 페이오프가 누적됐다. Zephrys 에 이르러 "중복 0"의 약점이 거의 사라졌다 — 제약이 사실상 공짜가 됐다. *제약형 메커니즘(하이랜더, 짝수/홀수)은 페이오프를 매년 추가하면 결국 "제약 없는 것보다 무조건 이득"이 된다. 페이오프 누적 속도를 관리해야 제약의 의미가 유지된다.*

### 5-2. 카드 생성 인플레이션
Discover(2015) → Kazakus(2016) → Lackey(2019)로 "덱 밖 카드 획득"이 점점 흔해졌다. 장점: 손패 마름 방지, 게임마다 다른 경험. 단점: ① "덱 구축"의 의미 희석 (어차피 생성으로 채워짐) ② 무작위성 누적. *카드 생성은 강력하고 재미있지만, 과하면 "내가 짠 덱"의 정체성을 흐린다.*

### 5-3. 빌드업형 영웅 카드
Galakrond 는 "미리 쌓은 만큼 강한" 영웅 카드 — 2017 죽음의 기사(고정)보다 능동적. 플레이어에게 "지금 침공을 쌓을까, 다른 걸 할까"라는 매 턴 의사결정을 준다. *빌드업 메커니즘은 "장기 투자 vs 단기 이득"의 긴장을 만들어 게임을 깊게 한다.*

### 5-4. 게임 모드 확장 — 전장(Battlegrounds)
2019.11 전장 출시는 하스스톤 최대 전환점 중 하나. 같은 카드 자산을 재활용해 **완전히 다른 게임 모드(오토배틀러, 8인 PvP)**를 만들었다. 카드게임의 IP·자산을 새 장르로 확장 — 라이브 서비스의 수명 연장 전략.

## 6. 확장이 메타에 미친 영향

### 어둠의 반격 — "진영 스토리텔링"
EVIL 무리(악당) vs 탐험가 연맹의 서사를 카드로 전개. 2016 가젯잔 3길드처럼 카드를 진영으로 묶되, 이번엔 **3개 확장에 걸친 연속 스토리**. 카드게임이 "메타"뿐 아니라 "서사"로도 플레이어를 묶을 수 있음을 보여줌.

### 울둠 — "옛 메커니즘의 부활"
2017 Quest 를 2년 만에 9직업 전체로 부활. *검증된 메커니즘을 주기적으로 재활용하면 신규 디자인 부담을 줄이고, 옛 플레이어에겐 향수를 준다.* 단 같은 메커니즘이라도 새 보상 카드로 차별화 필요.

### 용의 강림 — "확장 = 종족 테마의 정점"
용의 강림은 "용족(Dragon) 확장" — 검은바위 산(2015)부터 누적된 용족 시너지의 집대성. *장기 시리즈는 "오래 빌드업한 종족/테마를 정점에서 폭발시키는" 확장으로 보상감을 줄 수 있다.*

## 7. stsl 적용 시사점

### 7-1. 제약형 렐릭의 페이오프 관리
하이랜더 5년 교훈 — stsl 에 "덱 제약 → 보상" 렐릭을 넣을 때, 페이오프를 계속 추가하면 결국 제약이 공짜가 된다. **제약형 렐릭은 페이오프 총량에 상한**을 두거나, 제약 강도도 함께 키워야 한다.

### 7-2. 카드 생성 — 로그라이크 궁합 & 절제
Lackey 류 "전투 중 카드 생성"은 로그라이크와 잘 맞지만(매 전투 다른 경험), 과하면 "덱 빌딩"의 의미가 흐려진다. stsl 은 덱빌딩이 핵심이므로 생성 메커니즘은 **절제** — 보조 수단으로만.

### 7-3. 빌드업형 영웅 각성
Galakrond 의 "쌓은 만큼 강한 영웅 카드"는 stsl 영웅 시스템에 직접 응용 가능. 예: "전투 중 특정 행동을 N회 하면 영웅 각성/강화" — 능동적 빌드업이 매 턴 의사결정을 만든다.

### 7-4. 서사로 묶기
2019의 3확장 연속 스토리 교훈 — stsl 의 챕터(신화별 act)도 메커니즘뿐 아니라 **서사 연결**로 플레이어를 묶을 수 있다. stsl 은 이미 6신화 × 3act 구조 + 영웅 별명 설정이 있으니, 챕터 간 서사 연결을 강화할 여지.

### 7-5. 검증된 메커니즘 재활용
울둠 Quest 부활 교훈 — stsl 신규 챕터에서 **이전 챕터의 검증된 메커니즘을 새 옷을 입혀 재활용**하면 디자인 부담↓ + 일관성↑. 단 보상 카드는 차별화.

### 7-6. 게임 모드 확장 (장기)
전장 출시 교훈 — stsl 의 카드/영웅/적 자산을 재활용해 **다른 모드**(예: 무한 생존 모드, 보스 러시, 데일리 챌린지)를 만들면 콘텐츠 수명이 길어진다. 로드맵의 포스트런치 엔드게임(M11)과 연결.
