# 하스스톤 2022 메타 분석 — 신규 카드 타입과 멀티파트 하수인

> 작성일: 2026-05-20
> 목적: stsl 기획 영감 자료. 하스스톤 2022년 — "히드라의 해". 신규 카드 타입(장소), 멀티파트 하수인(콜로사스), 신규 직업(죽음의 기사)이 동시에 등장한 해.
> 범위: 2022.4 정복자의 항로 ~ 2022.12 리치 왕의 진군.
> 선행 문서: `hearthstone_2014~2021_meta.md`
> **stsl 직접 연관**: 콜로사스(Colossal)는 stsl 의 `multi_part` 보스 구상과 본질이 같음 — 4장 집중 분석.

## 1. 2022 타임라인

| 시점 | 릴리스 | 카드 수 | 신규 요소 | 핵심 변화 |
|---|---|---|---|---|
| 2022.4.12 | 정복자의 항로 (Voyage to the Sunken City) | 135장 | 잠수(Dredge), 콜로사스(Colossal), 나가(Naga) 종족 | 멀티파트 하수인 |
| 2022.8.2 | 나스리아 성 살인 사건 (Murder at Castle Nathria) | 135장 | **장소(Location) 신규 카드 타입**, 주입(Infuse) | 8년 만의 새 카드 타입 |

## 2. 핵심 신규 요소 (2022의 정체성)

### 콜로사스 (Colossal) — 멀티파트 하수인 ★ stsl 직접 연관
- 거대 하수인이 **부속 부위(appendage)와 함께** 전장에 등장
- 예: 본체 8/8 + "팔" 2기가 동시에 — 한 카드가 여러 칸을 차지
- 부속 부위는 별도 하수인 — 따로 제거 가능, 본체와 별개 스탯/효과
- *핵심*: 한 "캐릭터"를 여러 개의 독립 부위로 표현 — **stsl 의 `multi_part` 보스(야마타노오로치 8머리, 히드라 등) 구상과 본질적으로 동일**

### 장소 (Location) — 신규 카드 타입
- 하수인/주문/무기/영웅에 이은 **5번째 카드 타입** (8년 만)
- 전장에 영구히 놓이고, 쿨다운마다 효과 발동 (내구도/사용 횟수 보유)
- 하수인처럼 공격당하지 않음 — "안전한 반복 효과 엔진"
- *핵심*: 신규 카드 타입은 "기존 타입이 못 하던 역할"을 채워야 한다. 장소 = "공격받지 않고 매 턴 반복되는 효과"

### 죽음의 기사 (Death Knight) — 11번째 직업 + 룬 시스템
- 영웅 능력: 2코 — 시체 자원으로 사용하는 효과
- **룬(Rune) 시스템**: 덱에 룬 슬롯 3개 — 혈기(Blood)/냉기(Frost)/부정(Unholy) 룬을 카드마다 요구. 덱의 룬 구성이 사용 가능 카드를 제한
- **시체(Corpse) 자원**: 하수인이 죽으면 시체 획득 → 시체를 소모해 효과 발동
- *핵심*: 룬은 "덱 구축 제약"의 정교한 버전 — 3슬롯을 혈기3 / 냉기3 / 혈기2냉기1 등으로 배분, 각 조합이 다른 덱

### 잠수 (Dredge) & 주입 (Infuse)
- 잠수: 덱 **바닥** 3장 중 1장을 맨 위로 — 덱 순서 조작 (Discover 의 덱 내부판)
- 주입: 손/덱의 카드가 "아군 하수인이 죽을 때마다" 강해짐

## 3. 메타 3시대 구분

### 정복자의 항로기 (2022.4~8) — 콜로사스와 나가
- **콜로사스 하수인**: 멀티파트 거대 하수인이 보드를 한 번에 장악
- **Naga 종족 덱**: 주문 시전과 시너지 (Mage·Rogue 등)
- 잠수(Dredge) 덱 — 덱 바닥에 강카드를 깔고 잠수로 끌어올림

### 나스리아기 (2022.8~12) — 장소와 미스터리
- **장소(Location) 카드**가 각 직업에 1~2종 — 반복 효과 엔진
- **주입(Infuse)** 덱 — 하수인 희생 시너지
- 살인 미스터리 테마 (10명 용의자 서사)

### 리치 왕기 (2022.12~) — 죽음의 기사 등장
- **죽음의 기사 직업** 출시 — 룬 조합별 3대 빌드:
  - 혈기(Blood) DK: 자가 회복 컨트롤
  - 냉기(Frost) DK: 주문/번 콤보
  - 부정(Unholy) DK: 시체·하수인 떼 어그로
- 출시 직후 비교적 안정 — 2020 악마사냥꾼의 "강하게 출시 후 너프" 실패를 학습한 듯 보수적 출시

## 4. 아키타입 진화 + 신규 축 — 2022

```
빠름 ←──────────────────────────────────→ 느림
어그로          미드            컨트롤
Unholy DK       Naga 계열       Blood DK
Aggro 계열      Colossal 덱     Control / Location 덱
            룬 시스템 (죽음의 기사 — 덱 구축 제약 축)
```

### 4-1. 멀티파트 하수인 — 콜로사스 ★ stsl 핵심 참조

| 항목 | 내용 |
|---|---|
| 메커니즘 | 본체 하수인 + 부속 부위 N기가 한 카드로 동시 등장 |
| 예시 | 본체(거대 스탯) + 좌/우 부속(보조 스탯·효과). 부속은 독립 하수인 — 개별 제거 가능 |
| 전략적 의미 | 한 카드가 여러 위협 → 상대는 본체와 부속을 각각 처리해야 함. "1장이 보드 절반을 채움" |
| 약점 | 부속을 먼저 제거당하면 본체만 남음. 광역기에 한 번에 정리당함 |

*기획 분석 (stsl 적용)*: 콜로사스는 **한 "개체"를 여러 독립 부위로 분할**하는 설계다. 이는 stsl 의 보류된 `multi_part` 보스 구상(야마타노오로치 8머리, 히드라 머리 분리)과 정확히 같은 문제를 푼다:
- **부위별 독립 HP/스탯** — 각 부위가 따로 죽음
- **부위 제거 순서가 전략** — "팔(보조 부위)을 먼저 죽일까, 본체를 먼저 칠까"
- **본체 vs 부속의 역할 분담** — 본체는 위협, 부속은 버프/도발/효과
하스스톤 콜로사스의 구현(데이터 모델: 본체 카드가 부속 토큰을 연결, 부속은 독립 엔티티)을 stsl `multi_part` 보스 설계의 직접 레퍼런스로 삼을 수 있다.

### 4-2. 신규 카드 타입 — 장소(Location)

| 항목 | 내용 |
|---|---|
| 정체성 | 공격받지 않는 반복 효과 엔진. 쿨다운마다 1회 발동, 사용 횟수 제한 |
| 기존 타입과의 차별 | 하수인(공격받음, 공격함) / 무기(영웅이 휘두름) / 주문(1회성)과 달리 — "안전하게 매 턴 반복" |
| 기획 의미 | 8년 만의 새 카드 타입. "기존 4타입이 못 하던 역할(안전한 지속 효과)"을 정확히 채움 |

*기획 교훈*: 신규 카드 타입은 ① 기존 타입의 빈 역할을 채우고 ② 기존 타입과 명확히 구별되는 규칙(장소는 공격 불가·쿨다운)을 가져야 한다. 그냥 "강한 하수인"은 새 타입이 아니다 — **새 규칙이 곧 새 타입**.

### 4-3. 룬 제약 — 죽음의 기사

| 룬 조합 | 빌드 | 특징 |
|---|---|---|
| 혈기 3 | Blood DK | 자가 회복 컨트롤 |
| 냉기 3 | Frost DK | 주문/번 콤보 |
| 부정 3 | Unholy DK | 시체·하수인 떼 어그로 |
| 혼합 (2+1) | 하이브리드 | 두 룬 카드를 섞되, 순수 빌드의 극단 카드는 포기 |

*기획 분석*: 룬은 **"덱 구축 제약"의 가장 정교한 버전**. 2015 하이랜더(중복 0), 2018 짝수/홀수, 2020 순수(중립 0)는 "제약 1개 → 보상 1개"였다. 룬은 **3슬롯 배분**이라 "혈기3" vs "혈기2냉기1"처럼 연속적인 스펙트럼을 만든다 — 제약 자체가 덱 빌딩의 핵심 의사결정. 직업 1개 안에 사실상 3~4개의 하위 직업이 들어있는 셈.

## 5. 메타 이론 — 2022의 디자인 진화

### 5-1. 멀티파트 — "하나의 적을 여러 개로"
콜로사스는 "한 카드 = 여러 엔티티"를 정식화. 보스/거대 적을 "단일 거대 HP 덩어리"가 아니라 "부위별 독립 개체"로 표현하면:
- 플레이어에게 "어느 부위부터?"라는 의사결정
- 부위마다 다른 역할(공격/방어/버프)로 전투가 입체적
- 부위를 깎는 점진적 성취감
*거대 적은 단일 HP 바보다 멀티파트가 전략적으로 풍부하다.*

### 5-2. 신규 카드 타입 = 새 규칙
장소는 8년 만의 새 타입 — 그만큼 신중했다. 새 타입의 조건: 기존이 못 하는 역할 + 명확히 다른 규칙. *콘텐츠 확장의 가장 큰 단위는 "새 카드"가 아니라 "새 타입/시스템"이다.*

### 5-3. 제약의 정교화 — 1차원에서 다차원으로
하이랜더(이분법: 중복 0/아님) → 룬(3슬롯 배분: 연속 스펙트럼). 제약 메커니즘이 "켜고 끄는 스위치"에서 "다이얼"로 진화. *제약을 다차원화하면 같은 직업/영웅 안에서도 빌드 다양성이 폭발한다.*

### 5-4. 신규 직업 출시 — 2020의 학습
2020 악마사냥꾼은 강하게 출시 → 긴급 너프 실패. 2022 죽음의 기사는 상대적으로 보수적 출시 — **이전 실패를 학습한 흔적**. 라이브 게임은 자사의 과거 사례에서 배운다.

## 6. 확장이 메타에 미친 영향

### 정복자의 항로 — "멀티파트로 보드 게임을 입체화"
콜로사스가 "한 카드로 보드 절반"을 만들며 보드 싸움의 양상을 바꿈. *멀티파트는 보드 상태를 단숨에 복잡하게 만드는 강력한 도구.*

### 나스리아 — "8년 만의 새 카드 타입"
장소 도입은 신중한 대형 결정. 출시 후 큰 사고 없이 안착 — *충분히 검토된 새 타입은 메타를 부드럽게 확장한다.*

### 리치 왕 — "신규 직업 + 신규 제약 시스템 동시"
죽음의 기사는 직업 + 룬 시스템을 함께 도입. 룬이 출시 직후 너프 대상이 되긴 했으나(특정 룬 조합 강세), 2020 악마사냥꾼보다 안정적. *신규 직업에 고유 시스템(룬)을 묶으면 정체성이 선명해진다.*

## 7. stsl 적용 시사점

### 7-1. 콜로사스 = multi_part 보스의 직접 레퍼런스 ★
stsl 의 보류된 `multi_part` 보스(야마타노오로치 8머리, 히드라 머리 분리, 야마 head 부위)는 하스스톤 콜로사스와 **본질이 같다**. 콜로사스 설계를 직접 참조:
- **데이터 모델**: 본체 적 + 부속 부위 적을 연결. 부속은 독립 enemy 엔티티 (개별 HP/intent)
- **부위 제거 순서 전략**: "팔/머리(부속)를 먼저 죽일까, 본체를 칠까" — 영웅 카드 타겟팅 의사결정
- **본체 vs 부속 역할 분담**: 본체=강공격, 부속=버프/도발/추가 공격
- stsl 의 `_enemy_char_nodes` / `_enemy_status` 배열에 부속을 별도 인덱스로 등록하면 기존 시스템 재활용 가능
→ multi_part 보스 구현 시 이 문서를 설계 기반으로 활용 권장.

### 7-2. 신규 카드 타입 — "장소"형 지속 효과
stsl 카드는 현재 ATTACK/SKILL/POWER. 장소(Location)처럼 **"전장에 놓고 매 턴 반복 발동되는" 신규 카드 타입**을 검토 가능. 단 신규 타입은 "기존이 못 하는 역할 + 명확한 새 규칙"이 필수.

### 7-3. 룬형 다차원 제약 — 영웅 빌드 분화
죽음의 기사 룬(3슬롯 배분) 교훈 — stsl 영웅의 archetype 시스템을 **"슬롯 배분"형 제약**으로 확장 가능. 예: 영웅이 3개 archetype 슬롯을 가지고, "돌격3" vs "돌격2군단1" 처럼 배분 — 한 영웅 안에 여러 빌드.

### 7-4. 거대 적 = 멀티파트가 단일 HP보다 낫다
stsl 보스를 "단일 거대 HP"로 둘지 "멀티파트"로 할지 — 콜로사스 교훈은 명확히 후자. 멀티파트는 전략적 의사결정·점진적 성취·입체적 전투를 준다.

### 7-5. 신규 영웅/시스템은 보수적 + 고유 시스템 묶기
2020→2022 학습 — stsl 신규 영웅은 보수적 출시 + 고유 시스템(죽음의 기사의 룬처럼)을 묶으면 정체성이 선명.
