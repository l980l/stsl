# STSL 스토리·로어 설계 — "영령의 전당 / 순환의 사육장"

> 엘든링식 **암시·추론형(implicit) 서사**. 컷신·대사 시스템 없이, 기존 표면(죽음 화면·유물·챕터)에 파편을 심어 플레이어가 세계를 *유추*하게 한다. 톤: **어둡고 모호**.

## 1. 개요

- **한 줄**: 죽은 역사 위인들이 *전당*에 안치돼 있다가 '은총'으로 깨어나, 각 신화의 죽음의 영역으로 보내져 끝없이 싸운다.
- **목표**: 현재 강렬한 전제("역사 vs 신화")에 *서사적 접착제*를 입힌다. 왜 모였나·여긴 어디인가·무엇을 위해 싸우나를 단서로 추론하게.
- **제약**: 게임은 계속 확장(영웅·챕터 추가)된다 → 로어는 **덧붙이기**로 커져야지 **고쳐쓰기**가 되면 안 된다 (§5).
- **비-대사**: 현재 캐릭터 대사 시스템 없음. 이 설계도 대사에 의존하지 않는다(보스 목소리는 §8 선택 항목).

## 2. 중심 뼈대 — 영령의 전당

영웅은 **죽은 역사 인물**이다. 죽은 뒤, 시대도 국적도 다른 위인들이 *전당(The Hall)* 에 유물처럼 안치된다. **관리자(The Curator)** 가 그들에게 **은총(Grace)** 을 내려 깨우고, 각 신화의 *신역(죽음의 영역)* 으로 보내 "정복"을 명한다. 왜인지는 듣지 못한다.

이 뼈대는 현재 미감과 거의 1:1로 맞물린다:

| 게임 요소 | 서사적 의미 |
|---|---|
| Museum Mat 프레임 (배틀씬 영웅·몬스터) | 전당에 *전시·안치된* 영령 |
| 보상 화면 "전리품과 은총" | 은총을 받고 전리품(유물)을 거둠 |
| 카드 아트(유물을 museum-quality로 묘사) | 영령의 유물이 전당에 안치된 모습 |
| 챕터(신화권) | 각 신화의 *사후세계/신역* |
| 챕터 보스 | 그 신역의 주인(신격) |
| 영웅 영입 | 전당에서 또 다른 영령을 깨움 |
| 유물·은총 | 전당이 *빌려준(실은 빼앗은)* 힘 |
| 카드 | 영령의 생전 위업·기억의 재현 |
| 로그라이크 런/죽음/리셋 | **한 번의 각성과 그 끝** (§3) |

## 3. 중심 비밀 — 순환의 사육장

전당은 해방이 아니라 **굴레**다. 영령은 **각성 → 신역 진군 → 전사 → 재안치 → 기억 소거**를 끝없이 반복한다. 자신은 *처음* 깨어났다 믿지만 수없이 되풀이된 일이다.

- **은총 = 사슬**: 깨우고 힘을 주지만, 동시에 영령을 전당과 순환에 묶는다.
- **유물 = 빼앗은 전리품**: 이전 순환에서 스러진 영령들에게서 *거둔* 것. 그래서 유물엔 남의 기억이 묻어있다.
- **로그라이크가 곧 디제틱 장치**: 매 런 = 한 번의 각성. 패배(=재안치)·재시작(=각성)·메타 진행이 그대로 순환의 표현.

**점진적으로 추론될 질문(끝까지 다 풀지 않음):** 왜 깨워지는가 · 관리자는 무엇을 거두는가(영광? 위업? 영혼?) · 순환에 끝은 있는가 · 신역의 주인들도 갇힌 자인가.

## 4. 확장 안전 아키텍처

### 4계층 (추가 = 슬롯 채우기)

**L0 — 코어 정전 (고정, 절대 안 바뀜)**

- **전당**: 무시간의 안치소. 빛이 한결같고 시간이 흐르지 않는다.
- **관리자**: 전당을 관장하며 은총을 내리는 존재. 얼굴·정체 불명. 자비로운 후원자처럼 보인다.
- **은총**: 영령을 깨우고 유물·힘을 부여하는 권능. 본질은 순환에 묶는 사슬.
- **순환**: 각성→진군→전사→재안치→기억 소거. (§3)
- **신역**: 전당 너머 펼쳐진 각 신화권의 사후세계. 영령은 이를 정복하라 명받는다.
- **유물**: 은총이 빌려준 듯하나, 스러진 영령들에게서 거둔 전리품.

**L1 — 영웅 슬롯 (영웅 1명당, 자기완결)**

슬롯 필드: `생전` / `죽음(역사 기반)` / `미련(순환이 매번 건드리는 상처)` / `은총이 빼앗은 것(그를 묶는 대가)`.

| 영웅 | 죽음 | 미련 | 은총이 빼앗은 것 |
|---|---|---|---|
| napoleon | 유배지 세인트헬레나에서 쓸쓸히 | 끝내 되찾지 못한 제국 | *패배(워털루)의 기억* — 그래서 매 순환 "이번엔 이긴다" 믿음 |
| cleopatra | 독사(아스프)로 스스로 | 지키지 못한 왕국·핏줄 | *안식* — 죽음의 방식(독)을 무기로 되돌려받았으나 끝나지 못함 |
| yi_sun_sin | 노량 마지막 해전, 유탄에 ("내 죽음을 알리지 마라") | 지켜낸 바다, 그 후를 못 봄 | *죽음을 알릴 권리* — 전당이 그의 죽음을 숨기고 계속 싸우게 함 |
| joan_of_arc | 화형 | 증명받지 못한 신의 음성 | *'은총'이라는 단어* — 신의 은총인 줄 믿고 사슬을 따름 |
| genghis_khan | 원정 중, 무덤조차 숨겨짐 | 끝나지 않은 정복 | *안식처* — 숨겨진 무덤처럼 전당이 그의 끝을 지움 |
| musashi | 동굴에서 홀로(오륜서를 남기고) | 도달 못한 '공(空)'의 경지 | *비움* — 비우려 했으나 순환이 매번 다시 채움 |

> 신규 영웅 = 이 4필드만 채운다. 다른 영웅/챕터를 참조하지 않는다.

**L2 — 신역 슬롯 (신화권 1개당, 자기완결)**

슬롯 필드: `죽음의 영역(이름)` / `주인(보스)` / `순환 힌트(그 영역 개념이 영령의 처지를 비추는 한 줄)`.

| 신화권 | 죽음의 영역 | 순환 힌트(개념적 메아리) |
|---|---|---|
| greek | 하계 (스틱스 너머) | "강을 건넌 자는 돌아오지 못한다 — 너는 이미 여러 번 건넜다" |
| egyptian | 두아트 (심장의 저울) | "네 심장은 매번 같은 무게다 — 기억이 없어 죄도 공도 쌓이지 않으니" |
| norse | 헬·니플헤임 / 발할라 | "영광된 전사자의 끝없는 전쟁 — 너의 전당과 무엇이 다르냐" |
| japanese | 황천(요미) | "돌아보지 말라 했다 — 너에겐 돌아볼 기억조차 없다" |
| daoist | 지부·황천 (윤회의 수레) | "너는 윤회조차 박탈당했다 — 같은 몸으로 도느니" |
| buddhist | 윤회·지옥도(naraka) | "해탈은 수레에서 내리는 것 — 전당은 너를 내려주지 않는다" |

> 신규 챕터 = 새 신화권의 사후세계 개념 1개를 골라 슬롯을 채운다. 각 신화의 *사후세계 개념이 순환을 비추는* 패턴을 유지.

**유물 lore 라인 (유물 1개당 한 줄)**

패턴: *"[누구/언제]에게서 거두었다 + 은총·순환 암시."* (기존 `relic.X.desc`(기계 설명)와 분리된 `relic.X.lore`)

- `burning_blood`: "식지 않는 심장에서 거두었다. 그는 아직도 자신이 살아있다 믿는다."
- (예시) 방패류: "어느 충신이 마지막까지 놓지 않은 것. 그 주인의 이름은 전당도 기억하지 못한다."
- (예시) 회복류: "상처를 잊게 하는 권능. 잊는 것은 상처만이 아니다."

### 확장 원칙 3

1. **숫자·순서 하드코딩 금지.** "6명의 챔피언", "4번째 신역", "최종은 X" 금지. → *"챔피언들", "신역에서 신역으로"* (열린 수). 시작 영웅·영입·챕터 순서가 가변(로그라이크)이므로 필수.
2. **파편은 순서 독립.** 어떤 단서도 "이미 본 X"를 전제하지 않는다. 아무 순서로 모아도 그림이 맞춰진다.
3. **결말은 '수'가 아니라 '순환의 진실'에 묶는다.** 끝 = *관리자/순환과의 대면* (특정 챕터 번호 아님). 챕터를 더 붙여도 여정만 길어지고 페이로프는 유효.

## 5. 전달 표면 — 러프 1차 범위

선택된 3개 (모두 기존/소규모, 코어 비밀 전달에 집중):

### 5.1 죽음·각성 화면
- **각성 라인(런 시작)** / **재안치 라인(패배)** / **순환 암시(승리)** 세트.
- **런 카운트에 따라 미묘히 변주** → "전에도 왔다"를 점진 자각시키는 연출 (저장된 run count 필요).
- 신규 i18n 키 + 표시 지점(게임 시작 전환, `ui.game_over.*`).

### 5.2 유물 lore
- `relic.X.lore` 신규 키 90개. 유물 툴팁/상세에 회색·이탤릭 한 줄 추가.

### 5.3 챕터(신역) 진입 라인
- `chapter.realm.X.intro` 신규 키. 챕터 진입 전환 화면에 1줄.

## 6. 톤 샘플

> **각성(런 시작)**: "또다시 눈을 뜬다. 천장의 빛은 어제와 같고, 어제가 언제였는지는 기억나지 않는다."
>
> **재안치(패배)**: "전당이 너를 다시 거둔다. 흠집 하나 없이 — 기억만 빼고."
>
> **순환 암시(승리)**: "또 하나의 신역이 잠잠해졌다. 전당의 빛은 여전히, 너를 부른다."
>
> **유물(버닝 블러드)**: "식지 않는 심장에서 거두었다. 그는 아직도 자신이 살아있다 믿는다."
>
> **챕터1 진입(하계)**: "강을 건넌 자는 돌아오지 못한다 했다. 너는 이미 여러 번 건넜다."

## 7. 보류·미정 (후속 결정)

- **결말/관리자 대면 슬롯**: 지금은 비워둔다. 마지막 신역을 붙일 때 *참엔딩(순환의 해소 or 직시)* 으로 끼움. 현재는 단서가 미스터리를 *쌓기만* 함 (정상).
- **캐릭터 목소리(선택)**: 보스 1줄 대사(순환 암시)·영웅 '메아리'(생전 기억 환청). 신규 표면이라 러프 1차 제외. 추가 시 *희소·암호* 원칙.
- **카드 flavor**: 카드 표면 신규 + 200+장이라 비용 큼 → 보류.

## 8. 비-목표

- 컷신·분기 서사·성우 더빙.
- 기존 이벤트 *메커니즘* 변경 (텍스트 윤색은 후속, 1차 제외).
- 전 영웅·전 유물 로어 *완성*(이 문서는 정전+템플릿+시드까지. 전량 집필은 구현 계획에서).
- 게임플레이/밸런스 변경.
