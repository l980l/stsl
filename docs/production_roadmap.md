# STSL — Production Roadmap

> 작성일: 2026-04-17
> 기준: 현재 구현 상태(Act 1 플레이 가능 프로토타입) 기준 완성까지의 전 작업 목록
> 범례: ✅ 완료 / 🔲 미완료 / 🔶 부분 완료

---

## 현재 상태 요약

Act 1 전체 흐름(맵 → 전투 → 카드픽 → 상점 → 휴식 → 이벤트 → 보스 → 엔딩)이 동작하는 수직 슬라이스 프로토타입 완성.
영웅 3인, 보스 1종(히드라), 카드 약 15장, 렐릭 약 10종, 이벤트 5종.

---

## Milestone 1 — Act 1 콘텐츠 완성 (현재 단계)

### 1-1. 카드 풀 확장
각 영웅별 최소 15장 고유 카드. 현재 스타터 카드 2~4장에서 확장.

**나폴레옹** (아키타입: 돌격 / 군단 / 지휘)
- 🔲 돌격 아키타입 카드 5장 (저비용 연속 공격, 사기 소모 폭발기)
- 🔲 군단 아키타입 카드 5장 (병사 토큰 소환·활용)
- 🔲 지휘 아키타입 카드 5장 (팀원 카드 복사·강화)
- 🔲 사기(Morale) 시스템 실제 구현 (현재 consume_morale 카드만 존재)

**이순신** (아키타입: 거북선 / 학익진 / 필사즉생)
- 🔲 거북선 아키타입 카드 5장 (방어도 축적 + 방어도 비례 반격)
- 🔲 학익진 아키타입 카드 5장 (팀 전체 방어도/버프)
- 🔲 필사즉생 아키타입 카드 5장 (저 HP 조건부 강화)
- 🔲 진형(Formation) 시스템 구현 (생존 팀원 수에 따라 효과 변화)

**클레오파트라** (아키타입: 독살 / 조종 / 저주)
- 🔲 독살 아키타입 카드 5장 (독 스택 특화)
- 🔲 조종 아키타입 카드 5장 (매혹 부여·활용)
- 🔲 저주 아키타입 카드 5장 (다중 디버프 중첩)
- 🔲 매혹(Charm) 시스템 구현 (적을 1턴 아군으로 전환)

### 1-2. 적 추가 (Act 1 — 그리스 신화)

**일반 적** (목표: 6종)
- ✅ 기본 적 (스켈레톤 계열 - 실질적으로 구현된 것)
- 🔲 메두사 시선 (독 부여 + 취약)
- 🔲 사이클롭스 (고 피해 단일 공격, 가끔 전체 공격)
- 🔲 하르피이아 (빠른 연속 약공격, 카드 버리기)
- 🔲 케르베로스 (3마리 형태, 하나씩 처치)
- 🔲 미르미돈 병사 (약함, 2~3마리 등장, 강화 시 위험)

**엘리트 적** (목표: 3종)
- 🔲 미노타우로스 (보복형 - 직전 공격자 역타)
- 🔲 스킬라 (다중 헤드 - 헤드별 독립 HP/패턴)
- 🔲 고르곤 (매 턴 취약 부여 + 페이즈 전환)

**보스** (목표: 1종 — 히드라)
- ✅ 히드라 (3페이즈, phase_thresholds 구현)
- 🔲 히드라 실제 비주얼 및 페이즈별 연출

### 1-3. 렐릭 확장
- ✅ 공용 렐릭 ~10종
- 🔲 나폴레옹 전용 렐릭 2종 (황제의 인장, 포병 나팔)
- 🔲 이순신 전용 렐릭 2종 (거북선 모형, 난중일기)
- 🔲 클레오파트라 전용 렐릭 2종 (독사의 팔찌, 파라오의 인장)
- 🔲 저주 렐릭 3종 (강력한 효과 + 패널티)
- 🔲 캐릭터 생존 조건부 강화 효과 구현

### 1-4. 이벤트 확장
- ✅ 기본 이벤트 5종
- 🔲 그리스 신화 테마 이벤트 5종 추가 (총 10종)
  - 예: 신탁의 목소리 (미래 예언 - 다음 룸 타입 확인), 프로메테우스의 불 (카드 강화 or HP 손실), 아킬레우스의 갑옷 (강력한 방어 렐릭 or 치명적 약점)

### 1-5. 상점 보완
- 🔲 상점 카드 목록을 현재 영웅 덱 기반 풀에서 추출
- 🔲 카드 제거 기능 (골드 소모)
- 🔲 렐릭 구매 기능 구현 확인

### 1-6. 크로스 시너지 구현
- 🔲 나폴레옹 사기 → 이순신 진형 발동 조건 연동
- 🔲 클레오파트라 독 → 이순신 반격 추가 피해 연동
- 🔲 나폴레옹 사기 소모 → 클레오파트라 매혹 스택 부여 연동

### 1-7. 알려진 버그 수정
- 🔲 TargetType.ALL 전체 영웅 공격 미적용
- 🔲 블록 완전 흡수 시 amount=0 시그널 발화

## Milestone 2 — Act 2 (이집트 신화)

### 2-1. Act 2 맵
- 🔲 Act 2 전용 맵 생성 로직 (Act 1과 분리 or 파라미터화)
- 🔲 Acts 간 전환 흐름: 보스 처치 → 영웅 영입 → Act 2 맵 진입
- 🔲 Act 2 난이도 조정 (적 HP/공격력 스케일)

### 2-2. Act 2 적 (이집트 신화)
- 🔲 일반 적 6종: 아누비스 전령, 미이라 전사, 스카라베 군집, 세크메트의 사제, 사막 독사, 샤브티 인형
- 🔲 엘리트 적 3종: 스핑크스 (수수께끼 메카닉), 세트의 화신 (디버프 특화), 바스테트의 군주
- 🔲 보스: 오시리스의 심판 (다중 단계 심판 메카닉)

### 2-3. Act 2 이벤트 (이집트 테마 10종)
- 🔲 사자의 서, 파라오의 저주, 이시스의 가호 등

### 2-4. Act 2 전용 렐릭 3종
- 🔲 이집트 신화 테마 공용 렐릭

---

## Milestone 3 — Act 3 (북유럽 신화)

### 3-1. Act 3 적 (북유럽 신화)
- 🔲 일반 적 6종: 드라우그르, 우르드의 거미, 요툰 병사, 볼바 마녀, 흐림팍시 기수, 갸르라르 뱀
- 🔲 엘리트 적 3종: 펜리르 새끼 (성장 메카닉), 발키리 (전사한 영웅 부활), 요르문간드르 분신
- 🔲 보스: 요르문간드르 (전장 독 안개 + 페이즈별 독 폭발)

### 3-2. Act 3 이벤트 10종, 전용 렐릭 3종
- 🔲 오딘의 까마귀, 라그나로크의 예언, 발할라 초대장 등

---

## Milestone 4 — Act 4 (동아시아 신화) + 최종 보스

### 4-1. Act 4 적 (한국/일본/중국 신화 혼합)
- 🔲 한국: 저승사자, 처용, 도깨비
- 🔲 일본: 오니, 텐구, 유키온나
- 🔲 중국: 나타, 사대천왕 병사, 네잔
- 🔲 엘리트 3종, 보스: 염라대왕 (3개 재판 페이즈)

### 4-2. 최종 보스
- 🔲 신화 혼합 최강 신격 (4개 신화권 능력 순차 사용)
- 🔲 4페이즈 구조

## Milestone 5 — 추가 영웅

GDD 기준 MVP 3인 이후 확장 영웅.

- 🔲 영웅 4: 잔 다르크 — 신성 메카닉, 팀 부활 특화
- 🔲 영웅 5: 칭기즈칸 — 기동(Rush) 메카닉, 다수 약공격
- 🔲 영웅 6: 측천무후 — 저주/독 강화, 사망 활용
- 🔲 영웅당 카드 15장, 전용 렐릭 2종, 크로스 시너지 정의

## Milestone 6 — 시스템 완성

### 6-1. 병사 토큰 시스템
- 🔲 소환된 토큰 유닛 — 별도 HP 없는 버프 오브젝트 or 독립 전투원
- 🔲 나폴레옹 군단 아키타입 카드와 연동

### 6-2. 비밀 룸 / 저주 경로
- 🔲 MapGenerator에 SECRET / CURSED_PATH 룸 타입 추가
- 🔲 비밀 룸: 고유 렐릭 보상
- 🔲 저주 경로: 강적 + 강렐릭

### 6-3. 팀원 부활
- 🔲 특정 이벤트에서 사망 팀원 부활 옵션
- 🔲 부활 비용 (골드 or 카드 제거)

### 6-4. 도발(Taunt) 시스템
- 🔲 카드 사용 시 해당 팀원에게 모든 적 어그로 집중
- 🔲 BattleManager 어그로 로직 추가

### 6-5. 카드 타입 시스템
- 🔲 ATTACK / SKILL / POWER 구분 구현
- 🔲 POWER 카드: 즉시 사용, 런 내 지속 효과, 덱에서 소진

### 6-6. 덱 뷰어 / 조합 힌트
- 🔲 전투 중 덱 전체 열람
- 🔲 현재 시너지 활성 여부 표시 (선택 사항)

### 6-7. 난이도 설정
- 🔲 일반 / 어려움 / 고행(Ascension) 모드
- 🔲 Ascension: 단계별 누적 패널티 (적 HP+, 저주 렐릭 강제 등)

---

## Milestone 7 — 비주얼 / 오디오

### 7-1. 캐릭터 아트
- 🔲 나폴레옹 스프라이트 (아이들 / 공격 / 피격 / 사망)
- 🔲 클레오파트라 스프라이트
- 🔲 이순신 스프라이트
- 🔲 사망 상태 연출 (반투명 or 그레이스케일)

### 7-2. 적 아트
- 🔲 Act 1 적 전체 스프라이트 (일반 6 + 엘리트 3 + 히드라)
- 🔲 히드라 페이즈별 스프라이트 변화 (머리 수 감소)
- 🔲 Acts 2~4 순차 추가

### 7-3. 카드 아트
- 🔲 카드별 일러스트 (우선순위: 스타터 카드 → 주요 아키타입 카드)
- 🔲 카드 프레임 디자인 (일반 / 강화)

### 7-4. UI 폴리싱
- 🔲 전투 화면: HP바, 에너지, 인텐트 아이콘 실제 그래픽 적용
- 🔲 맵 화면: 노드 아이콘, 경로선, 배경
- 🔲 카드 픽 / 상점 / 휴식 / 이벤트 화면 배경
- 🔲 게임 오버 / 클리어 화면 연출
- 🔲 상태이상 아이콘 실제 이미지 (현재 이모지 텍스트)

### 7-5. 애니메이션 / 이펙트
- 🔲 카드 사용 시 이펙트 (공격 임팩트, 독 스플래시, 방어막)
- 🔲 히트 스톱 (공격 시 0.1초 정지)
- 🔲 씬 전환 페이드 인/아웃
- 🔲 페이즈 전환 연출 (보스 분노 이펙트)

### 7-6. 오디오
- 🔲 BGM: Act별 테마 음악 (Act 1 그리스 → 웅장한 오케스트라)
- 🔲 전투 BGM / 보스 BGM 분리
- 🔲 SFX: 카드 드로우, 카드 사용, 공격 임팩트, 방어, 피격, 적 사망
- 🔲 UI SFX: 버튼 클릭, 씬 전환
- 🔲 보이스: 선택 사항 (캐릭터 전용 보이스 라인)

- 🔲 첫 런 시작 시 기초 튜토리얼 (카드 사용, 드래그, 타겟 선택)

## 우선순위 요약

| 우선순위 | 항목 | 이유 |
|---|---|---|
| 🔴 즉시 | 카드 풀 확장 (Milestone 1-1) | 덱빌딩이 없으면 게임이 아님 |
| 🔴 즉시 | 사기/진형/매혹 시스템 구현 | 각 영웅의 정체성 |
| 🟠 단기 | 적 추가 Act 1 완성 (Milestone 1-2) | 전투 다양성 |
| 🟠 단기 | 크로스 시너지 (Milestone 1-6) | 핵심 차별점 |
| 🟡 중기 | Act 2~4 콘텐츠 | 런 길이 및 볼륨 |
| 🟡 중기 | 추가 영웅 (Milestone 5) | 리플레이어빌리티 |
| 🟢 장기 | 비주얼/오디오 (Milestone 7) | 몰입감 |
| 🟢 장기 | 모바일 최적화 (Milestone 8) | 출시 요건 |
| 🔵 출시 직전 | 밸런싱 / 튜토리얼 / QA (Milestone 9) | 품질 보증 |
