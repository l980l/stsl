# 사운드 에셋 목록

## 개요

- 장르: 덱빌딩 로그라이크 카드게임 (Slay-the-Spire류)
- 신화: 그리스 / 이집트 / 북유럽 (런마다 랜덤 배정)
- 영웅: 나폴레옹 / 클레오파트라 / 이순신
- 구성: BGM + 효과음(SFX) + 환경음(Ambient)

## 8. 집계

| 카테고리 | 파일 수 |
|---------|--------|
| BGM | 16 |
| UI 효과음 | 23 |
| 전투 효과음 | 37 |
| 적 효과음 | 29 |
| 이벤트 효과음 | 7 |
| 환경음 | 8 |
| 보이스 (선택) | 11 |
| **합계** | **131** |

> 보이스(VO)는 구현 우선순위 낮음. BGM + SFX 위주로 먼저 제작/수집.

## 9. 권장 포맷

| 용도 | 포맷 | 비트레이트 | 비고 |
|------|------|-----------|------|
| BGM | `.ogg` | 128–192kbps | Godot 스트리밍 재생 |
| SFX | `.wav` | 44.1kHz 16bit | 짧은 효과음 — 메모리 재생 |
| Ambient | `.ogg` | 96kbps | 루프, 스트리밍 재생 |
| VO | `.ogg` | 96kbps | 스트리밍 재생 |
