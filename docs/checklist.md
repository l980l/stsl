# 인디게임 개발 준비 체크리스트

> 프로젝트: STSL (덱빌딩 + 팀빌딩 로그라이크 카드게임)
> 플랫폼: 모바일 (Godot 4.6)
> 수익화: 유료 앱

## 1단계 — 기획

- [ ] 게임 컨셉 확정 (핵심 루프: 덱빌드 → 맵탐험 → 턴제 전투)
- [ ] GDD 작성 (게임 개요, 메카닉, 콘텐츠 계획, 아트 방향, 기술 고려사항)
- [ ] MVP 범위 정의 (1 Act + 제한된 카드/적 수)
- [ ] 기능 크립 방지 규칙 수립
- [ ] 참고 게임 분석 (Slay the Spire, Monster Train, Balatro, Fights in Tight Spaces)
- [ ] 개발 환경 세팅 (Godot 4.6, Claude Code, Git, 헤드리스 모드)

## 2단계 — 프로토타입

- [ ] 핵심 루프 구현 (카드 드래그&드롭, 손패 관리, 에너지 시스템, 기본 전투)
- [ ] 카드 시스템 설계 (CardResource + EffectResource 데이터 드리븐)
- [ ] 로그라이크 요소 구현 (맵 생성, 이벤트/상점/전투 선택, 덱 빌드 화면)
- [ ] 팀원 시스템 구현 (팀원별 HP, 도발 메카닉, 카드-팀원 연결)
- [ ] 몬스터 AI 기본 구현 (고유 타겟팅 패턴)

## 3단계 — 콘텐츠 설계

- [ ] 역사 인물 초상권/저작권 검토
- [ ] 카드 목록 전체 설계 (팀원당 카드 수 확정)
- [ ] 밸런싱 시트 작성 (데미지/비용/효과 수치 기준)
- [ ] 챕터별 몬스터/보스 설계
- [ ] 이벤트 룸 목록 설계 (동료 영입/부활/비밀룸/저주 경로 등)
- [ ] 카드 강화 시스템 설계
- [ ] 릴릭(유물) 목록 설계

## 4단계 — 본 제작 (Production)

- [ ] UI 목업 제작 (전투 화면, 맵 화면, 덱 빌드 화면)
- [ ] 카드 아트 스타일 확정 및 파이프라인 결정 (AI생성/외주/직접)
- [ ] 폰트 라이선스 확인
- [ ] BGM/효과음 출처 결정
- [ ] 콘텐츠 대량 추가 (카드, 릴릭, 적, 이벤트, 보스 데이터 드리븐 확장)
- [ ] 아트 & 사운드 제작/조달 (플레이스홀더 → 최종 아트 순)
- [ ] 저장 시스템 구현 (진행 저장, 덱 저장, 세이브/로드 안정성)
- [ ] JUICY 효과 & 폴리싱 (카드 애니메이션, 파티클, 카메라 흔들림, 사운드 피드백)
- [ ] UI/UX 완성 (손패 정리, 툴팁, 설정 화면, 난이도 조절)
- [ ] 밸런싱 작업 (카드/적/난이도 플레이테스트 반복 조정)

## 5단계 — 기술 & 안정성

- [ ] 헤드리스 모드 자동 테스트 구축
- [ ] 성능 최적화 (카드 다수 시 프레임/메모리)
- [ ] 다중 해상도/입력 지원 테스트
- [ ] 실기기 테스트 (Android/iOS)

## 6단계 — 출시

- [ ] 사업자 등록 및 개발자 계정 생성 (Google Play $25 / App Store $99/년)
- [ ] 베타 테스터 모집 및 피드백 수집
- [ ] 스토어 페이지 준비 (소개 문구, 스크린샷, 트레일러)
- [ ] 가격 책정
- [ ] 개인정보처리방침 페이지 준비
