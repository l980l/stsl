# 튜토리얼 구현과 검증

메인 메뉴 → 튜토리얼에서 세 레슨을 자유롭게 선택하고 재도전할 수 있다.

- **기초 전투:** 에너지 → 공격 → 방어 → 파워 → 턴 종료 → 확정 치명타 → 승리.
- **카운터와 차지:** 강공 예고 → 카운터로 무효화 → 적의 기절 턴 확인 → 마무리.
- **상태이상과 독:** 취약 → 독침 → 첫 독 피해 확인 → 독 재부여 → 독 피해로 승리.

각 단계의 카드·턴 종료 제한은 UI와 전투 로직 양쪽에서 적용한다. 카드 효과가
완료되기 전에는 추가 카드와 턴 종료를 차단한다. 학습에 지정된 치명타 이외의
확률 치명타는 비활성이다. 우측 상단 도감 왼쪽의 복귀 아이콘 버튼으로 자신의 행동 대기 중 레슨 선택으로
돌아갈 수 있다. 중도 종료와 패배는 완료 처리하지 않는다.

완료 기록은 기존 ProgressManager에 저장한다. 튜토리얼 중 SaveManager.save()는
진행 중이던 정규 런을 덮어쓰지 않는다. 팀빌딩 레슨은 아직 구현하지 않았으므로
선택 화면에 미완성 항목을 노출하지 않는다.

## 테스트

`tests/test_tutorial.gd`는 전체 `tests/test_runner.gd`에 포함된다.
`tests/test_tutorial_integration.gd`는 실제 전투 씬과 입력 핸들러를 사용하여
두 카드 디자인의 세 레슨, 안내 화면·종료 버튼의 viewport 클릭 전달,
잘못된 입력, 효과 도중 연속 입력, 종료·패배 후 재도전,
완료 기록의 저장·재로드 및 정규 런 저장 보존을 검사한다.

저장 파일에 영향을 주지 않도록 **별도 임시 프로젝트 경로**에서 실행한다.
프로젝트의 project.godot을 복사하고 리소스 디렉터리 및 .godot을 링크한 뒤,
임시 프로젝트의 `override.cfg`에 다음을 둔다 (원본 프로젝트에 두지 않는다).

```ini
[application]
config/use_custom_user_dir=true
config/custom_user_dir_name="STSL-tutorial-validation-고유이름"
```

```sh
godot --headless --path /임시/프로젝트 -s res://tests/test_runner.gd
godot --headless --path /임시/프로젝트 -s res://tests/test_tutorial_integration.gd
```

통합 테스트는 저장·진행 파일이 동일한 `STSL-tutorial-validation-*` 디렉터리에
있는지 확인하고 실행한다. macOS 샌드박스로 Application Support 쓰기가 막히면
임시 프로젝트의 `autoload`를 링크 대신 복사하고, 그 복사본에 있는 저장 경로
상수 6개(save/progress/game_settings/locale/audio/sacred_theme)를
`/tmp/STSL-tutorial-validation-고유이름/` 아래로 지정한다. 원본 코드의 저장 경로는
변경하지 않는다. CSV 번역 변경 후에는 임시 프로젝트에서
`godot --headless --editor --import --quit --path /임시/프로젝트`를 먼저 실행한다.

화면 캡처는 `--headless` 없이 실행하면서 `-- --capture-dir=/절대/경로`를 추가한다.
이는 자동 진행 시점의 화면을 남기며 실제 마우스 사용감의 수동 플레이테스트를
대체하지 않는다.
