- 다운로드 폴더의 프로젝트를 현재 `pearlfish` 작업 폴더로 옮긴 뒤 작업했다.

- 실제 카드·몬스터 데이터를 분석한 뒤 사용자 적용 승인에 따라 선행 오류를 수정했다. 과거 재현과 남은 강화 후속은 [[전투-밸런스-분석에서-확인한-미해결-오류]].
- 검토용 카드 구성 개편안 v3를 작성했다. 여섯 시작덱·핵심 보상 카드 36개·강화·검증 계획이 포함된다. [[카드-구성-개편안-검토상태]].
- 2026-10-04 최신 작업본 화면 피드백에 따라 튜토리얼의 레슨 선택 버튼을 도감 왼쪽 40×40 복귀 아이콘으로 변경했다. 이전 중앙 배치는 폐기. 통합 테스트 312개 통과, 최종 렌더링 검수는 남았다. [[튜토리얼-구현과-검증]].
- 사용자 지정 개인 AI 위키를 초기화하고 루트에 이후 주요 작업의 자동 읽기·기록 지침을 설치했다. [[2026-10-04-STSL-AI-위키-운영]].

## 확정된 것

- 현재 구현의 위치와 작업 제약은 [[STSL-프로젝트-작업-기준]]이 정리한다.
- LFS 사용 안 함. 커밋·푸시 자동 실행 안 함.
- 2026-10-04 사용자가 이번 변경의 커밋·푸시를 명시적으로 요청했다. 이 요청은 이번 업로드에 대한 승인이고 위키의 평상시 `manual` 정책은 그대로다.
- AI 위키는 개인 범위, 기본 위치 `docs/ai-wiki`.
- 사용자 “적용해” 및 “진행해” 승인에 따라 v3 제안 범위의 게임 적용을 완료했다. 수치 자체는 첫 실험안이며 실제 재미·승률 개선은 미확인이다.

## 열려 있는 질문 / 남은 액션

1. 새 시작덱과 지정 핵심 카드의 실제 플레이 비교. solo/2인/3인, 보스 카운터 봉쇄와 전투 길이를 따로 확인한다.
2. 제안서 밖 카드의 새 명시적 1강을 정의할지는 별도 결정이다. 이번 부분 개편에서 기존 강화 규칙을 유지했다.
3. 실제 창에서 수정 버튼의 문자·정렬·겹침과 세 레슨 화면을 시각 검수한다.
4. 실제 플레이 전투 길이·승률·선택률은 아직 측정하지 않았다. 옛 단순 점수/시뮬레이터를 최신 밸런스 증거로 쓰지 않는다.
5. Git 이력 연결 문제는 해결됐다. `pearlfish`에서 직접 커밋·push 가능하며 현재 연결·브랜치·백업·push 설정은 [[STSL-프로젝트-작업-기준]]에 정리했다. 미추적 파일은 승인된 변경과 구별해 선택적으로 추가한다.

### 2026-10-04 커밋·푸시 시도 결과

- 원본 이력을 복제한 `/tmp/STSL-publish-c1GEZ4/repo`에서 구현·테스트·프로젝트 문서 51개를 커밋했다: `8b4b04f` (`feat: complete tutorial flow and align battle UI`). 아트·오디오·raw·기존의 별도 미추적 자료는 제외했다.
- GitHub 쓰기 도구가 `MCP tool call requires approval, but approval policy is never`로 거절되어 원격 커밋/푸시는 수행하지 못했다. 이 차단을 우회하지 않는다.
- 일반 텍스트의 공백 검사는 정상이며, 복사된 위키 템플릿의 빈 필드·빈 목록 뒤 공백은 `git diff --check` 경고가 남는다. 템플릿 스키마를 무단 수정하지 않았다.
- 업로드 인수인계용 번들은 프로젝트 루트 `git-handoff/stsl-tutorial-completion.bundle`에 남긴다. `cdb11f3` 기반의 로컬 튜토리얼 이력을 담으므로 원격 최신 `main`의 README 커밋(`22f763e`)도 보존하며 통합해야 한다. 강제 푸시하지 않는다.
- 원본 다운로드 프로젝트와 Orca 작업 폴더의 Git 메타데이터는 변경하지 않았다. 커밋은 위 임시 저장소에 있으며 `pearlfish`가 커밋된/원격 연결된 상태로 바뀐 것은 아니다.

### 2026-10-04 Full access 변경 후 해결

- 사용자가 세션을 Full access로 변경한 후 일반 Git 네트워크 접속·fetch·push에 성공했다. 위의 승인 차단은 당시 실행 환경의 기록이며 현재 푸시는 해결됐다.
- 원격 `main`의 README 커밋 `22f763e`를 튜토리얼 브랜치에 병합했다: `37badb0`. 기존 이력을 유지했고 강제 푸시는 하지 않았다.
- `https://github.com/l980l/stsl/tree/feat/tutorial-completion`으로 푸시한 뒤 원격 브랜치 SHA가 로컬 HEAD와 같음을 확인했다. `main`은 `22f763e` 그대로다. PR 생성·main 병합은 아직 하지 않았다.
- 이번 업로드도 기존 이력을 가진 임시 저장소에서 수행했다. `pearlfish` 자체의 별도 Git 이력 연결 문제는 여전히 별도 정리가 필요하며, 업로드 성공과 구별한다.
- [[튜토리얼-구현과-검증]]의 전체 1,606개·통합 312개 통과 결과를 사용했다. 이번 재시도에서는 게임 코드를 바꾸지 않았고 원격 README만 병합했다.
