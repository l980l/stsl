- 2026-10-04 최신 작업본 화면 피드백에 따라 튜토리얼의 레슨 선택 버튼을 도감 왼쪽 40×40 복귀 아이콘으로 변경했다. 이전 중앙 배치는 폐기. 통합 테스트 312개 통과, 최종 렌더링 검수는 남았다. [[튜토리얼-구현과-검증]].

## 확정된 것

- 현재 구현의 위치와 작업 제약은 [[STSL-프로젝트-작업-기준]]이 정리한다.
- LFS 사용 안 함. 커밋·푸시 자동 실행 안 함.
- 2026-10-04 사용자가 이번 변경의 커밋·푸시를 명시적으로 요청했다. 이 요청은 이번 업로드에 대한 승인이고 위키의 평상시 `manual` 정책은 그대로다.
- AI 위키는 개인 범위, 기본 위치 `docs/ai-wiki`.
- 카드 개편 문서 작성은 승인됐지만 그 안의 게임 변경은 아직 승인된 결정이 아니다.

## 열려 있는 질문 / 남은 액션

1. 사용자 카드안 검토 결과를 기다린다. 선택한 범위가 확인되면 원문 명세와 실제 구현을 함께 갱신한다.
2. 전투 오류 수정 요청이 오면 재현 테스트부터 만든다. 카드 수치 변경과 별도 작업으로 검증한다.
3. 실제 창에서 수정 버튼의 문자·정렬·겹침과 세 레슨 화면을 시각 검수한다.
4. 실제 플레이 전투 길이·승률·선택률은 아직 측정하지 않았다. 옛 단순 점수/시뮬레이터를 최신 밸런스 증거로 쓰지 않는다.
5. 기존 GitHub는 `l980l/stsl`. `pearlfish` Git은 초기 커밋만 있고 원격이 없으며 다운로드 원본의 Git 이력과 다르다. 일반 Git 네트워크는 DNS 오류여서 이번 업로드는 GitHub 연결 기능을 사용한다. 원격 `main`의 README를 보존해 `feat/tutorial-completion` 브랜치에 변경을 올릴 준비를 했다. 로컬 작업 폴더 Git 연결 정리는 완료됐다고 가정하지 않는다.
