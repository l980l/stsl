# 전투 밸런스 분석에서 확인한 미해결 오류

## 증상

2026-10-03까지의 카드·몬스터 분석에서 아래 동작을 확인했다. 분석은 읽기 전용이었고 이 오류들은 아직 수정하지 않았다. 2026-10-04 기록 시 주요 문제 코드가 그대로 있는 것도 확인했다.

| 문제 | 당시 확인한 예 / 의미 |
|---|---|
| 카드 소유자 처리 | 두 번째 영웅 무사시의 비연참 에너지 환급이 첫 영웅에게 들어감. 첫·둘째 에너지 4/2. 둘째 영웅의 드로우도 첫 영웅 손만 4→5 |
| 일반 힘 상태 누락 | 일반 `strength` 0과 10에서 같은 기본 공격 피해 100. 파워 힘과 다른 경로 |
| 적 약화 만료 순서 | 약화 0·1일 때 다음 공격 100, 약화 2일 때 75. 약화 1이 행동 전에 만료 |
| 독의 왕좌 상태 종류 | 독만 있는 적에게 디버프 종류 비례 공격 피해 0. 저장 키와 조회 키 불일치 |
| 독 처치의 사망 반사 누락 | 불교 적에 일반 피해 900 후 직접 100 마무리면 반사 250, 독 100 마무리면 반사 0 |
| 중복 막별 공격 배율 | 3막 크로노스 첫 페이즈 공격 160이 224 대신 313. 같은 리소스를 두 경로에서 스케일 |
| 효과 없는 강화 | 공통 카운터를 중복 제거하면 25종에서 강화 전후 효과 수치 동일. 카운터 비용 감소 주석도 현재 구현과 다름 |
| 정예 등급 | 정예 목록의 55개 정의가 일반 등급으로 남아 기본 속도 45를 사용. 의도된 정예 속도 53과 차이 |

수치 예는 당시 특정 조건의 재현값이지 일반적인 피해·승률의 예측값이 아니다. 원본 임시 재현 스크립트·로그는 프로젝트에 영구 보관하지 않았으므로 수정 작업에서는 현재 소스로 회귀 테스트를 새로 만든다.

## 환경

- Godot 4.7.2 mono, 저장 경로를 분리한 headless 진단.
- 재현에서는 확률 치명타를 끈 소규모 전투와 실제 리소스를 사용했다.
- 분석 당시 시드 20261003. 카드·적·전투·덱·강화·시그니처 소스 목록의 SHA-256 집계값: `89c53cf1461362aa21015d376b5afd2d7b90cece84db22bccacc3a9d1e6d9a5e`.
- 작업 트리는 프로젝트 파일 대부분 미추적 상태였으며 확정 커밋 기준의 결과는 아니다. 위 집계는 당시 소스 지문이고 이후 변경의 지문으로 재사용하지 않는다.

## 원인

- `BattleManager`의 일반 DRAW/ENERGY·일부 손패 조건은 `DeckManager`의 첫 영웅용 legacy API를 참조한다.
- 일반 힘 상태는 `_hero_status`에 쌓이나 일반 공격의 힘 보너스는 `_active_powers`에서 읽는다.
- 적 약화는 `_run_one_enemy_turn`의 인텐트 처리 전에 감소한다.
- 독은 `poison_dmg`/`poison_dur`에 저장되는데 상태 종류 계산은 `poison`을 확인한다.
- `_tick_enemy_poison`의 처치 경로는 직접 공격의 시그니처 사망 hook을 호출하지 않는다.
- `_apply_act_difficulty`가 `intent_pattern`과 `phase_patterns`를 따로 돌 때 동일 인텐트 객체를 두 번 변경한다.
- 자동 강화 분기에 빠진 효과와 잘못된 정예 기본 등급이 있다.

## 해결

**아직 미해결.** 분석 요청과 카드안 문서 작성은 이 오류의 구현 수정을 승인한 작업이 아니었다. 다음 수정 요청에서는 소유자 판정·상태·사망 이벤트·공유 리소스 배율·강화 효과를 먼저 회귀 테스트로 고정한다. 정예 속도 수정으로 난이도도 변하므로 별도 비교한다.

## 시도했지만 안 된 방법

기존 `tools/balance_check.gd`의 점수 통과를 실제 밸런스 합격으로 쓰지 않는다. 영구 속도의 999차례를 문자 그대로 평가하고, 효과 서명에서 지속시간 등을 빼며, 일부 강화 투영이 런타임과 다르다. `tools/encounter_simulation.gd`도 3인·고정 피해·방어와 특수 효과 제외를 가정하므로 솔로 초반·실제 ATB 승률 증거가 아니다.

## 재발 방지

- 동일 팀에서 카드 소유자와 영입 순서를 바꿔 드로우·에너지·손패 결과를 검사한다.
- 직접 공격·독·반사·병사 등 처치 경로의 사망 효과를 비교한다.
- 0강/1강에서 설명·미리보기·실제 효과를 비교한다.
- 일반·정예·보스와 모든 페이즈의 막별 배율을 검사하되 공유 리소스를 중복으로 변형하지 않는다.
- 단위 테스트 통과, 밸런스 시뮬레이션, 사람이 느끼는 전투 길이를 구별해서 기록한다.
