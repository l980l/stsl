# 카드 구성 개편안 검토상태

## Summary

사용자가 검토 후 “적용해”, 이어 “진행해”로 v3 구현을 승인했다. 2026-10-08 제안 범위의 시작덱·핵심 보상·명시 강화·공통 규칙과 선행 오류를 적용했다. **제안 범위 구현·회귀 검사 완료, 실전 밸런스 검증 대기**다.

## 원리

개편안은 영웅별 시작 경험을 구별하고 방어·병사·사기의 일부를 소비하는 공격 선택을 제안한다. 현재 구현 오류를 수정한 버전과 비교해야 하며, 오류가 있는 원본보다 강하다는 이유로 성공 판정하지 않는다.

## 동작 과정

- 6명 시작덱 전체: 기본 공격 2 + 기본 방어 2 + 고유 카드 5 + 카운터 1, 각 10장 적용.
- 보상 풀의 핵심 변경 항목 36개, 0강·1강 제안 효과와 역할·위험 포함. 일부 시작덱 카드와 겸용이다.
- 기존 보상 풀 등록 수 189는 유지 제안. 189개 전체의 최종 수치 명세가 아니다.
- 지정 카드와 기본 공격·방어에 명시적 1강을 적용. 표 밖 카드는 기존 강화 규칙이며 새 1강 정의는 아직 미정.
- 현재 피해 100·영웅 HP 1,000 단위를 유지해 구성 변경 효과를 분리. 작은 숫자 전환은 별도 선택지.

## 실무 고려사항

- 검토 중 무사시의 3에너지·4장 손패로 빈 손을 만들 수 없는 초안을 찾아, 방어 자세 한 장을 0비용 버리기 카드 명상으로 대체했다.
- 예약 피해·비용 감소 중복, 권능 중복 규칙을 문서에 명시했다. 이러한 공통 규칙은 미수정 카드에도 영향을 준다.
- 이 위키에서 제안 36개를 복사해 두 번째 수치 정본을 만들지 않는다. 구체적인 카드 표는 아래 원문을 갱신한다.

> [!question] 미확인
> 실제 승률·전투 길이·재미 개선은 아직 측정하지 않았다. 구현 검사를 밸런스 합격으로 해석하지 않는다. 새로운 설명은 한국어·영어이며 다른 언어의 새 설명은 영어로 제공한다.

## 적용과 검증

- 전체 1877 / 튜토리얼 실제 씬 321 / 새 카드 UI 16개 통과, 실패 0. 결정적 규칙 검사이며 독립 플레이 표본 수가 아니다.
- 기존 런의 카드 장수·순서·소유자는 보존하고, 알려진 카드의 최신 정의·강화·키워드를 복원한다. 새 시작덱은 새 런부터 사용한다.
- `CardRevisionV3`가 지정 카드의 효과를 적용하고 GameManager 실제 강화 규칙을 도감과 저장 복원에서도 사용한다.
- 저장 필터 1·2·3·4를 충족하여 기록. 게임·문서·위키 변경은 로컬이며 이번 작업의 커밋·푸시는 하지 않았다.
