# 카드 구성 개편안 검토상태

## Summary

사용자가 검토 후 v3 구현을 승인했고, 2026-10-16에는 단순 수치 변형을 넘어 아키타입 시너지 개편을 요청했다. 최신 로컬 작업은6명/18아키타입의 보상36장 재구성이다. **실제 효과·순서·소비·표시·강화·저장 검증 완료, 사람의 재미와 개편 후 캠페인 밸런스는 미측정**이다. 앞선 절은 각 시점의 승인/검증 기록이며 새로운 카드 규칙에 그대로 승률 근거로 적용하지 않는다.

## 원리

개편안은 영웅별 시작 경험을 구별하고 방어·병사·사기의 일부를 소비하는 공격 선택을 제안한다. 현재 구현 오류를 수정한 버전과 비교해야 하며, 오류가 있는 원본보다 강하다는 이유로 성공 판정하지 않는다.

## 동작 과정

- 6명 시작덱 전체: 기본 공격 2 + 기본 방어 2 + 고유 카드 5 + 카운터 1, 각 10장 적용.
- 보상 풀의 핵심 변경 항목 36개, 0강·1강 제안 효과와 역할·위험 포함. 일부 시작덱 카드와 겸용이다.
- 기존 보상 풀 등록 수 189는 유지 제안. 189개 전체의 최종 수치 명세가 아니다.
- 지정 카드와 기본 공격·방어에 명시적 1강을 적용. 표 밖 카드는 기존 강화 규칙이며 새 1강 정의는 아직 미정.
- 초기 v3는 피해 100·영웅 HP 1,000 단위로 구성 변경을 분리했다. 10/15 실제 작은 정수 적용으로 이 기본 단위를 대체했다.

## 실무 고려사항

- 검토 중 무사시의 3에너지·4장 손패로 빈 손을 만들 수 없는 초안을 찾아, 방어 자세 한 장을 0비용 버리기 카드 명상으로 대체했다.
- 예약 피해·비용 감소 중복, 권능 중복 규칙을 문서에 명시했다. 이러한 공통 규칙은 미수정 카드에도 영향을 준다.
- 이 위키에서 제안 36개를 복사해 두 번째 수치 정본을 만들지 않는다. 구체적인 카드 표는 아래 원문을 갱신한다.

> [!question] 미확인
> 실제 승률·전투 길이·재미 개선은 아직 측정하지 않았다. 구현 검사를 밸런스 합격으로 해석하지 않는다. 새로운 설명은 한국어·영어이며 다른 언어의 새 설명은 영어로 제공한다.

## 적용과 검증

- 전체 1877 / 튜토리얼 실제 씬 321 / 새 카드 UI 16개 통과, 실패 0. 결정적 규칙 검사이며 독립 플레이 표본 수가 아니다.
- 기존 런의 카드 장수·순서·소유자는 보존하고, 알려진 카드의 최신 정의·강화·키워드를 복원한다. 새 시작덱은 새 런부터 사용한다.
- `CardRevisionV3`가 지정 카드의 효과를 적용하고 GameManager 실제 강화 규칙을 도감과 저장 복원에서도 사용한다.
- 저장 필터 1·2·3·4를 충족하여 기록. 게임·문서·위키 변경은 로컬이며 이번 작업의 커밋·푸시는 하지 않았다.

## 2026-10-12 콘텐츠 완성도 1차 보완

- 사용자 승인으로 성능 프로파일링을 중단하고 카드 기능·강화를 먼저 보완했다. 최신 main에서 `content/card-completeness`로 작업하며 큰 수치 단위 전환·카드 삭제·풀 축소는 하지 않았다.
- 등록은 시작 덱/보상 합집합 `owner_id|card_name` 216개, 보상 풀 189개다. 최종 생성 결과를 기준으로 무효 강화 9개와 독력의 실효 없는 +1 강화를 보완했다. 나머지 구방식 강화는 유지한다.
- 파라오의 독력은 본인 남은 에너지 소비 후 기존 독을 `2×소비 에너지`로 일회성 증폭하도록 명확히 했다. 결투는 지정 적과 시전자 사이의 직접 피해 +50%·적 차례 만료를 구현했다. 사기 방어·독 폭발·매혹 배율 설명, 결투 배지·미리보기도 실제 규칙과 일치시켰다.
- 앞서 대화에서 기적의 부활을 무효 강화라고 한 판단은 잘못이었다. 실제 v3 덮어쓰기 후에는 부활30→40%·대체 회복120→160으로 이미 동작한다. 옛 helper 정의만 읽는 방식으로 판단하지 않는다.
- 전체2947·효과29·강화897·카드UI20·튜토리얼321 통과, 실패0. 전용 검사는 전체와 중복이며 플레이 표본이 아니다. 실제 영웅별 밸런스·역할 중복의 최종 재설계는 미완료다.
- 근거·10개 강화 표·역할 비교 후보는 아래 콘텐츠 보완 문서가 정본이다. 필터1·2·3·4·5 충족, 위키/코드 로컬 저장만·커밋/푸시 없음.

## 수치 축소 검토 — 2026-10-12 당시 제안, 10/13 후보 구현 승인

- 사용자가 큰 전투 수치 때문에 암산이 불편하다는 피드백의 해결 방향을 질문했고, 10/13 작은 정수 후보 작성·비교 검증 진행을 승인했다. 이전 피해100/HP1000 유지 결정은 당시 개편 효과를 분리하기 위한 것이며 작은 숫자 전환을 금지한 것은 아니다.
- 추천 초안: HP·피해·방어·회복·독 피해량·힘 보너스를 약1/10 규모의 정수로 재설계하고, 강화는 고정 +1/+2 또는 비용 감소처럼 명시한다. 에너지·사기·병사·드로우·지속·속도·소비 횟수는 일괄 나누지 않는다.
- 소수점 표시나 내부 큰 숫자를 둔 단순 반올림 표시로 문제를 숨기지 않는다. 작은 독/힘과 다단 공격은 개별 조정하고 적용 순서·반올림·최소 피해·저장 버전을 함께 검증해야 한다.
- 목표는 인지/계산 부담 감소다. HP와 피해를 같은 비율로 줄여도 전투 차례 수가 저절로 줄지는 않는다. 계산된 대상별 최종 피해·다단 총합을 보여주는 UI는 별도 보조 수단이다. 전체 퍼센트 상태 삭제나 밸런스 확정은 이번 제안에 포함하지 않는다.

## 작은 정수 후보 v1 — 2026-10-13

- `SmallNumberProfile`이 실제216개 카드의0/1강 결과를 복제해 차원별로 환산한다. 원본 변경·게임 기본 전환은 아직 없다. 실제 BattleManager의 후보 `combat_unit_divisor=10`과 작은 HP/독/매혹 Resource를 사용하며 내부 큰 수치의 표시 반올림 방식이 아니다.
- 매혹 임계100→10/저항20→2, 소비한도, 독/힘·순교은행·시너지의 하드코딩 전투량을 같이 검증한다. 방어당/매혹당 피해계수와 퍼센트는 단위상 유지한다. 일반 플레이 기본divisor1은 기존 동작을 유지한다.
- 강화는 원본 강화를 환산하며 전체 카드가 무효가 될 때만 한 항목+1 후보를 준다. 모든 항목에 각각+1을 주는 방식은 과강화라 제외했다. 소수 표시 ×1.5는 실제 비율 유지/150% 설명으로 변경했다.
- `tools/evaluate_small_numbers.gd`는 카드216×0/1강×빈/축적자원×1/3인팀1728쌍의 실제 즉시 효과를 비교한다. 동일 난수·자원 기반 진단이지 독립 플레이 표본/승률/재미 검증이 아니다. 손패 선택·부활/사망·다음 턴 권능·유물/이벤트/시그니처는 후속 범위다.
- 기본 전환에는 모든 몬스터/영웅/유물/이벤트 생성 데이터·튜토리얼·상점과 SaveManager(version2)의 일회성 HP 이전이 필요하다. 기존 세이브 자동 변환은 아직 하지 않았다. 성능 측정 재개 없음·테스트 무음/격리 저장 유지.
- 단위/평가 계약·재현 명령은 아래 작은 정수 문서가 정본이다. 필터1·2·3·4·5 충족, 위키와 코드 로컬 저장만·커밋/푸시 없음.
- 최종 전체4044통과/실패0, 후보1110(중복)·단위 런타임9통과. 한국어 후보 설명의 숫자 소수 표시0·미분류 숫자 필드0. 1728쌍 중 이상치4쌍은 사막 기마의 드로우당 피해3→4 이산 강화폭 때문에 의도적으로 남겨 검토한다. 선택 대기8쌍(사막의 조리법/명상)은 coverage gap이고 합격으로 취급하지 않는다. 이 수치는 전체 플레이 밸런스 완료를 뜻하지 않는다.

## 2026-10-14 실제 ATB 시뮬레이션

- 사용자 요청으로 실제 BattleManager 턴 큐·비용·드로우·독/병사를 사용하는 원본/후보 다중 턴 비교를 추가했다. 초기 고정 교대 모델은 실제 ATB 결과와 섞지 않는다. 작은 정수 기본 적용/추가 수치 튜닝은 하지 않았다.
- 시작 덱6개와 보상 탐침2개, 지원 일반 몬스터15종의 비교에서 승패 뒤집힘은 없었지만 일부 후보의 차례·잔여 HP 차이가 관측됐다. 시그니처/미지원 의도가 있는105종·정예/보스/복수 적/팀 조합·캠페인 경제는 검증 공백이다. 쉬운 단독 전투 모두 승리는 전체 밸런스 합격이 아니다.
- 화면 밖 병사 타이머의 null Tree 문제는 연출 대기만 건너뛰는 최소 수정과 실제 피해 검사로 고정했다. 기록은 상태 깊은 복사와 손패/덱 순서 보존으로 고쳤고 전용 검사 통과. 제한은 패배가 아닌 비완결 상태로 분리한다.
- 실행·정확한 분모/수치·소스 해시·원시 JSON 경로·재현 명령은 아래 시뮬레이션 보고서가 정본이다. 테스트 무음/저장 격리·성능 프로파일링 중단 유지. 보존 필터1·2·3·4, 코드/위키 로컬 저장만·커밋/푸시 없음.

## 2026-10-14 후보 v2 1차 밸런스 조정

- 사용자 “밸런스를 맞춰보자 일단”/“진행해” 승인으로 사막 기마·독침·나일의 분노 후보만 조정했다. 정수 쌍 드로우/고정+1 강화, 직접 피해 보상과 독 반복 피해의 동시 검증을 사용한다. 일반 게임/세이브 수치는 유지했다.
- 기존 전투720쌍에 새 패배가 없으며, 합성8×HP/4×공격 압박의 동결240쌍에서는 원본과의 잔여HP 차이·승패 편향이 줄었다. 즉시 효과의 기존 이상치4쌍은 없어졌지만 선택대기8쌍·다른 영웅의 큰HP 차이·시그니처/보스/팀 조합은 여전히 미해결이다. 합성 압박의 승률을 실제 게임 승률로 해석하지 않는다.
- 나일의 분노 실제 원본은1강에서 랜덤 피해65 유지/독10→11이다. 예전 주석65→72는 오판이어서 수정했다. 독침도 옛 helper가 아니라 최종v3 독15를 기준으로 검토했다.
- 조정표·전후 분모·수치·동결 원시 경로·규칙 검사는 아래 v2 문서가 정본이다. 보존 필터1·2·3·4, 로컬 저장만·커밋/푸시 없음·테스트 무음/격리·성능 측정 중단 유지.

## 2026-10-15 실제 작은 정수 체계 전체 적용

- 사용자 “남은 것들도 전부 적용해”/“진행해” 승인으로 비교 후보에만 있던 체계를 실제 기본 플레이에 연결했다. 카드216종0/1강·영웅HP100·몬스터192종의 일반/정예/보스/시그니처/페이즈/소환·유물/이벤트/상점/휴식/튜토리얼·저장 복원을 전환했다. 에너지/장수/속도/기간/골드/퍼센트는 일괄 나누지 않는다.
- 옛 저장의 HP는 메모리 사본에서 한 번 환산하며 새 저장에 combat_unit_version2를 기록한다. 미지원 미래 버전은 원본을 지우지 않는다. 카드 단위/적 희생 비용은 복제에서 사라질 수 있는 메타만 의존하지 않고 필드로 보존한다.
