# 정량 성과의 포트폴리오 근거

## Summary

사용자 요청으로 문서·Git·원시 측정값을 조사하고 [정량적 문제 해결 사례](../../../../portfolio/정량적_문제해결_사례.md)에 정리했다. 포트폴리오 본문에 반영한 것이 아니라 검토용 후보 문서다. 실제 게임 코드·기존 작업·Git 원격은 바꾸지 않았다.

## Context

[[챕터-자동-플레이와-성능-측정]]의 과거 성능 자료와 [[런-몬스터-중복과-조우-선택]]의 선택 시뮬레이션을 근거로 쓴다. 일반 성능 조사 자동 재개 금지는 유지한다. 후속 사용자 명시 요청에 한해 세 사례의 격리 신규 측정·실제 캡처를 수행했다. 생성 수나 메서드 wall time을 게임 FPS로 해석하지 않는다.

## Details

### 후속 증거 준비 — 현재 정본

- [증거 패키지](../../../../portfolio/evidence/README.md)에 실제 Godot 컴포넌트 A/B·반복별 JSON/CSV·로그·전후 PNG·그래프·스크립트·Git 타깃/공통 런타임/자산 지문을 보존했다. 현재 브랜치/기존 dirty/자산은 지문 대조로 보존 확인하며 게임 코드는 수정하지 않는다.
- 카드·손패는 역사적 컴포넌트를 같은 의존성에 올린 별도 폴더 비교이지 전체 옛 빌드가 아니다. ABBA 교차·cold/warm 분리·픽셀 동일/상태 회귀를 확인했다. 조우는 같은 실제맵/seed/경로를 세 정책 정순/역순으로 실행해 sequence까지 재현했다. 새 수치·분모·검사 결과는 위 정본 보고서에만 기록한다.
- 과거 카드 시간과 신규 값이 달라 신규를 정본에 썼다. focus 미통제 표본·후반 지연·종료 뒤 관측한 배터리/저전력 설정·과거 환경 미기록을 한계로 보존하고 단일 원인은 단정하지 않는다. 모든 표본 유지/민감도 별도·전체 FPS/GPU/메모리/재미 개선 주장 금지.
- 조우 캡처는 실제 Godot가 측정 JSON을 읽어 출력한 대시보드이며 전투 플레이·Profiler가 아니다. 손패 캡처도 영웅 미등록의 비활성 fixture다. 첫 격리 설정 오류는 guard가 차단했고 실패/종료 경고 로그를 삭제하지 않았다.
- [이전 조사 원문](../../../../portfolio/정량적_문제해결_사례_이전조사.md)은 보존본이며 아래 초기 이력도 당시 범위로만 해석한다. 신규 자료는 ignored log가 아닌 docs/portfolio/evidence에 있으나 Git manual로 아직 커밋·푸시하지 않았다. 포트폴리오 본문 반영 없음.

### 초기 조사 이력 — 후속 신규 측정과 구분

- 추천3건: 당시 warm 카드갱신 메서드 시간, 오늘 손패 재갱신 루트 생성 수, 당시 조우선택 반복 감소. 첫두건은 같은PR의 다른경로라 속도개선율을합산하지않는다. 수치·계산식·각기여·커밋·raw경로는 위 정본에만 기록한다.
- 손패는 afe1bee/1710ca6의 해당 battle_scene 스크립트만 git archive로 임시분리하고 현재 동일의존성에서실행했다. 고정5장·초기생성제외·30갱신1시퀀스/arm에서 신규루트150→0·삭제대기요청150→0을2026-10-22에측정했다. 로그/harness/컴포넌트는 ignored `log/portfolio/2026-10-22/`에보존했다. 당시전체빌드·실제메모리측정이아니다.
- 조우 정본IuYmlU JSON의개별sequence부터분모/재등장/직전반복을재집계해기존집계와일치·소스29지문현재일치확인. 이는새시뮬레이션이아니다. 카드시각벤치JSON은요약분위수만있어개별샘플부터CI재계산은불가하다.
- 반복아트/하트CPU는전후포커스차이·작은표본때문에보류목록으로분리했다. startup/prefetch는비용이동을총로딩단축으로기재하지않고, GPU0ms/미제작음원경고/테스트개수를성능·오류율개선으로만들지않는다.
- 사용자문제제기·우선순위·승인과AI분석/구현/실행을구별한다. Git Author만으로사용자수작업기여를확정하지않고,확인불가한기여비율은쓰지않는다. 당시실측/시뮬레이션·오늘신규측정·코드산출·재계산·미측정을분리한다.
- 원시파일은로컬ignored산출물이므로다른컴퓨터/외부제출에는별도증거보존이필요하다. old/new자산·동등입력·포커스·할당계측없는전체FPS/메모리/수동작업시간개선율은미작성이다.
