# 런 몬스터 중복과 조우 선택

## Summary

사용자는 한 플레이 안에서 몬스터 중복을 최소화하는 방향을 승인했다. 초기 분석 당시에는 이력 없는 층별 가중 랜덤이었고, 이후 난도 내 미등장 우선/연속중복 방지/최소 재사용·저장 복원을 적용했다. 초기 원인/검토안은 당시 기록이며 아래 적용 결과가 현재 상태다.

## 초기 분석에서 코드로 확인한 사실

- `autoload/game_manager.gd:769`의 일반 전투는 액트에 배정된 신화의 `normals.encounters()`에서 뽑는다. 같은 신화의 일반 풀은 액트별 독립 풀이 아니지만 기본 챕터1은 그리스/이집트/북유럽을 섞어 각 액트에 하나씩 배정한다(`:200`, `:735`). 따라서 기본 런에서 동일 신화가 모든 액트에 반복된다는 설명은 틀리다. 챕터2는 사용 가능한 신화가 부족하면 순환 채우는 fallback이 있다.
- 6개 `resources/enemies/*/*_normals.gd`의 조우 표를 정적으로 집계한 결과, 신화별 조합10/종20/출현슬롯24, 같은 종을 복수 배치한 조합3개다. 서로 다른 조합 사이에는 동일 factory종이 겹치지 않는다. 이 집계는 전투 출현 빈도 시뮬레이션이 아니다.
- `_pick_weighted_encounter`(`game_manager.gd:792`)는 거리 기반 가중치만 사용하며 이미 선택한 조합/몬스터를 제외하지 않는다. 정예도 `elites.pick_random()`(`:876` 부근)으로 이전 종류를 제외하지 않는다.
- `MapGenerator.FLOORS=15`(`autoload/map_generator.gd:8`)인데 일반 조우 진행도는 `floor_idx/9.0`을0~1로 제한한다. 층 인덱스9 이후 target9가 고정되어10조합 중 인덱스6~9의4개에만 양의 가중치가 남는다. 일반전이 계속되면 이 고정 후보에서 다시 뽑는다. 13은 휴식/14는 보스라 후반 모든 층이 일반전이라는 의미는 아니다.
- 동일한 인원수 흐름(1/2/1/2/3/3/3/4/3/2)은 여섯 신화에서 같지만, 이것만으로 AI/의도/그림까지 같은 몬스터라고 결론내리지 않는다.

## 동작 과정 — 초기 검토안 (이후 승인)

> [!question] 초기 검토와 구현의 경계
> 초반/중반/후반 난도 자격을 유지하면서 미등장 조합 우선 → 같은 조합 연속 금지 → 풀이 소진될 때만 가장 적게 만난 조합을 재사용하는 방향을 권장한다. 일반 종은 기본1회, 부족한 경우만2회라는 목표를 두되 실제 경로/조우 가능 수로 달성 가능성을 검증해야 한다. 정예도 미등장 우선과 연속 중복 방지를 적용하고, 보스는 기존 신화/액트 구성을 보존한다.

한 전투 안의 무리(쥐3마리 등)는 전투 재등장과 구분한다. 동일종 다수 편성은 의도된 역할일 수 있으므로 전면 금지하지 않는다. 다른 조합에 나온 같은종도 과거 이력에 포함하되, 처음 보는 몬스터를 만들겠다는 이유로 초반에 후반용 적을 투입하지 않는다.

조우 이력은 실제 선택/확정된 전투만 기록하고 미방문 맵 분기로 소진시키지 않아야 한다. 이 요구는 아래 후속 구현에 반영했고, 일반종 최대2회는 절대 상한 대신 후보 부족 시 최소 재사용으로 정리했다.

## 실제 사용 예시

이집트의 스카라베2마리를 한 전투에서 만나는 것은 무리 구성이다. 다음 일반전에서 같은 스카라베2마리 조합을 또 뽑는 것은 반복 조우다. 현재 조합들이 서로 다른 종을 사용하므로 조합 재사용을 줄이는 것만으로도 종의 전투 간 반복을 줄일 여지가 있다.

## 실무 고려사항

- 신뢰도 높음: 이력 없는 선택과15층/9층 기준 불일치. 추론: 이 구조가 반복 체감을 높일 수 있다. 미측정: 실제 플레이 경로별 반복률/재미/난도 영향, 패턴 중복률.
- 재미 가설은 발견과 공략 변화다. 후속에는 동일 시드/경로의 연속동일조합 횟수·다른전투에서의 종 재등장 횟수·고유조합/전투 수·난도자격 위반·풀소진 횟수를 비교하고, 사람에게 '다음 전투의 새로움/다른 공략이 필요했는가'를 묻는다. 자동 조우 다양성이 재미를 증명하지는 않는다.
- 초기에는 원인 설명과 제안만 기록했고, 이후 아래 승인 구현으로 이어졌다. 기존 카드 밸런스 결과를 조우 다양성 근거로 사용하지 않는다.

## 흔한 오해

- 전체 도감192종이 한 액트에서 모두 선택되는 것은 아니다.
- 중복0을 위해 난도/저작 조합을 무시한 완전 랜덤 편성을 권장하지 않는다.
- 동일 종의 무리 배치와 동일 전투 조합의 재등장은 다른 제한이다.

## 2026-10-17 승인 후 실제 적용

- 실제 GameManager에 일반/정예 이력 선택을 연결했다. 양의 난도 가중치 창 안에서 직전 제외→최소 조합 사용→최소 종 재등장→가중 랜덤 순으로 선택한다. 일반 진행도는15층 맵의 마지막 일반 가능 층12에 맞췄다. 후보가1개뿐이면 진행을 막지 않으며 보스/적수치/기존 무리는 그대로다.
- 새런 초기화·액트 이력 유지·이벤트 공용·미방문 분기/보스 미소비, 신화 순서와 이력 저장/복원을 적용했다. 옛 저장에는 과거 이력이 없으므로 빈 이력부터 시작하며 전역 RNG 자체의 저장 변경은 아니다.
- 전용46검사(`IuYmlU`)에 실제 격리 SaveManager 파일 왕복을 포함했다. 3600고유 액트 경로(6신화×3액트×100시드×좌/우)의 동일 입력3방식 대조에서 일반 조합 재등장7576→833/27774전투(89%감소), 연속일반4595→0, 정예재등장295→0/3438·연속286→0, 새난도창 위반0. 12층 가중치만 바꾸면 일반재등장7591로 줄지 않아 이력선택의 효과를 구별했다.
- 신규2984/3600경로는 일반 조합 반복0, 관측된 동일 조합 최대2회지만 모든 이벤트/경로의 하드캡은 아니다. 종 재등장은16823/58080→1635/55904의 종-전투 방문 단위다. 같은 전투 내부의 복수마리는 중복에서 제외한다.
- 최종 전용46/live1672/튜토리얼312/희생99/구회귀4161 통과·실패0, SCRIPT ERROR/ERROR/WARNING0·소스29지문 일치. 초기 동적 노드의 typed Array fixture 오류는 수정하고 필수검사 수 검증으로 중단을 최종 통과에서 제외했다.
- 정본 [구현 규칙·평가 계약·분포 변화·원시 근거](../../../../game_design/encounter_diversity.md). 몬스터 수치는 같지만 일반 조합 평균 인덱스4.94→4.59로 노출 빈도가 달라져 전체 캠페인 난도 불변/재미 개선을 확정하지 않는다. 카드 덱 실험 당시 지문과 새 조우 규칙의 근거를 구별한다.

## 제출 상태 — 2026-10-17

사용자 명시 요청으로 카드 시너지/방어 수명/희생 보상/밸런스 평가와 함께 `07d36ff`에 커밋하고 `origin/content/archetype-synergies`로 푸시했다. [PR #239](https://github.com/l980l/stsl/pull/239)는 `main` 대상이며 에이전트는 머지하지 않았다. 위의 커밋푸시 없음은 구현 당시 기록이다. 별도 아트/실험/raw/실행 로그는 제외했고, 이번 제출 결과 위키 기록도 같은 요청 범위로 커밋·푸시한다. 기본 Git manual 정책은 유지한다.
