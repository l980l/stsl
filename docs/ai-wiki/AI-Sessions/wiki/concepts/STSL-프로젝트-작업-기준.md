# STSL 프로젝트 작업 기준

## Summary

현재 수정본은 `/Users/kimkwanhyeon/orca/workspaces/stsl/pearlfish`다. 다운로드 폴더에서 옮긴 뒤 이 작업 폴더에 튜토리얼과 UI 최종 수정을 적용했다. 이후 작업은 이 폴더를 기준으로 한다.

## 원리

- Godot 프로젝트이며 `project.godot`을 연다. 검증에 사용한 설치 엔진은 Godot 4.7.2 mono다.
- 영웅 6명은 나폴레옹·클레오파트라·이순신·잔다르크·칭기즈칸·무사시다.
- 각 영웅은 자신의 덱·손패·에너지를 가지며 기본 차례 시작 에너지 3, 기본 드로우 4다. 행동 순서는 속도 기반 ATB다.
- 모든 영웅은 기본 최대 HP 1,000. 2026-10-08 새 시작덱을 10장으로 적용했다. 기존 런의 덱 장수는 유지한다. [[카드-구성-개편안-검토상태]].

## 동작 과정

1. 위키의 인수인계와 해당 주제를 읽는다.
2. 현재 소스·Git 상태를 확인한다. 오래된 문서나 테스트 숫자를 최신 실행 결과로 간주하지 않는다.
3. 구현·검증 후 변경과 미해결 사항을 해당 주제와 인수인계에 반영한다.

## 실무 고려사항

- 사용자는 LFS를 쓰지 않기로 했다. 아트·오디오 일부는 `.gitignore`로 제외되므로 Git 체크아웃만으로 모든 로컬 에셋을 복원할 수 있다고 가정하지 않는다.
- 위키의 평상시 Git 정책은 `manual`이다. 사용자의 명시적 요청으로 튜토리얼 변경을 푸시했고 PR #235는 main에 머지됐다. 이후 자동 커밋·푸시를 허용하는 정책으로 바뀐 것은 아니다.
- 2026-10-04 초기에 현재 작업 폴더의 프로젝트 파일 대부분이 미추적이었으나, 13:48에 사용자의 요청으로 아래 Git 연결을 완료했다. 초기 상태와 현재 상태를 혼동하지 않는다.
- 게임 테스트는 저장 경로가 분리된 임시 프로젝트에서 실행한다. 진행·일반 런 파일을 쓰는 테스트를 실제 사용자 저장 폴더에 실행하지 않는다.
- 챕터 완주·프레임 측정은 [[챕터-자동-플레이와-성능-측정]]의 새 격리 실행기를 사용한다. 과거 `/tmp` 프로젝트가 남아 있더라도 설정 파일 존재를 가정하지 않는다.
- 테스트 로그·캡처는 임시 경로일 수 있다. 중요한 검증 결과는 날짜와 범위를 프로젝트 문서에 남긴다.

## 현재 Git 연결 (2026-10-04 13:48)

- 원격 `origin`: `https://github.com/l980l/stsl.git`.
- 현재 작업 브랜치: `work/pearlfish`. 기준 HEAD는 PR #235가 머지된 `afe1bee2dc101a16bd70835b67893b47489ddce5`이며 `origin/main`과 일치한다.
- pull 기준은 `origin/main`. 이 프로젝트 로컬 설정 `push.default=current`로 일반 `git push`는 `work/pearlfish`를 대상으로 한다. 새 원격 작업 브랜치는 첫 실제 push 때 생성된다. main에 바로 push하지 않는다.
- 여기서 직접 fetch와 `git push --dry-run`에 성공했다. 임시 저장소로 복사할 필요가 없다. 이번 연결 작업 자체로 추가 커밋·실제 push는 하지 않았다.
- Orca의 기존 worktree·`.git` 포인터를 유지했다. 저장소의 새 worktree 기준은 `origin/main`으로 설정했다. 다른 main worktree의 초기 브랜치는 변경하지 않았다.
- 최초 이력은 `backup/pearlfish-initial-20261004`와 프로젝트 루트 `git-handoff/orca-before-link-20261004.bundle`에 보존했다. 파일을 덮어쓰지 않는 mixed reset으로 기준 이력·인덱스만 연결했다.
- 연결 전후 3,657개 기존 파일의 목록·크기·수정시각 지문이 같았다. 로컬에 없던 원격 README만 새로 복원했다. 게임 코드 차이는 없다.
- 추적 파일 1,036개와 기존 미추적 파일 364개를 구별했다. 미추적 에셋·초안·UID 등을 임의로 추가하지 않았다. `git add .` 전에 반드시 포함 범위를 검토한다. 최신 위키 변경은 미커밋 상태로 남아 있다.

## 2026-10-11 커밋·푸시 요청

- 사용자가 현재까지 작업의 커밋·푸시를 명시적으로 승인했다. 카드 v3 개편·실제 캠페인 봇·버그 수정·카드 UI 최적화·회귀 검사·검증 문서와 위키를 포함한다.
- 대상은 기존 `origin`의 `work/pearlfish`이며 `main`에 직접 올리거나 PR 생성·머지하지 않는다. 이번 push 성공 후 upstream은 `origin/work/pearlfish`로 맞춘다. 위의 2026-10-04 `origin/main` tracking 설명은 당시 상태다.
- 로컬 아트·오디오·로그·raw·임시 초안·이번 작업과 무관한 기존 미추적 파일은 제외한다. LFS 미사용·평상시 Git manual 정책은 유지한다.
- 성능 미해결 범위는 [[챕터-자동-플레이와-성능-측정]]에 기록한다. 원격 반영 여부와 커밋 ID는 실제 Git 조회로 확인한다.

## 흔한 오해

- 다운로드 폴더의 프로젝트가 최신본이라고 가정하면 작업을 놓친다.
- 전체 단위 테스트 통과는 카드·몬스터 밸런스나 그래픽 품질의 증명이 아니다.
- 개인 AI 위키는 이 프로젝트 작업 중 갱신하는 기억이다. 앱이 닫혀 있어도 계속 수집하는 서비스는 아니다.
