# 튜토리얼 구현과 검증

## Summary

기초 전투·카운터와 차지·상태이상과 독의 3개 레슨을 수정하고 검증했다. 팀빌딩 레슨은 구현하지 않았고 선택 화면의 미완성 항목은 숨겼다.

## 원리

단계별 카드와 턴 종료 제한을 UI·전투 로직 양쪽에서 적용한다. 효과 처리 중 추가 입력을 막고 학습용 확정 치명타 이외의 확률 치명타를 억제해 단계가 건너뛰지 않게 한다. 완료 기록만 영구 진행에 저장하며 일반 런 저장은 보호한다.

## 동작 과정

1. 레슨 선택 → 지정 영웅·덱·적 생성 → 안내 클릭 → 단계별 전투.
2. 승리와 레슨 마지막 단계가 완료되면 완료 기록 저장.
3. 중도 종료·패배는 완료 처리하지 않고 레슨 선택으로 복귀. 이후 재도전 가능.
4. 씬을 떠날 때 드래그·커서·전투 상태를 정리하고 연출이 바꾼 게임 속도를 복원.

| 2026-10-04 추가 피드백 후 | 144×30, 글자 13으로 추가 축소. 통합 검사 299 통과 / 0 실패 | 13개 언어의 크기·중앙 기준 위치·비겹침 검사 65개 추가. 최종 렌더링 화면은 미검수 |

| 2026-10-04 커밋 준비 | 전체 테스트 1,606 통과 / 0 실패 | 격리된 저장 경로에서 실행. 도감 왼쪽 배치의 312개 통합 검증은 직전 실행 결과 |

통합 검사는 두 카드 디자인의 3개 레슨, 잘못된 입력, 연속 입력, 종료·패배 후 재도전, 완료 기록 재로드와 일반 런 저장 보존을 포함한다. 제한된 macOS 환경의 인증서 조회 오류는 별도로 출력됐으며 게임 스크립트 오류와 구별한다.

## 종료 버튼 변경

2026-10-04 사용자가 버튼이 우측 메뉴와 너무 붙고 크다고 지적했다. 처음에는 248×42 → 160×32 → 144×30으로 축소해 중앙에 배치했으나, 최신 작업본 화면을 확인한 사용자가 그 위치를 거부하고 도감 왼쪽·동일 가로 세로 크기를 명시했다.

현재 배치는 **도감 왼쪽 40×40**, 도감과 10px 간격, 상단 10px이다. 1920×1080 기준 `(1770, 10, 40, 40)`. 도감과 동일한 우측 상단 앵커와 `IconButton` 스타일을 사용한다. 정사각형 크기에 맞춰 기존 복귀 화살표 에셋을 재사용하고, 번역된 ‘레슨 선택으로’ 문구는 툴팁에 유지한다. 중앙 버튼 배치는 더 이상 현재 설계가 아니다.

> [!warning] 실행본 확인 필요
> 추가 스크린샷은 옛 우측 상단 배치와 일치했고, 다운로드 폴더의 드라이버에는 248×42 설정이 남아 있었다. 최신 수정은 `pearlfish`에 있다. 실제 실행 경로는 확인하지 못했으므로 옛 프로젝트 또는 이전 실행 인스턴스라는 원인은 아직 추정이다. 버튼이 그대로라면 코드 재수정보다 실행 프로젝트와 재시작 여부부터 확인한다.

이후 사용자가 최신 작업본을 실행했다고 말하며 중앙 버튼이 표시되는 새 스크린샷을 제공했다. 그 화면에서는 당시 변경이 반영된 것이 확인되었다. 위 경고는 이전 실행본 혼동의 재발 방지를 위한 기록이다.

## 실무 고려사항

기능 검증과 렌더링 화면 검수는 별개다. 실제 창에서 버튼 위치·문자 잘림·카메라 상태를 확인하는 시각 검수는 남아 있다. 문서의 현재 상태와 최근 테스트를 확인한 뒤 변경한다.
