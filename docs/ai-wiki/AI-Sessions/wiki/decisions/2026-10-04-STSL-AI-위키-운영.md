# STSL AI 위키 운영

## Summary

STSL 프로젝트 안의 `docs/ai-wiki`를 개인용 Obsidian AI 위키로 사용한다. 주요 작업 전에 관련 내용을 읽고 의미 있는 결과가 나오면 갱신한다. 커밋·푸시는 자동 실행하지 않는다.

## Context

사용자는 2026-10-04 프로젝트 진행사항이 AI 위키에 저장되고 있는지 물었고, 없다면 저장하도록 요청했다. 기존 기록은 `docs`에 있었으나 프로젝트·상위 경로에 `.ai-wiki.yml`이 없었다. 사용자가 후속 답변으로 개인 범위와 기본 저장 위치를 지정했다.

## 검토한 대안

| 대안 | 장점 | 단점 | 채택 |
|---|---|---|---|
| 프로젝트 내 개인용 `docs/ai-wiki` | 프로젝트와 함께 이동, 다음 세션이 찾기 쉬움 | Obsidian에서 별도 Vault로 열어야 함 | O |
| 팀 공용 위키 | 협업용 공유 운영 | 사용자가 지정한 개인 범위와 다름 | X |
| 중앙 개인 Vault / Notion | 기존 중앙 지식과 통합 | 목적지 미지정, 다른 프로젝트와 섞일 수 있음 | X |

## 선택 근거

사용자 지정: “개인용이고 저장 위치는 기본 저장 위치로 해.” 앞서 제안한 기본 위치는 `docs/ai-wiki`다. 사용자에게 알린 자동 커밋·푸시 없음과 기존 커밋 보류를 유지한다. 루트 설정은 `scope: personal`, `git.commit_mode: manual`, `push: false`, `track_raw: false`다.

## 되돌리는 조건

사용자가 팀 공유, 다른 Vault 경로, 또는 다른 Git 기록 방식을 지정하면 변경한다. 그 전에는 중앙 Vault나 외부 서비스로 자료를 자동 복사하지 않는다.
