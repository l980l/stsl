## 신(Divine) 등급 카드 상세

### 징기스의 분노 — 누적 강화형 진화

| 강화 | DMG ALL | 히트 수 | 유니크 보조효과 |
|---|---|---|---|
| 0강 | 60 ALL | × 2 | 없음 (총합 120 ALL) |
| 1강 | 70 ALL | × 2 | 없음 (총합 140 ALL) |
| 2강 | 79 ALL | × 2 | 모든 적에 POISON 2 부여 (총합 158 ALL + 독) |

**의도**: 몽골 기병 아키타입의 집약 카드. `DMG × 2` 표기는 무사시 이도류와 같은 처리 방식 (hit_count 파라미터). 2히트로 독 트리거 2회 — 클레오파트라 독침 반격 크로스 시너지에 특히 유효. 2강에서 POISON 2 ALL 추가 → 독 아키타입 연동 폭발.

### 수치 조정 근거

- **전체 공격(ALL) 베이스**: 단타의 50~60%. 기마 돌격 50 / 화살 세례 55 / 초원의 폭풍 80. 코스트 대비 총합 피해는 전체 적에 균일 분배라 단타보다 효율이 높음.
- **0코 카드 비중**: 정찰(0코 DRAW), 기습(0코 DMG), 정복자의 야망(0코 DMG+DRAW) 3장. 기동 아키타입 특성상 0코가 많아야 한 턴 다장 플레이 가능. 다만 0코 공격 총합 피해는 의도적으로 낮게 유지.
- **만리 원정**: 카드 사용 횟수 × 30 BLOCK은 한 턴 기동 5장 시 150으로 강력. 단, 5장 플레이가 선행되어야 하므로 후반 카드 — 코스트 1 기술로 밸런스.
- **대칸의 명령**: 이번 턴 전체 코스트 0 효과는 코스트 2 LEGENDARY 효과로 정당화. DRAW 3 + 코스트 0 → 당겨온 카드 전부 무료. 2강 다음 턴 ENERGY+1까지 추가로 다음 턴 가속.

### 기존 영웅과 차별화

| 영웅 | 공격 방식 | 칭기즈칸과 차이점 |
|---|---|---|
| 나폴레옹 | 1~2코 고피해 단타 + MORALE 소모 | 칭기즈칸은 0~1코 저피해 다수. 에너지가 아닌 카드 수 기반 |
| 이순신 | FORMATION_BLOCK 팀 방어 | 칭기즈칸은 방어 카드 최소. 공격 일변도 |
| 클레오파트라 | 독 장기전 | 칭기즈칸은 독 부여도 하지만 즉각 전체 피해가 주력 |

### 크로스 시너지 연동

- **칭기즈칸 × 클레오파트라 — "약탈과 독"**: 칭기즈칸의 전체 공격(독화살·징기스의 분노)이 적에 독 스택 부여 → 클레오파트라의 독 시너지(독침 반격·포이즌 버스트) 트리거. 독 부여 카드 사용 후 클레오파트라 전환 시 즉각 독 폭발.
- **천군만마 렐릭 + 기동 루프**: 한 턴 5장+ 목표 → 대칸의 명령 코스트 0 전환으로 쉽게 달성. DMG +15% 발동.
- **포위 전술(WEAK ALL)** → 나폴레옹 황제의 명령(DMG ALL) 연계 시 약화 보정 적용.
