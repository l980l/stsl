# 챕터 2 중국 신화 이벤트 기획 v1

## 이벤트 풀링 구조

`_build_event_pool()` match에 `"chinese": return _EventsChinese.build_pool()` 분기 추가. `events_chinese.gd` 단일 파일에 10종 통합. Act 무관하게 중국 신화 런이면 이 풀 사용.

사용 가능한 EventChoice.EffectType: `NONE, GOLD, HEAL, DRAW_UP, REMOVE_CARD, ADD_RELIC, ADD_HERO, ADD_RELIC_GAMBLE`

---

## 이벤트 목록 (10종)

---

### 1. 서왕모의 복숭아나무

> 곤륜산 깊숙이 복숭아나무 한 그루가 서 있다. 3000년에 한 번 열린다는 불로불사의 복숭아가 탐스럽게 달려 있다.

**선택지**:
| 레이블 | 효과 | 비용 |
|---|---|---|
| 복숭아를 따 먹는다 | MAX_HP +40 (팀 전체 랜덤 1명) | NONE |
| 그냥 지나친다 | NONE | NONE |

**기획 의도**: 무료 최대 HP 증가. "불로초" 테마. 안전한 좋은 선택지로 이벤트 참여를 유도.

---

### 2. 손오공의 도전

> 원숭이 한 마리가 나타나 우쭐대며 말한다. "내 여의봉을 피하면 뭔가 주지. 피하지 못하면 대가를 치러야 해."

**선택지**:
| 레이블 | 효과 | 비용 |
|---|---|---|
| 도전을 받아들인다 | GOLD +100 OR HP -30 (50/50) | NONE |
| 거절한다 | NONE | NONE |

**기획 의도**: 고위험 도박 선택지. 골드가 많이 필요하거나 HP 여유가 있을 때 선택. "한국 산신령 내기"와 유사하지만 보상이 더 큼.

> 구현 메모: 50/50 랜덤 결과는 `ADD_RELIC_GAMBLE` EffectType 응용 or `gamble_good_effect/gamble_bad_effect` 필드로 처리. 불가 시 GOLD +70 고정으로 단순화.

---

### 3. 당삼장의 경전

> 서역에서 돌아온 스님이 경전을 펼쳐 보인다. "이 경전을 읽으면 깨달음을 얻을 수 있소. 다만 시간이 걸리지요."

**선택지**:
| 레이블 | 효과 | 비용 |
|---|---|---|
| 경전을 탐독한다 | DRAW_UP +1 (영구) | NONE |
| 감사히 거절한다 | NONE | NONE |

**기획 의도**: 무료 영구 카드 드로우 증가. 안정적인 좋은 선택지. 모든 빌드에서 유용하여 이벤트 참여 명확.

---

### 4. 팔선(八仙)의 연회

> 하늘에서 내려온 여덟 신선이 잔치를 열고 있다. 그들이 당신을 바라보며 초대의 손짓을 한다.

**선택지**:
| 레이블 | 효과 | 비용 |
|---|---|---|
| 잔치에 참여한다 | HEAL +50 | GOLD -40 |
| 술을 가져간다 | GOLD +60 | NONE |
| 그냥 지나친다 | NONE | NONE |

**기획 의도**: 3선택지 이벤트. 자원 종류에 따라 최적 선택이 갈림. HP 위기팀 → 치유 선택, 골드 여유팀 → 골드 거절.

---

### 5. 천계 시장(天界 市場)

> 구름 위 하늘 시장에 도착했다. 선인들이 기이한 물건을 팔고 있다.

**선택지**:
| 레이블 | 효과 | 비용 |
|---|---|---|
| 고가 유물을 구입한다 | ADD_RELIC | GOLD -80 |
| 불량품을 집어든다 (도박) | ADD_RELIC_GAMBLE | GOLD -30 |
| 그냥 구경만 한다 | NONE | NONE |

**기획 의도**: 렐릭 획득 이벤트. 안전한 고가 구매 vs 저가 도박. 골드 상태에 따라 분기.

---

### 6. 용왕의 용궁 초대

> 바다 아래에서 청아한 빛이 올라오며 용왕의 사자가 나타난다. "왕께서 당신을 초대하셨습니다. 용궁 보물창고를 열어주시겠다고 하셨습니다."

**선택지**:
| 레이블 | 효과 | 비용 |
|---|---|---|
| 초대에 응한다 | GOLD +90 | HP -25 |
| 보물 하나만 요청한다 | ADD_RELIC | HP -40 |
| 정중히 거절한다 | NONE | NONE |

**기획 의도**: 3선택지 고위험 보상. HP를 소비해 골드 or 렐릭 선택. HP 여유팀 전용.

---

### 7. 여동빈(呂洞賓)의 검술 수련

> 검을 들고 있는 노인이 당신의 팀을 보더니 눈빛이 날카로워진다. "내 검술을 전수해드릴까요? 잠재력이 보이는군요."

**선택지**:
| 레이블 | 효과 | 비용 |
|---|---|---|
| 수련을 받는다 | REMOVE_CARD (랜덤 1장 제거) | NONE |
| 감사히 거절한다 | NONE | NONE |

**기획 의도**: 무료 카드 제거(덱 정제). 약한 카드가 많을 때 매력적. 스타터 카드 제거 용도.

---

### 8. 옥황상제의 사자

> 황금 갑옷을 입은 천사(天使)가 하늘에서 내려온다. "황제 폐하의 명으로 당신들의 투쟁에 개입하겠다."

**선택지**:
| 레이블 | 효과 | 비용 |
|---|---|---|
| 사자의 도움을 받는다 | ADD_HERO | NONE |
| 일의 귀찮음을 피한다 | GOLD +50 | NONE |

**기획 의도**: 영웅 영입 or 골드 선택. 팀이 가득 차 있으면 자동으로 골드만 선택 가능. 팀 구성 전략과 연계.

---

### 9. 신농(神農)의 약초

> 황소 머리를 한 신인이 약초를 잔뜩 지고 있다. "이 약초를 맛보시오. 치료도 되고, 독도 될 수 있소이다."

**선택지**:
| 레이블 | 효과 | 비용 |
|---|---|---|
| 약초를 먹는다 | HEAL +40 | HP -15 *(독 가능성)* |
| 좋은 약초만 고른다 | HEAL +20 | GOLD -40 |
| 거절한다 | NONE | NONE |

**기획 의도**: 위험한 치유 vs 안전한 유료 치유 vs 포기. HP -15는 독 복용 리스크 표현. 역설적으로 HP 낮을수록 위험한 선택이 될 수 있음.

---

### 10. 봉황(鳳凰)의 부활

> 불꽃 속에서 아름다운 새가 솟아오른다. 그 깃털 하나가 당신 앞에 떨어진다.

**선택지**:
| 레이블 | 효과 | 비용 |
|---|---|---|
| 깃털을 가져간다 | ADD_RELIC_GAMBLE *(봉황 렐릭 or 저주 렐릭)* | NONE |
| 깃털을 바람에 돌려보낸다 | HEAL +30 | NONE |

**기획 의도**: 도박 vs 안전한 치유. 봉황의 부활 테마 — 좋은 것과 나쁜 것이 공존. 두 선택지 모두 이익이지만 위험 선호도에 따라 갈림.
