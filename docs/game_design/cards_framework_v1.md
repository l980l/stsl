## 1. 5등급 정의

| 등급 | 영문 ID | 강화 한도 | 역할 |
|---|---|---|---|
| 일반 | COMMON    | **0강 (강화 불가)** | 기본 동작 카드. 시작덱 포함. 저비용이지만 수치 고정. |
| 희귀 | UNCOMMON  | **1강**            | 덱빌딩 기초. 적당한 비율 상승으로 안정적 성장. |
| 특급 | RARE      | **1강**            | 아키타입 핵심 카드. 강화 시 명확한 차이. |
| 전설 | LEGENDARY | **2강**            | 영웅 덱의 대표 카드. 2강 시 압도적 수치. |
| 신   | DIVINE    | **2강**            | 전설 수치 + 강화 단계별 유니크 보조효과 (진화형). |

**등급 분포 가이드라인** (영웅당 15장 기준):
- 전설 + 신 합산 **2~3장 초과 금지**
- 일반 카드는 시작덱에 포함되므로 최소 4~6장 권장

**실제 분포 (v1 기획 완료 기준)**:

| 등급 | 나폴레옹 | 클레오파트라 | 이순신 |
|---|---|---|---|
| COMMON    | 4 | 4 | 5\* |
| UNCOMMON  | 4 | 4 | 4 |
| RARE      | 5 | 4 | 4 |
| LEGENDARY | 1 | 2 | 2 |
| DIVINE    | 1 | 1 | 2 |
| **합계**  | **15** | **15** | **15+2†** |

> \* 이순신 COMMON: 방패·역공(시작덱) + 거북선 방패·해군 기동·기타
> † ⚠️ **이순신 이슈**: LEGENDARY 2 + DIVINE 2 = **4장**으로 가이드라인(2~3장) 초과. DIVINE 1장 → RARE 강등 또는 LEGENDARY 1장 축소 검토 필요. 사용자 결정 대기.

## 2. 강화(Upgrade) 규칙

### 2-1. 수치 효과 — 등급별 백분율, 총합 누적

강화 결과 = **베이스 × (1 + rate × upgrade_level)**

| 등급 | rate | 1강 결과 | 2강 결과 |
|---|---|---|---|
| COMMON    | — | — | — |
| UNCOMMON  | 10% | 베이스 ×1.10 | 없음 |
| RARE      | 12% | 베이스 ×1.12 | 없음 |
| LEGENDARY | 14% | 베이스 ×1.14 | 베이스 ×1.28 |
| DIVINE    | 16% | 베이스 ×1.16 | 베이스 ×1.32 |

> **주의**: 2강은 `1강 수치 × rate` 추가가 **아님**. 항상 **원본 베이스 기준**으로 계산.
>
> 전설 예시 (베이스 80):
> - 1강: 80 × 1.14 = **91**
> - 2강: 80 × 1.28 = **102** (91 × 1.14 = 103.7 아님)

공격 카드 예시 (베이스 80):
```
일반 : 80              (고정)
희귀 : 80 → 88
특급 : 80 → 90
전설 : 80 → 91 → 102
신   : 80 → 93 → 106  (+유니크 효과)
```

### 2-2. 정수 효과 — 강화 단계당 +1 고정

비율 계산 대신 단순 정수 증가. 해당 효과 타입:

| 효과 타입 | 설명 | 예시 |
|---|---|---|
| DRAW | 드로우 장수 | 2 → 3 → 4 |
| ENERGY | 마나 회복량 | 1 → 2 → 3 |
| 지속시간 (turns) | 버프·디버프 지속 턴 수 | 2턴 → 3턴 → 4턴 |
| POISON 스택 | 독 부여량 | 3 → 4 → 5 |
| WEAK 스택 | 약화 부여량 | 1 → 2 → 3 |
| VULNERABLE 스택 | 취약 부여량 | 1 → 2 → 3 |
| CHARM 스택 | 매혹 부여량 | 1 → 2 → 3 |
| MORALE | 사기 증가량 | 1 → 2 → 3 |

> COMMON 카드도 정수 효과가 있으면 표기하되 실제 값은 0강 고정.

## 3. 전체 수치 스케일 기준

영웅 HP 1000 기준. 한 턴에 받는 기대 피해: 8~15%.

| 대상 | 기준값 | 비고 |
|---|---|---|
| **영웅 HP** | **1000** | 전원 동일 베이스 (렐릭·이벤트로 조정 가능) |
| 일반 적 HP | 300 ~ 2000 | 적 종류별 차등 (아래 섹션) |
| 엘리트 HP | 1500 ~ 2500 | |
| 보스(히드라) HP | 4500 | |
| 공격 카드 베이스 | 100 ~ 150 | 스타터 100, 대형 공격 150 |
| 방어 카드 베이스 | 80 ~ 130 | 스타터 80, 방패류 130 |
| 힐 카드 베이스 | 80 ~ 150 | 대상 범위에 따라 차등 |
| 적 공격력 (일반) | 80 | 한 턴 8% HP 타격 |
| 적 공격력 (엘리트) | 130 ~ 180 | |
| 적 공격력 (보스) | 200 ~ 300 | |

### 수치 계산 유의사항
- **독(Poison)**: 턴마다 스택 수만큼 피해 → 누적 독이 중요하므로 스택 자체는 작아도 됨 (초기 3~5 스택이 적절)
- **방어도(Block)**: 턴 종료 시 초기화 → 베이스 방어도보다 카드 조합·주기 설계가 중요
- **COST_NEXT**: 다음 카드 비용 감소 → 수치보다 연계 조합이 핵심, 비용 감소량은 정수 효과

## 4. 신(Divine) 등급 유니크 효과 규칙

신 등급 카드는 강화 단계마다 **다른 보조 효과**가 교체·추가됨 (진화형).

### 유형 분류

| 유형 | 설명 | 예시 |
|---|---|---|
| **누적 강화형** | 같은 계열 디버프/버프가 점점 세지거나 많아짐 | 약화1 → 약화2 → 약화3 |
| **맥락 전환형** | 단계마다 다른 상태이상으로 전환, 복합 디버프 진행 | 약화 → 취약 → 독 |
| **조건 해금형** | 1강까지는 단순, 2강에서 특수 조건 효과 해금 | 0강:없음 → 1강:적 독상태시+피해 → 2강:즉사 임계치 25% 이하 |

### 설계 원칙
- 0강에도 유니크 효과 **탑재** (강화 전부터 신 등급임을 체감)
- 1강→2강으로 진행할수록 효과가 시너지 친화적으로 강화
- 수치 자체는 전설과 동일 → 유니크 효과가 **차별점**

## 6. 이후 구현 단계 참조 (다음 플랜용)

```gdscript
# CardResource 필요 변경
enum Rarity { COMMON, UNCOMMON, RARE, LEGENDARY, DIVINE }
@export var rarity: Rarity = Rarity.COMMON
@export var upgrade_level: int = 0  # 0/1/2

# 강화 계산 공식
static func get_upgraded_value(base: int, rarity: Rarity, level: int, is_percent: bool) -> int:
    if is_percent:
        var rate := {Rarity.UNCOMMON: 0.10, Rarity.RARE: 0.12,
                     Rarity.LEGENDARY: 0.14, Rarity.DIVINE: 0.16}
        return int(base * (1.0 + rate.get(rarity, 0.0) * level))
    else:
        return base + level  # 정수 효과
```
