# 3인 팀·다중 적 독/매혹 평가 계약

## 가설과 판정

작은 정수 전환 후 긴 매혹 소비 보스전이 (1) 팀/대상 구성에서도 남는지, (2) 반함 직전 소비를 피하는 선택으로 완화되는지 비교한다. 실제 BattleManager ATB와 카드/적 정의를 사용하며 게임 수치는 먼저 바꾸지 않는다.

- 단위: 동일 팀·덱·강화·적 구성·초기 시드에서 legacy/live 전투 쌍. 정책 효과는 같은 단위의 정책 간 차이로 따로 비교한다.
- 주 표본: 나폴레옹/클레오파트라/이순신. 클레오는 이전 평가의 시작/독/매혹제어/매혹피해 10장, 나머지는 실제 시작덱. 기본 또는 모든 카드 강화(획득 가능한 평균 런을 뜻하지 않음).
- 적: 이집트/북유럽의 저작된 3마리 일반전 각1개와 각 신화 Act1/Act2 보스 각1개, 총6개 구성. 추가 단독 클레오·피요르긴은 이전 병목의 정책 재검증용이다. 적 HP/공격 배율은 조작하지 않는다.
- 시드101/202/303, 입력96회 제한. 치명타 없음, 유물 없음, 최대 HP 시작. 실제 ATB의 영웅 입력 차례 수이며 라운드/초 단위가 아니다.
- 기준 정책은 손패 순서 첫 사용 가능 카드·첫 생존 적. 매혹 피해 덱만 consume-first와 threshold-aware를 추가한다. 다른 덱에서 같은 정책을 반복해 표본을 부풀리지 않는다.
- consume-first: 현재 매혹이 있는 적에 사용 가능한 소비 카드를 먼저 낸다. 나머지는 기준과 같다.
- threshold-aware: 소비 대상에 이미 반함이 있으면 소비를 막지 않는다. 임계치가 이미 충족됐거나, 지금 사용 가능한 매혹 카드 하나로 반함을 만들 수 있으면 소비를 보류하고 그 매혹 카드를 먼저 낸다. 나머지는 기준과 같다. 미래 손패를 보거나 승리를 강제하지 않는다. 대상은 기준과 같고 실제 도발 잠금을 반영한다. 이 실험용 정책은 캠페인 봇 기본 정책을 대체하지 않는다.
- 관측: 승/패/제한/미완료, 입력 횟수, 전체 잔여 영웅/적 HP, 독 틱 피해 신호, 반함 증가, 매혹 소비 카드 전후 스택·사용, 소비 보류/순서 변경 결정 이유와 불변 전투 궤적. 보류 표시는 실제 미사용 카드 장수나 독립 표본 수가 아니라 결정 이벤트다. 피해 신호는 초과 피해를 포함할 수 있다.
- 비교 신호: 승패 역전, 같은 승리끼리 입력 차이3회 이상, 반함 직전 소비 보류가 실제 발생했는지. 정책 변경으로 차이가 줄면 선택 병목의 근거, 계속 남으면 수치/팀·적 조합의 후속 후보다. 자동 수치 조정/전체 밸런스 합격 기준은 아니다.
- 증거 경계: 고정 실험 덱·고정 팀·유물 없는 전투이며 캠페인 획득 비용·숙련자 최적 플레이·재미를 측정하지 않는다. 같은 초기 시드도 경로 분기 후 난수 소비는 달라질 수 있다. 중복 궤적과 정책이 실제 달라진 상태 수를 함께 보고한다.

### 3인 팀: 기존 단위 ↔ 현재 단위

각 행은 같은36개 초기 구성, 기준 손패 정책이다. 양쪽 모두 각36전투를 승리했다. 중앙값은 상위 중앙값, P90은 정렬된36개 중33번째 값이다.

| 클레오 덱 | 입력 중앙값 기존→현재 | 입력 P90 기존→현재 |
|---|---:|---:|
| 시작 덱 | 20→20 | 35→35 |
| 독 | 14→14 | 23→23 |
| 매혹 제어 | 22→23 | 42→42 |
| 매혹 소비 피해 | 21→21 | 38→39 |

현재 표본에서는 독·매혹의 작은 정수 전환이 3인 팀의 전반적 승패/전투 길이를 무너뜨린 증거가 없다. 서로 다른 덱의 희귀도·획득 비용은 맞추지 않았으므로 독 덱의 짧은 전투를 '독이 우월/과강함'으로 판정하지 않는다.

### 현재 단위: 정책 대조

매혹 소비 피해 덱만 비교한다. 모든 수치는 동일 시드/강화/적에서 기준 정책 대비 차이다.

| 범위/정책 | 승리 | 양쪽 승리 중 빨라짐/느려짐/동일 | 실제 궤적 변화 |
|---|---:|---:|---:|
| 3인·손패 순서 | 36/36 | 기준 | 기준 |
| 3인·즉시 소비 | 36/36 | 20 / 4 / 12 | 26/36 |
| 3인·임계치 인지 | 36/36 | 2 / 14 / 20 | 21/36 |
| 단독·손패 순서 | 4/6 | 기준 | 기준 |
| 단독·즉시 소비 | 2/6 | 1 / 1 / 0 (양쪽 승리2개) | 6/6 |
| 단독·임계치 인지 | 5/6 | 1 / 3 / 0 (양쪽 승리4개) | 6/6 |

- 3인 즉시 소비는 최대12입력 단축하지만, 잔여 팀 HP는 기준보다 최대73 낮아진 표본도 있다. 세 영웅이 살아 승리했는지와 팀 HP를 함께 봐야 하며 속도만으로 기본 정책 교체를 정당화하지 않는다.
- 3인 임계치 인지는25/36전투에서 보류/순서변경 판단48회를 기록했지만 실제 전투 궤적 변화는21/36이다. 판단 횟수와 효과가 생긴 전투 수는 다르다. 반함 증가 합은68→96이나 전투 시간도 늘어 단순 발동 합계를 성능으로 해석하지 않는다.
- 단독 기본강화·303은 기준51입력 패배/영웅HP0에서 임계치 인지75입력 승리/HP71로 바뀌었다. 생존 병목을 해결한 표본이지 전투 단축은 아니다. 같은 강화·202는70→66입력으로 줄었지만 HP는24 낮아졌다.
- 단독 강화·101은41→64입력, HP는38 증가했다. 임계치 인지를 일괄 적용하면 제어에 치우쳐 마무리를 늦출 수 있다는 반례다.

## 판정과 다음 의사결정

1. 긴 단독 보스전을 카드 수치 결함만으로 단정하지 않는다. 팀원 유무와 소비/제어 선택 모두 결과를 바꾼다.
2. 독·매혹 일괄 상향/하향은 하지 않는다. 이 표본에서는 전반적 붕괴가 없으며, 세 정책 간 속도/생존의 교환관계가 관측됐다.
3. 임계치 인지 정책은 실험 도구에만 추가하고 기존 캠페인 봇 기본 정책을 유지한다. 실제 캠페인 진입 상태·HP 압박·위험한 적 의도까지 반영한 정책은 별도 검증 대상이다.
4. 기본 광역 매혹의 추가1회 요구는 기존 경계값 관측으로 남긴다. 현재 전체 전투 결과만으로 그 카드 하나의 영향을 분리하거나 수정하지 않는다.

- 기존 스냅샷5·live1672·조건 표시130 통과/실패0 (`STSL-tutorial-validation-live-FYzf9J`). 정책32 최종 로그는 `STSL-tutorial-validation-live-QZHYVK`.
- 공용 비교기에 다중 적/초기 계측 훅을 추가한 뒤 기존 단독144쌍을 재실행했다(`STSL-tutorial-validation-live-5PCdAz`). 기존137/현재140승 및144개 paired 궤적 SHA-256 모두 이전 t8UOiN과 동일하다. 3인 평가 JSON의 소비 소스 SHA-256도 작업 종료 시 현재 파일과 전부 일치함을 확인했다.
- 정책은 소비 카드만의 순서/보류를 바꾸며 나머지 타깃 선택을 동일하게 유지했다. 타깃 최적화·여러 매혹 카드 조합 탐색·정확한 처치 예측은 하지 않는다. 생산 카드의 선행 피해로 적이 죽을 수 있어 결정 사유는 실제 반함 발생 증거가 아니다.
- 도발 사망 경계의 초기 검사 실패2건은 HP를 남기고 alive 플래그만 내린 불가능한 fixture가 원인이다. 실제 사망처럼 HP0과 alive=false를 함께 설정한 최종 검사에서 통과했다. 중간 실패를 통과 수에 합치지 않는다.
- 일반전은 3마리 조합2개뿐이다. 유물·실제 드래프트 비용·손상된 캠페인 진입·추가 팀 구성·숙련 플레이/재미는 미측정이다. 전체 밸런스 완료 판정이 아니다.
