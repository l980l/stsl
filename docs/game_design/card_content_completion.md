# 카드 콘텐츠 완성도 정리 — 1차 기능 보완

2026-10-12. 사용자 승인: 성능 프로파일링 중단, 기존 카드의 미작동 효과 → 무효 강화 → 역할 중복 순서로 콘텐츠 개발.

## 범위와 판단 기준

- 최신 머지 `main`의 `0a916bb`에서 `content/card-completeness`로 작업. 기존 에셋·사용자 저장·카드 ID·풀과 시작 덱은 보존한다.
- 보상 풀 189장, 시작 덱은 영웅별 10장. 시작 덱과 보상을 합친 고유 정의는 `owner_id|card_name` 기준 216개다. 공용 카운터를 이름만으로 합치면 211개다.
- v3에서 정한 효과와 강화는 유지한다. 이번에는 기능이 없는 카드와 강화해도 실제 효과가 변하지 않는 카드를 먼저 수정한다. 나머지 카드를 일괄 상향하거나 새 카드로 대체하지 않는다.
- 등록·이미지 존재·규칙 테스트 통과는 밸런스나 재미의 완성을 뜻하지 않는다. 이번에는 성능 측정, 캠페인 표본 수집, 큰 수치 단위 변경을 하지 않는다.

## 효과 계약

### 파라오의 독력

기존 정의는 남은 에너지 소비를 명시하지만 실행 코드 없이 권능 목록에만 저장되었다. “에너지당 독 부여량 ×2”는 새 독인지 기존 독인지, 지속형인지 불분명했다.

이번 해석은 **기존 독의 일회성 증폭**이다. 본인의 남은 에너지를 전부 소비하고, 살아 있고 독이 걸린 모든 적의 `poison_dmg`를 `소비 에너지 ×2`배로 만든다. 에너지 0은 효과가 없고 독이 없는 적에게 새 독을 만들지 않는다. 지속 시간은 늘리지 않는다. 영구 권능이나 에너지 수에 따른 지수 증폭은 만들지 않는다. 한국어·영어 설명에 이 해석을 명시한다.

### 운명의 결투

기존 카드 정의의 “대상 적과 3턴 결투, 상호 피해 +50%”를 구현한다. 시전자와 지정한 적 사이의 직접 공격 피해만 증가한다. 다른 아군이나 다른 적은 영향을 받지 않고, 적을 강제로 특정 대상으로 공격시키지도 않는다. 지속은 지정한 적의 차례 종료로 감소하며, 독 등 지속 피해에는 적용하지 않는다.

피해 보너스는 받는 쪽의 취약과 가산하고 시전자의 약화와는 곱한다. 예를 들어 기본 피해 100·약화·취약·결투는 `100 × 0.75 × (1 + 0.5 + 0.5) = 150`이다. 단일 카드 미리보기와 예약 피해도 같은 규칙으로 표시한다. 결투 상태 배지에는 남은 적 차례와 시전자 이름을 표시한다.

## 무효 강화 10개 보완

기존 강화식에서 실제 데이터가 바뀌지 않던 9개 카드와, 소비 효과에 사용되지 않는 `value +1`만 받던 독력을 보완한다. 그 외 의미가 있는 강화와 v3 기존 강화는 유지한다.

| 카드 | 이번 명시 1강 |
|---|---|
| 사막의 약법 | 선택 버리기 후 드로우 2→3 |
| 유혹의 정체 | 감속 5/3차례→7/4차례 |
| 함포 일제사 | 팀 병사당 피해 45→55 |
| 투지 | 사기당 방어 50→60 |
| 거북선 점호 | 팀 속도 4/4차례→6/5차례 |
| 성령의 가호 | 동료 속도 4/3차례→6/4차례 |
| 약탈자의 본능 | 무작위 4타 각각 40→50 |
| 강철 일격 | 방어 비례 피해 120%→140% |
| 검귀의 광기 | 무작위 5타 각각 30→40 |
| 파라오의 독력 | 증폭 계약은 유지하고 본인 방어 20 추가 |

모든 216개 정의의 실제 GameManager 강화 경로에 대해 비용·레벨·효과 데이터 변화를 전수 검사한다. 이는 실제 전투 시나리오를 216번 수행한 것이 아니다. 전체 풀의 최종 강화 재설계나 승률 합격으로 해석하지 않는다.

## 설명 검수

- 사기→방어는 실제 `effect.value` 계수를 표시한다. 특히 투지는 사기당 방어 50인데 기존 설명은 1이라고 표시했다.
- 독 폭발은 실제 독 피해의 백분율을 표시한다. 기존에는 강화로 피해 계수가 바뀌어도 0강·1강 설명이 같았다.
- 매혹의 향기는 실제 `1 + effect.value` 배율을 표시한다. 현재 0강은 3배, 1강은 4배인데 기존 설명은 모두 2배였다. 이번에는 실행 수치를 바꾸지 않고 설명을 일치시켰다. 옛 helper 주석의 “2턴 ×2”와 현재 실행의 차이는 후속 디자인 검토 후보로 남긴다.
- 결투의 시전자·지정 적 범위, 지속 기준과 독력의 에너지 소비·일회성 증폭을 설명에 반영한다.
- 새 설명은 한국어·영어를 제공하고, 다른 11개 언어에는 영어 대체 문구를 제공한다. 번역 자체가 완성되었다는 뜻은 아니다.

## 역할 정리의 다음 후보 — 아직 수치 변경하지 않음

| 영웅 | 유지할 중심 선택 | 다음에 비교할 카드 / 질문 |
|---|---|---|
| 나폴레옹 | 사기 준비·소비와 병사 공격 | 참호 구축 / 그랑다르메의 방패: 같은 사기+방어를 희귀도와 수치만으로 구별해도 충분한가? |
| 클레오파트라 | 독 축적→증폭/폭발, 매혹 소비 | 독력 / 독살의 의식 / 파라오의 역병: 지속 독을 남기는 선택과 즉시 소비하는 선택이 실제로 구별되는가? |
| 이순신 | 방어 축적→소비, 팀 병사/진형 | 반격 / 거북선 돌격: 비용과 소비 상한 차이가 선택을 만드는가? 투지의 사기 계수 설명부터 바로잡는다. |
| 잔다르크 | 팀 회복·방어와 희생 보상 | 수호 천사 / 천사의 날개: 지속 회복과 제한된 후속 회복의 비용·회수 타이밍을 비교한다. |
| 칭기즈칸 | 카드 연계·기동과 병사 소비 | 기병 후퇴 / 기병 포위망: 즉시 팀 방어와 병사 준비가 서로 다른 덱에서 선택되는가? |
| 무사시 | 다단 공격, 단일 적 결투, 빈 손 | 정점의 겨냥 / 격류 / 무쌍 베기: 같은 단일 적 조건에 작은 수치·디버프 차이만 있어 역할이 겹치는지 비교한다. |

이 표는 코드의 유사 역할을 토대로 만든 검토 후보이지, 카드가 불필요하거나 재미없다는 검증 결과가 아니다. 자동 삭제·풀 축소·획득 확률 변경은 하지 않았다.

## 검증

Godot 4.7.2 Mono, 무음 headless(`--audio-driver Dummy`), 사용자 저장과 분리된 `/tmp/STSL-tutorial-validation-content-R52DWQ`에서 검사했다. 효과·설명·결투 배지 회귀 테스트는 수정 전 실패를 확인하고 구현 후 재실행했다.

- 전체 `tests/test_runner.gd`: **2947 통과, 실패 0**. 실행별 RNG 분기로 검사 수가 소폭 달라질 수 있다.
- 효과 전용 `tests/run_card_content_effects.gd`: **29 통과, 실패 0**. 본인/타 영웅 에너지, 0에너지, 죽은 적·독 없는 적, 독 지속·일회성 증폭, 결투 대상·시전자·독 피해 제외·0/1강 만료·미리보기·약화/취약 조합.
- 강화 전용 `tests/run_card_upgrade_completeness.gd`: **897 통과, 실패 0**. 216개 고유 정의, 0/1강 비용·효과 데이터 차이, 9개 지정 수치와 독력의 방어 20.
- 실제 카드 UI `tests/test_card_revision_ui.gd`: **20 통과, 실패 0**. 기존 두 디자인의 입력·비용 검증에 한국어/영어 결투 배지 지속·피해 보너스·시전자 툴팁 검사 추가.
- 실제 튜토리얼 씬 `tests/test_tutorial_integration.gd`: **321 통과, 실패 0**.
- `git diff --check` 통과. 위 최종 게임 테스트 로그에 엔진 오류·경고 없음. 에디터 import에는 기존 미추적 BurstParticles2D 폴더의 중첩 프로젝트 무시 경고가 별도로 남는다.
- `tools/generate_catalog.gd -- --cards-only`로 로컬 도감 MD/CSV 재생성. 이 생성 파일은 기존 Git 제외 정책을 유지하며 커밋 대상으로 자동 추가하지 않는다.

전용 검사 수는 전체 묶음과 중복되므로 합산해 독립 표본 수로 사용하지 않는다. 최종 로그는 같은 임시 폴더의 `final-{full,effects,upgrades,ui,tutorial}.log`다. 화면 캡처·수동 플레이·영웅별 승률이나 재미의 검증은 수행하지 않았다. 코드·문서·위키만 로컬 변경이며 커밋·푸시하지 않았다.

## 남은 내용

- 이번 10개 강화 보완 외에는 기존 강화 규칙을 유지한다. 지속 권능의 작은 +1 등은 데이터상 무효는 아니지만 선택 가치가 충분한지 추가 설계가 필요하다.
- 매혹의 향기의 과거 의도(2턴 ×2)와 현재 실행(전투 내 3/4배)을 별도 판단한다. 설명 일치를 전체 디자인 확정으로 해석하지 않는다.
- 위 역할 비교 후보를 바탕으로 카드별 선택 이유를 정하고, 이후 큰 수치 변경과 획득 풀 조정은 별도 변경으로 검증한다.
