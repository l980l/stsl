# 적 몬스터 정체성 교체 (2026-05-23, PR `feat/enemy-reskin-dedup`)

같은 신화 인물이 여러 적으로 중복 등재된 9개 그룹에서 **각 그룹 1종만 유지**하고 나머지를 같은 신화 내 다른 인물로 **정체성만** 교체. 전투 메커니즘(`intent_pattern`·`max_hp`·`mythology`·`signatures_enabled`·`charm_resistance`)은 원본과 동일하게 보존. 총 13종 교체.

미세 조정 2건: 호네온나 `damage_type` ice → curse, 조로구모 ice → poison (신규 정체성에 맞춤). 그 외 메커니즘 변경 없음.

## 후속 작업

- 일러스트 아트 재생성: 신규 13종의 영문 프롬프트는 `docs/illustration_prompts_enemies.md` 에 갱신 완료. 실제 이미지 생성은 별도 워크플로우.
- 미사용 그룹 (이번 범위 외): 외부 AI가 지목했으나 게임플레이상 명확히 구별되는 그룹 (gorgon/medusa/medusid, harpy/fly_harpy 등)은 그대로 유지.
- 별도 후속: 메커니즘 복제 쌍 (`yasha ↔ invincible_ronin` 100% 동일, Greek `cerberus` normals/act2 키 충돌, `anubis_guard ↔ clay_soldier` 등) — 이번 정체성 작업과 무관한 별도 정리.
