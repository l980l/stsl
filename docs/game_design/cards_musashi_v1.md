## 영웅 정체성

| 아키타입 | 설명 |
|---|---|
| **이도류(二刀流)** | 한 카드로 2회 분할 공격 (`DMG X × 2`). 총합 피해는 동등급 단타보다 낮지만, 2회 히트가 독·상태이상 트리거에 유리. |
| **결투(決鬪)** | 적이 **1마리**일 때 수치 증가. `CONDITIONAL_DMG` 조건 키 `enemy_count == 1`. 보스·엘리트 전에서 폭발적 화력. |
| **무심(無心)** | **핸드가 0**일 때 조건 발동. `CONDITIONAL_DMG` 조건 키 `hand_size == 0`. 패를 비운 뒤 극대 피해. 핸드 자원 소모가 이순신의 HP 소모와 다른 자원 축. |

## 밸런스 메모

### 등급 분포

| 등급 | 장수 | 비율 |
|---|---|---|
| COMMON | 4 | 27% |
| UNCOMMON | 4 | 27% |
| RARE | 5 | 33% |
| LEGENDARY | 1 | 7% |
| DIVINE | 1 | 7% |

- 전설 + 신 합산 = **2장** (규칙 내, ≤ 3)
- COMMON 4장: 스트라이크(시작덱) × 3 + 디펜드(시작덱) × 2 포함 → 풀에서 이도 베기·검기 수련으로 2종

### 수치 조정 근거

- **이도류 총합**: 단타 동급 대비 약 115~120% 총합. 2회 히트 보상 (독 트리거 2회, 니텐이치류 렐릭 연동)
- **결투 CONDITIONAL**: 적 1마리 조건 시 약 180% 피해. 복수 적에서는 보통 수준 유지 — 보스·엘리트 전문 폭딜
- **무심 CONDITIONAL**: 패 0 조건은 세팅 필요 → 무심검 DMG 350이 폭발적이지만 세팅 없이는 150에 그쳐 패널티가 분명
- **병법의 길**: 다음 공격 카드 DMG +30 — 단발성 버프. 이순신 '이순신의 결의' 류와 유사하나 대상이 공격 카드 전체 (등급 무관)

### 기존 영웅과 차별화

| 영웅 | 자원 축 | 무사시와 차이점 |
|---|---|---|
| 이순신 | HP 소모(필사즉생) | 무사시는 핸드(패) 소모. HP 보존하면서 패를 소진 |
| 나폴레옹 | MORALE 누적·소모 | 무사시는 MORALE 미사용. 단독 전투력 집중 |
| 클레오파트라 | 독·매혹 상태이상 | 무사시는 상태이상 최소화. 결투·이도류 직접 피해 위주 |

### 크로스 시너지 연동

- **무사시 × 이순신 — "검사의 약속"**: 무사시의 결투 카드(혈로 개척·일도양단) 사용 시, 이순신의 FORMATION_BLOCK 조건(생존 팀원 수)에 +1 버프 부여. 무사시가 단일 적에 집중하는 동안 이순신이 방어를 강화하는 상호보완.
- **연격(이도류 + 독)** → 클레오파트라 독 시너지 트리거 (독침 반격 등). 이도류 2히트가 독 스택 2번 생성.

## 필요한 신규 EffectType

| 신규 여부 | 내용 |
|---|---|
| ❌ 신규 불필요 | 이도류 `DMG X × 2`는 기존 DAMAGE를 2번 적용. EffectType 추가 없이 `hit_count: 2` 파라미터로 처리 가능 |
| ❌ 신규 불필요 | 결투(enemy_count == 1), 무심(hand_size == 0)은 기존 `CONDITIONAL_DMG` 조건 키 확장으로 처리 |
| 🔶 구현 시 확인 | `effect_resource.gd`의 `CONDITIONAL_DMG` 조건 분기 로직에 `enemy_count`, `hand_size` 키 추가 필요 |
