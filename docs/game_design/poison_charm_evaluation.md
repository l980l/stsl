# 독·매혹 변경 전후 평가

## 평가 계약

- 목적: 작은 정수 전환이 독 누적/폭발 및 매혹 임계치 빌드의 실전 결과를 크게 바꾸는지 확인한다.
- 단위: 같은 덱, 적, 강화 단계, 초기 난수 시드의 legacy/live 전투 한 쌍.
- 입력: 클레오파트라 단독, 시작 덱 및 고정 10장 전문 덱 3종, 기본/전체 강화, 시드 101/202/303. 서로 다른 신화의 일반/정예/보스 6종.
- 정책: 실제 ATB 전투에서 손패 순서상 첫 사용 가능 카드, 첫 생존 적 대상. 치명타 끔. 유물·진행 보상 없음. HP 최대, 에너지 등은 실제 런타임 기본값.
- 관측: 승리/패배/입력 96회 제한/미완료를 분리하고, 입력 횟수·잔여 HP·독 틱 피해 신호·반함 부여 신호·카드 사용 횟수를 기록한다. 피해 신호는 초과 피해를 포함할 수 있어 순 HP 감소량으로 해석하지 않는다.
- 비교 기준: 승패 역전, 입력 횟수 차이 3회 이상, 정규화 독 피해 20% 이상 차이, 반함 발동 횟수 차이는 개별 원인 검토 대상으로 삼는다. 이 기준은 자동 합격/불합격이나 보편적 재미 점수가 아니다.
- 조치: 차이가 작으면 유지 후보, 큰 차이는 해당 카드/임계치/정책의 경계 사례를 추가 확인한다. 이 실험만으로 자동 수치 조정하지 않는다.
- 한계: 단독 영웅 스트레스 비교이며 일반적인 3인 캠페인 승률이 아니다. 광역 대상 수, 실제 카드 획득 비용, 적응적 플레이, 장면 VFX 난수는 미측정이다. 같은 궤적은 중복으로 보고한다.

실행: `bash tools/run_live_balance_checks.sh run_poison_charm_balance`
결과 JSON은 격리된 `user://poison_charm_balance.json`에 저장되며 로그에 절대 경로를 출력한다.
