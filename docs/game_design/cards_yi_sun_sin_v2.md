## 1. 영웅 정체성 + 아키타입 상세

### 영웅 정체성

이순신은 **방어도를 자원으로 쓰는 반격형 탱커-지원가**다.

- 방어도를 쌓아 피해를 버티고, 쌓인 방어도를 COUNTER_BLOCK으로 반격한다.
- 팀 전체 방어도와 버프를 공급하는 지원 역할도 겸한다.
- 저HP 상태를 두려워하지 않고 오히려 자원으로 활용하는 역발상 플레이가 핵심이다.
- v2에서 필사즉생 아키타입이 크게 보강되어 자해-회복 사이클이 완성된다.

### 아키타입 1 — 거북선

| 항목 | 내용 |
|---|---|
| **핵심 메카닉** | 방어도 대량 축적 → COUNTER_BLOCK 반격 피해 |
| **플레이 패턴** | 매 턴 BLOCK 카드를 연속으로 사용해 방어도를 누적. 상대가 공격하면 COUNTER_BLOCK으로 피해를 반사. 방어도 임계치(200 이상)를 달성하면 보너스 효과 발동. |
| **승리 조건** | 방어도를 쌓으면서 COUNTER_BLOCK 100% 카드로 수백~천 이상의 반격 피해를 누적해 적을 소진. |
| **핵심 EffectType** | BLOCK, COUNTER_BLOCK, BLOCK 임계치 조건 효과 |
| **v2 추가 설계** | 방어도 임계치 도달 시 보너스 효과 카드 3장 추가. BLOCK 연쇄 카드 2장 추가. 반격 강화 패시브성 POWER 카드 1장 추가. |
| **밸런스 주의** | COUNTER_BLOCK 상한 미구현 시 방어도 극대화 빌드에서 단일 피해 1000+ 가능. 구현 시 캡 검토 필수. |

### 아키타입 2 — 학익진

| 항목 | 내용 |
|---|---|
| **핵심 메카닉** | 팀 전체 방어도/버프 지원. 생존 팀원 수 기반 스케일. |
| **플레이 패턴** | BLOCK_ALL과 FORMATION_BLOCK으로 팀원 모두를 보호. 팀원이 살아있을수록 효과가 강해지므로 팀원 생존을 최우선으로. MORALE 공급으로 다른 영웅의 크로스 시너지를 활성화. |
| **승리 조건** | 팀원 전원을 살려 FORMATION_BLOCK 최대화. 긴 전투에서 팀 전체 체력과 방어도를 유지하며 상대를 압박. |

| **v2 추가 설계** | GAIN_MORALE 공급 카드 2장(크로스 시너지 허브). 팀원 수 조건 발동 카드 2장. 상시 팀 버프 POWER 카드 1장. |
| **밸런스 주의** | 팀원 전원 생존 전제 시 FORMATION_BLOCK이 과도해질 수 있음. 팀원 수 기반 공식에 상한 설정 권장. |

| 항목 | 내용 |
|---|---|
| **핵심 메카닉** | HP 소모(자해) → 강력 피해/방어. 저HP 조건(≤50%) 발동. 회복-소모 사이클. |
| **플레이 패턴** | 배수진류 자해 카드로 HP를 50% 이하로 낮춘 뒤 CONDITIONAL_DMG 카드로 2배 피해를 뽑는다. 그 후 HEAL 카드로 HP를 회복해 사이클을 반복. HP가 위험 구간을 드나드는 고위험·고보상 스타일. |
| **승리 조건** | 자해-회복 사이클을 안정적으로 돌리며 매 라운드 조건부 대형 피해를 뽑아내는 것. |
| **핵심 EffectType** | CONDITIONAL_DMG, HEAL(자신), HEAL_ALL, CONSUME_MORALE, BLOCK |
| **v2 추가 설계** | 저HP 조건부 카드 3장 추가. 자해+보상 카드 2장 추가. 회복+다음 카드 강화 카드 2장 추가. CONSUME_MORALE 연계 2장 추가. |
| **밸런스 주의** | 배수진(자해 BLOCK)과 CONDITIONAL_DMG 조합이 너무 결정적으로 굴러가면 다른 아키타입이 밀릴 수 있음. 회복 수단 제한적으로 설계. |

## 3. 전체 40장 카드 표

### 수치 강화 계산 규칙 (요약)

- UNCOMMON 1강: 베이스 × 1.10 (반올림)
- RARE 1강: 베이스 × 1.12 (반올림)
- LEGENDARY 1강: 베이스 × 1.14 / 2강: 베이스 × 1.28 (반올림)
- DIVINE 1강: 베이스 × 1.16 / 2강: 베이스 × 1.32 (반올림)
- 정수 효과(DRAW / ENERGY / 지속시간 / 디버프 스택 / MORALE): 강화당 +1
- **2강은 베이스 기준 누적**: `베이스 × (1 + rate × 2)`. "1강 × rate 추가" 아님.

## 4. 신(Divine) 등급 카드 2장 상세

### 14번 — 노량 해전 (v1 승계)

이순신이 마지막 전투에서 전사한 역사적 사실을 반영한 거북선 아키타입의 정점 카드.

| 강화 | 주 효과 | 유니크 보조효과 | 의도 |
|---|---|---|---|
| **0강** | DAMAGE 250 (단일) | — | 강력하지만 단순. "마지막 일격"의 원형. |
| **1강** | DAMAGE 290 (단일) | 이번 전투 동안 모든 COUNTER_BLOCK 비율 +20%p | 거북선 빌드 전체를 강화. 60%→80%, 100%→120%로 반격 폭발력 급증. |
| **2강** | DAMAGE 330 (단일) | 전투 내 COUNTER_BLOCK +20%p 유지 + 공격 후 즉시 BLOCK 120 획득 | "쏘고 막는다"의 집약. 공격과 방어를 한 카드에서. |

> **구현 메모**: 1강/2강의 COUNTER_BLOCK 비율 보너스는 전투 내 영구 버프 플래그로 처리 권장.

## 8. 밸런스 메모

### v1 인계 사항

- **COUNTER_BLOCK 상한**: 방어도 극단 축적 시 COUNTER_BLOCK 100% 카드가 단일 1000+ 피해 가능. 보스 상대 시에도 과도할 수 있음. 구현 시 상한캡(예: COUNTER_BLOCK 피해 최대 800) 검토 필수.
- **배수진 밸런스**: HP -80 자해로 필사즉생 조건(HP≤50%) 달성이 빠름 → 의도된 시너지이나 너무 결정적이면 다른 카드가 밀릴 수 있음. v2에서 유사 자해 카드가 늘어났으므로 조건 달성 속도 재검토 필요.
- **0코스트 카드**: 해군 기동(#13), 방패막이(#21), 진형 결속(#31) 3장. 매 턴 손 소모 없이 방어도/진형 방어 공급 → 덱 압박 없는 BLOCK 공급원. 과도한 0코 적층 시 BLOCK 자원이 코스트 없이 공급되므로 에너지 효율 재검토 필요.
- **DIVINE 카드 획득 빈도**: 노량 해전 2강, 학익진 완성 2강은 사실상 풀 빌드 조건. 상점/보상에서 낮은 확률로만 출현.

### v2 신규 주의사항

- **반격 태세(#22) POWER**: COUNTER_BLOCK 발동 시 피해 +20 고정 추가. 거북선 빌드에서 반격 횟수가 많을수록 총 피해 급증. 동일 전투 내 발동 횟수 제한 또는 상한 검토.
- **전사의 각오(#39) POWER**: HP≤50%에서 모든 BLOCK 카드 +20% → 배수진(#10)과 결합 시 HP -80 자해 후 BLOCK 202 → 242로 상승. 필사즉생 빌드 방어도가 거북선 수준으로 높아질 수 있음. 중복 POWER 제한 고려.
- **지휘 본능(#30) FORMATION_BLOCK 60**: 팀원 3명 생존 시 FORMATION_BLOCK 60 × 3 = BLOCK 180 (팀원 합산 아닌 이순신에게만이면 BLOCK 180). 공식 확인 필요. 생존 팀원 수 × 베이스 BLOCK 방식이면 팀원 사망 시 급감하는 자연 조절장치 내재.
- **독전(#38) CONSUME_MORALE**: MORALE 소모 실패(MORALE 0) 시 아무 효과 없음. 전투 흐름상 MORALE가 없을 때 낭비 카드가 되지 않도록 MORALE 공급원(#24, #27, #30)과 세트 구성 권장. 덱 빌딩 가이드에 명시 필요.
- **위기 돌파(#35) HP≤30% 조건**: 필사즉생(HP≤50%)보다 조건이 좁음. 자해 연속 사용으로 HP 30% 이하 유지 빌드 가능 → 팀 치유 없이는 전투 종료 전 사망 위험. 의도된 고위험이나 팀 회복 수단과 조합 여부 모니터링.
