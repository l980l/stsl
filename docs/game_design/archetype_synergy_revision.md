## 재미 프로필과 검증 계약

대상은 ATB 전투와 영웅별 손패를 사용하는 덱빌딩 플레이어다. 세 가지 가설을 테스트한다.

1. **순서의 숙련**: A→B와 B→A가 다른 자원/대상/손패 결과를 낸다. 실제 런타임의 고정 상태 순서쌍으로 검증한다. 플레이 질문: “왜 이 순서가 유리한지 이해하고 선택했나?” 차이가 없으면 수치만의 변형이므로 설계를 수정한다.
2. **기회비용과 표현**: 자원을 보존하는 지속 이득과 지금 소비하는 즉시 이득이 공존한다. 0자원·최대 소비·실패/처치/죽은 아군 등 경계 및 턴당 보상 제한을 검증한다. 질문: “상황에 따라 다른 카드를 남기거나 소비했나?” 항상 소비가 이득이면 대가/상한을 재검토한다.
3. **조합의 발견**: 같은 영웅의 서로 다른 아키타입 또는 기존 시작 카드와 새로운 보상 카드가 연결된다. 새 카드가 특정 한 장 없이는 기능하지 않는지, 기존 자원 공급원과 실제로 연결되는지 테스트한다. 질문: “새로운 조합을 직접 떠올리고 시험하고 싶었나?” 연결이 닫혀 있으면 기존 상태/카드와 접점을 늘린다.

자동화는 구조적 근거다. 재미/만족/숙련자 체감/장기 반복 플레이는 **not_measured**이며 검사 통과를 재미의 증명으로 쓰지 않는다. 플레이 피드백을 조작하거나 가상의 설문 응답을 만들지 않는다. 사회성/서사/편안함은 이번 목표에서 N/A다.

## 구현·검증 원칙

- 이미 존재하는 사기·병사·독·매혹·방어·희생 누적·손패를 재사용한다. 새 전용 게이지를 영웅마다 추가하지 않는다.
- 명시된 비용/대상/상한/턴당 한도와 부작용을 실제 효과와 카드 설명에서 동일하게 제공한다. ko/en, 기타 언어의 명시적 영어 fallback을 유지한다.
- 카드ID 기반 특수 분기보다 안정적인 rule_id/params를 공유한다. 카드 데이터와 실제 전투·미리보기·저장 복원·강화의 단위를 맞춘다.
- legacy/live 및0/1강 경계, 실제 카드 조합, 자원 부족, 자기/타 영웅, 죽은 대상, 환급 반복, 미리보기·번역 토큰을 검사한다. 기존 수치/튜토리얼 회귀의 변경 이유를 구별한다.
- 단위: 규칙/상태/강화/단위의 고정 실험. 시뮬레이션은 실제 BM을 사용하고 시드·입력 한도·규칙 지문을 기록한다. 같은 상태 반복을 독립 플레이 표본으로 세지 않는다.
- 게임에 없는 자원을 만들거나 승리를 강제하지 않는다. 커밋·푸시는 별도 요청 전까지 하지 않는다. 테스트는 Dummy 오디오·별도 user://로만 실행한다.

### 제한과 대가

- 사기/병사/희생 누적과 적의 디버프는 실제로 감소한다. 방어 이전은 원래 방어를 복제하지 않는다. 자기 자신을 지정한 이전은 추가 기본 방어만 얻고 이전은 하지 않는다.
- 독 잔여 한 틱의 즉발은 지속을1 줄이고 기존 독 사망 처리를 따른다. 강화/약화/방어를 일반 공격처럼 이중 적용하지 않는다.
- 적의 취약을 공격 전에 소비하면 그 취약의 피해 증폭도 잃는다. 미리보기 역시 소비 후 상태로 계산한다.
- 선택 버리기를 건너뛰거나 버릴 카드가 없으면 새 드로우 보상을 받지 않는다. 기존 명상/사막의 약법의 계약은 별도로 보존한다.
- 기동 에너지 정산과 이미 마킹된 적의 추가 드로우는 본인 차례당1회다. 예약된 첫 타격/공격 할인은 기존 최대값 예약 정책을 따른다.
- 회복 차단은 초과 회복 방어를 만들지 않으며 죽은 아군을 일반 회복으로 부활시키지 않는다.

이 구성은 '언제나 같은 카드부터 내는가'를 깨는 설계 가설이다. 자동 플레이의 승리나 설명의 존재만으로 재미를 확정하지 않는다.

## 남은 의사결정

- 구조 검증 후 사람 플레이에서 “왜 먼저/나중에 내는지 이해됐는가”, “보존/소비를 상황에 맞춰 선택했는가”, “다른 조합을 시험하고 싶은가”를 확인한다. 실제 응답은 아직 없다.
- 마지막 방패는 준비한 방어와 다른 아군이 필요하며, 자기 지정은 HP만 지불하는 나쁜 선택이다. 의도된 팀 전용 대가지만 플레이에서 혼동/죽은 카드가 되면 타깃 제한 또는 솔로 대체 효과를 검토한다. 자동 상향하지 않았다.
- 36장을 중심으로18개 연결을 바꾼 것이지216종 전체를 새로 설계한 것은 아니다. 나머지 카드의 가치·획득 비용·캠페인 누적 피해·유물 조합·무한 연계의 전역 부재는 확정하지 않는다. 변경 전 밸런스 보고서는 당시 규칙의 역사적 결과다.
- 기존 캠페인 봇은 새 소비/이전의 최적 전략을 아직 모른다. 통합 표본은 기능·중단·단위 정합성 확인이며 최적 플레이/재미를 대신하지 않는다.
