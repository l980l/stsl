# 작은 정수 표시·툴팁 전수 점검

2026-10-15. 사용자 요청: 변경 수치가 실제 카드·UI·툴팁에 적용됐는지 확인. 이전 구현 검사를 표시 전수 검증으로 간주하지 않고 별도 대조했다.

## 범위와 판정 기준

- 최종 생성 카드 216종×기본/1강×13언어×classic/modern = **11,232개 카드 설명 출력**. 빈 설명, 미치환 숫자/이름 토큰, `%%`, 프레임 간 내용 차이, 주요 단순 효과의 실제 수치 포함 여부를 검사했다. 강화는 실제 GameManager 경로를 사용한다.
- 몬스터192종의 일반/페이즈/차지 후속/사망/카드 카운터 의도를 리소스 중복 제거 후 점검했다. 언어까지 포함한 의도 상태12,532개다. 의도 라벨·툴팁·카운터 툴팁의 미치환 출력을 검사했다. 이는 전투12,532회나 사람 표본이 아니다.
- 유물42종 설명/도감 검색, 상태 배지6종, 신화 시그니처6종과 보스/주요 시너지 설명을13언어로 검사했다. 도감은 실제 필터 함수를 호출하고 합성 발견 상태를 사용했다.
- 맵/상점/도감/전투 유물, 이벤트 비용·회복 태그, 휴식/영웅/맵 HP와 디버그 유물 창은 호출 경로도 대조했다. 골드·에너지·장수·횟수·기간·속도·퍼센트는 무조건10으로 나누지 않는다.
- 실화면 표본: 네 카드의1강, 독 배지·반복 권능 진행 표시, ko/en×두 프레임×1280×720/1920×1080 = **8개 캡처**. 실제 카드/배지 컴포넌트를 띄운 합성 화면이며 전체 캠페인의 모든 화면/언어를 포인터로 조작한 검사가 아니다. 요청/실제 viewport 및 이미지 해상도는 일치했다.
- 이번 목표는 수치/조건 일치다. 일반적인 아름다움·접근성·모든 언어의 잘림·사람의 이해도를 합격 판정하지 않는다. 별도의 보편 UI 점수를 만들지 않았다.

## 발견하고 수정한 불일치

1. **독 튜토리얼:** 실제1→2인데 안내가10→20이었다. 13언어 안내를 이름 붙은 숫자 토큰으로 바꾸고 실제 레슨 독침의 최종 효과에서 중첩 전/후 값을 읽도록 했다. 레거시 비교 모드에서도 해당 정의를 읽으며 숫자를 수동으로 중복하지 않는다.
2. **일부 언어의 포맷:** 인과응보/카운터/일본어 약화·취약 툴팁에 `25%%` 등이 남았다. 인수가 없는 번역 출력의 percent escape를 정규화했다. 그리스어의 매N번째 공격 권능 라벨은 `%η` 오타로 숫자가 누락돼 `%dη`로 고쳤다.
3. **크로노스 카운터:** 존재하지 않는 번역 키를 화면에 그대로 보였다. 키가 없으면 실제 카드 종류/임계 횟수/후속 의도의 값으로 툴팁을 생성하는 기존 fallback을 사용한다.
4. **도감 검색:** 카드의 옛 description, 유물의 환산 전 번역을 검색했다. 화면과 같은 최종 효과 설명/유물 포맷터를 검색하도록 바꿨다.
5. **디버그 유물 추가/제거:** 설명 포맷터를 우회하던 두 창을 일반 유물 UI와 같은 경로로 연결했다. 실제 체크박스 입력을 자동 실행한 것은 아니며 해당 표시식의 소스 대조다.
6. **효과별 조건 누락:** 조건부 방어·드로우 등은 설명에 조건이 보이지 않았다. 최종 등록 카드가 쓰는 본인 저체력/손패0/적1/생존 아군3 조건을 효과 설명에도 붙였다. 일반 카드와1강 모두 같은 조건을 표시한다.
7. **이순신 조건의 실제 미발동:** 필사즉생·위기 돌파·사지결단의 본인 HP 조건 피해, 사지결단 방어, 불사조 드로우, 진형 사수 드로우에 조건 판정이 없었다. 명세/번역의 **본인 HP≤50% / ≤30%**, 생존 아군3명 기준으로 실행·피해 미리보기·공통 조건 판정을 맞췄다. 상대/다른 아군 체력을 잘못 읽지 않는다. 조건은 각 효과 처리 시점에 평가하므로 불사조는 앞선 회복 후 드로우 조건을 확인한다.

마지막 항목은 표시만 바꾼 것이 아니라 설명대로 발동하도록 한 실제 규칙 수정이다. 따라서 앞선 보스/밸런스 샘플은 그 당시 소스의 역사적 결과로 유지하며 새 규칙과 동결된 전후 비교로 재사용하지 않는다. 보스 수치·카드 원래 수치·비용을 추가로 튜닝한 것은 아니다.

최종 표의 로그는 스크립트/엔진 오류·경고0이다. 테스트는 시작부터 Dummy 오디오, Master무음, 별도 user://이며 실제 플레이어 저장/설정은 사용하지 않았다. 렌더링 표본은 성능 프로파일링이 아니다.

조건 수정 전 전용 검사는44통과/84실패였다. 초기 표시 검사에서는 포맷39건, 확장 검사에서는 크로노스13언어가 실패했다. 초기 도구의 startup preload 오류, CSV 수정 후 재임포트 전 출력, 첫 렌더 종료 시 커서 텍스처 정리 오류는 중간 실패 기록으로 남기고 최종 통과에 합치지 않았다. 최종 렌더 도구는 종료 전에 커서/그림/VFX 캐시를 해제한다.

원시 JSON·소스별 SHA-256·엔진 로그·8개 PNG는 `log/live-balance/STSL-tutorial-validation-live-UMSwxV/`에 보존했다. 샘플 [classic 한국어1280](../../log/live-balance/STSL-tutorial-validation-live-UMSwxV/ui-numbers-classic-ko-1280.png), [modern 영어1280](../../log/live-balance/STSL-tutorial-validation-live-UMSwxV/ui-numbers-modern-en-1280.png). 이미지 검수에서 표본의 변경 수치·조건·전체 아군 정화·다단2회·방어 강화가 표시됐고 카드 설명 영역 안에 들어왔다.

## 재현

```sh
# CSV를 바꿨다면 격리 프로젝트를 editor --headless --import로 먼저 재임포트한다.
bash tools/run_live_balance_checks.sh run_small_number_ui_audit run_card_display_conditions test_tutorial_integration
bash tools/run_live_balance_checks.sh --rendered run_small_number_ui_audit
bash tools/run_live_balance_checks.sh run_small_number_live
STSL_LEGACY_COMBAT=1 bash tools/run_live_balance_checks.sh test_runner
```

일반/도감/보상/강화는 같은 효과 설명 생성기를 사용한다. 손패의 일반 DAMAGE는 기존 대상·상태 반영 경로를 유지한다. 규칙형 카드의 공식 설명을 상황별 총 피해 숫자로 바꾸는 새 UI는 구현하지 않았다. 힘/독/조건의 실제 결과는 전투 검사와 별도로 구별한다.

미사용 레거시 템플릿까지 일괄 숫자 치환하지 않았다. 예컨대 예전 SACRIFICE_PAYOFF의100HP 문구는 현재216종에서 V3 규칙으로 대체되어 활성 표시 경로가 아니다. 전체13언어×모든 화면의 렌더/가독성·실제 마우스 호버·사람 플레이는 이 전수 **텍스트/규칙** 검증과 별개의 범위다.
