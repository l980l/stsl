| 강화 | 수치 효과 | 유니크 보조효과 |
|---|---|---|
| 0강 | CONSUME_MORALE 3 → DMG 300 | 단일 대상에 WEAK 1 부여 |
| 1강 | CONSUME_MORALE 3 → DMG 348 | 단일 대상에 WEAK 2 부여 |

## SUMMON_TOKEN 카드 설계

> 현재 기획에서 포병 일제사격을 군단 아키타입의 핵심 카드로 배치하고, SUMMON_TOKEN은 확장 예정 슬롯으로 남겨둠.
> 구현 시 아래 스펙 참조:

**병사 토큰** (SUMMON_TOKEN): HP 150, ATK 60 / 턴 종료 시 타겟에 자동 공격. 최대 3기.

향후 추가 예정 카드 (Pool 확장 시):
- **제국 보병 소집** (RARE, 2코): 토큰 2기 생성 [HP 150, ATK 60]. 군단 아키타입 핵심.
- **근위대 돌격** (UNCOMMON, 1코): 토큰 1기 생성 [HP 150, ATK 60] + DMG 80.

## 밸런스 메모

### 등급 분포

| 등급 | 장수 | 비율 |
|---|---|---|
| COMMON | 4 | 27% |
| UNCOMMON | 4 | 27% |
| RARE | 5 | 33% |
| LEGENDARY | 1 | 7% |
| DIVINE | 1 | 7% |

- 전설 + 신 합산 = **2장** (규칙 내)
- COMMON 4장: 스트라이크(시작덱)×3 + 디펜드(시작덱)×2 포함, 풀에서는 신속 기동·전열 재편으로 2종

### 수치 조정 근거
- 기존 스케일(HP ~100 기준 DMG 3~9) → 신 스케일(HP 1000 기준 DMG 80~300)로 전면 상향
- 전체 타격(ALL) 카드는 단일 타격의 약 60~80% 수치로 조정
- MORALE 정수 효과는 강화 시 +1씩 증가 (비율 미적용)
- 예나의 기습: 독 + 공격 복합으로 크레오파트라 크로스 시너지(독침 반격) 연동 의도

### 크로스 시너지 연동
- 예나의 기습 → 클레오파트라 독 시너지 트리거
- 황제의 명령 → MORALE 팀 공급으로 이순신 FORMATION_BLOCK 촉진
- 황제의 기개 2강 사기 회복 → 총공세 명령과 루프 가능성
