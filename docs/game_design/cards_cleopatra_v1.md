## 신(Divine) 등급 카드 상세

### 클레오파트라의 입맞춤 — 맥락 전환형 진화

| 강화 | 수치 효과 | 유니크 보조효과 |
|---|---|---|
| 0강 | CHARM 2 ALL, POISON 3 ALL | 전체 매혹 + 독 살포. 단순 복합 디버프. |
| 1강 | CHARM 3 ALL, POISON 4 ALL | 추가로 WEAK 1 ALL 부여. 아군 딜 증폭 레이어 추가. |
| 2강 | CHARM 3 ALL, POISON 5 ALL | WEAK 2 ALL + **이 턴 종료 시 독 틱 즉시 1회 추가 발동** (정규 틱 별도). |

**의도**: 0강은 조종 아키타입의 전장 통제. 1강에서 저주 레이어(WEAK)가 붙어 두 아키타입 브릿지로 기능. 2강의 독 즉발은 나일의 분노 등 POISON_BURST 직전에 쓰면 스택 피해 2회분 → 조건 해금형으로 최대 효율은 독살 빌드 완성 후 가능.

## 밸런스 메모

### 등급 분포

| 등급 | 장수 | 비율 |
|---|---|---|
| COMMON | 4 | 27% |
| UNCOMMON | 4 | 27% |
| RARE | 4 | 27% |
| LEGENDARY | 2 | 13% |
| DIVINE | 1 | 7% |

- 전설 + 신 합산 = **3장** (규칙 내 최대)
- COMMON 4장: 독침(시작덱)·왕실 방어(시작덱) 포함, 풀에서 독의 씨앗·이시스의 가호

### 수치 조정 근거
- 기존 독침 DMG 3 → 신 스케일 DMG 80 (기존 POISON 3 스택 유지)
- 기존 아스프 POISON 8 → 신 스케일 POISON 8 유지 (POISON 스택은 정수 효과, HP와 무관)
- 기존 독사의 마수 조건부 DMG 2/8 → 신 스케일 80/160으로 조건부 비율 유지
- 유혹: 기존 CHARM 1 → 신 스케일 CHARM 2 (기존 너프 조건 2스택 반영)
- 나일의 축복(HEAL 6) → 제거. 클레오파트라 정체성과 맞지 않아 파라오의 명(드로우+방어)으로 대체

### POISON_BURST 처리 방식
- 나일의 분노: `POISON_BURST (독 스택 × 배율)` 피해. 배율이 비율 효과 대상.
- 독 스택 자체는 정수 효과, POISON_BURST 배율은 비율 효과로 별도 처리.
- 예: 독 10스택 × 배율 3 = 30 피해. 1강(배율 ≈3.14)이면 31 피해.

### 크로스 시너지 연동
- 독사의 마수: 나폴레옹 예나의 기습 독 → 조건 활성화 (독침 반격 크로스 시너지)
- 저주의 시선 VULNERABLE: 나폴레옹 포격류 피해 증폭
- 클레오파트라의 입맞춤 CHARM ALL: 다수 적 전장에서 최대 효율. 혼란의 돌격 크로스 시너지 트리거
