# stsl 직업별 카드 구성 평가 v1

> 작성일: 2026-05-20
> 평가 대상: 영웅 6인 × (시작덱 10 + 풀 30~31) 카드 구성 (`resources/cards/cards_*.gd`)
> 평가 기준: `docs/inspiration/` 의 장르 연구 — 하스스톤 메타(2014~25), 슬더스1 아키타입, 슬더스2, 클레르 옵스퀴르 빌드
> 성격: 설계 평가. 코드 변경 아님. 개선안은 후속 작업으로 분리.

## 0. 평가 기준 — 연구에서 도출한 5대 원칙

| 원칙 | 출처 | 점검 질문 |
|---|---|---|
| 엔진 + 페이오프 | 슬더스 아키타입 §6-1 | 각 아키타입이 "자원 생성 → 승리 환산" 구조인가 |
| 아키타입 다양성 | 하스스톤 2014, 슬더스 | 영웅당 아키타입이 충분하고 서로 구별되는가 |
| 교차 영웅 콤보 | 슬더스 §7-2, 클옵 §6-3 | 한 영웅이 깔고 다른 영웅이 소비하는 설계가 있는가 |
| 고유 게이지 정체성 | 클옵 §5-2 | 영웅마다 다른 메커니즘으로 정체성이 분리되는가 |
| 희귀도·파워 분포 | 하스스톤 (파워 크리프) | 전설·신 분포가 영웅 간 균형 잡혔는가 |

## 1. 전체 구조 — 한눈에

- **6영웅 × 3아키타입**, 영웅당 시작덱 10장 + 풀 30~31장
- 각 아키타입은 **F / A / P / C / Chaos** 슬롯 구조
  - F(Foundation·기반), A(Amplifier·증폭), P(Payoff·정산), C(Connector·연결), Chaos(고변동)
- 영웅별 고유 메커니즘:

| 영웅 | 포지션 | 고유 메커니즘 | 3아키타입 |
|---|---|---|---|
| 나폴레옹 | 공격 지휘관 | 사기(Morale) | 돌격 / 군단 / 지휘 |
| 클레오파트라 | 디버프/조종 | 매혹(Charm) | 독살 / 저주 / 조종 |
| 이순신 | 방어 역공 | 진형(Formation) | 거북선 / 학익진 / 필사즉생 |
| 잔다르크 | 서포트/생존 | 부활·순교 | 신성 / 부활 / 순교 |
| 칭기즈칸 | 기동 정복 | 토큰·마킹 | 기동 / 몽골 기병 / 약탈 |
| 무사시 | 결투 검사 | 이도류·결투·무심 | 이도류 / 결투 / 무심 |

**총평 한 줄**: 단일 영웅 아키타입 설계는 **연구 원칙을 잘 지킨 우수한 수준**이다. 그러나 stsl 의 정체성인 **팀빌딩 — 교차 영웅 콤보 — 은 거의 비어 있다.** 가장 큰 개선 기회는 여기에 있다.

## 2. 강점 (연구 원칙 대비 잘 된 것)

### 2-1. 엔진+페이오프 구조가 설계에 내장됨 ★
F/A/P/C/Chaos 슬롯 체계 자체가 슬더스 문서 §6-1 의 "엔진+페이오프" 원칙의 구현이다. 모든 아키타입이 명시적으로 `기반(엔진) → 증폭 → 정산(페이오프)` 으로 분해돼 있다. 신규 카드 설계 시 "이건 어느 슬롯인가" 를 강제하는 좋은 규율.

### 2-2. 영웅별 고유 게이지 = 정체성 분리 ★
6영웅이 사기·매혹·진형·순교·토큰·이도류 등 **서로 다른 메커니즘**을 가진다. 클옵 §5-2 "메커니즘으로 정체성 분리" 원칙에 정확히 부합. 외형이 아니라 시스템으로 영웅이 구별된다.

### 2-3. 영웅 내 교차 아키타입 페이오프 존재
일부 카드가 다중 archetype 태그를 갖고, 2개 아키타입을 동시에 보상한다:
- 클레오파트라 `독의 옥좌` (디버프 종류당 피해) → 독살+저주 혼합 보상
- 클레오파트라 `황금 왕좌` → 조종 빌드 보상
이는 한 영웅 안에서의 "스플래시 빌드" 를 장려 — 좋은 설계.

### 2-4. 아키타입마다 Chaos 슬롯
각 아키타입에 고변동 카드 1장(`알프스 횡단`, `나일의 분노`, `검귀의 광기` 등). 슬더스의 "하이롤" 설계 요소를 의식적으로 반영.

### 2-5. 희귀도 프레임워크 일관
`cards_framework_v1.md` 기준 5등급·강화 공식·수치 스케일(HP 1000 기준)이 문서화·통일돼 있음.

## 3. 영웅별 평가

> 평가축: 아키타입 명확도 / 엔진·페이오프 완결성 / 보완점

### 3-1. 나폴레옹 — 양호
- **돌격**: 사기 적립(`황제의 권능`·`황제의 군단` 매턴 사기) → `황제의 기개`(0코, 사기3 소모 300딜) 정산. 엔진+페이오프 명확. ★
- **군단**: 토큰 소환은 많으나 **토큰 페이오프가 `군단의 진격` 1장뿐**. 12장 아키타입인데 정산구가 얇음 — 토큰을 "딜 배수" 보다 "방패" 로 쓰는 구조에 가까움.
- **지휘**: 드로우+비용감소(`황제의 의지`·`황제의 포위령`) → `대칸의 명령`류 0코 폭발. 무난.
- **보완**: 군단 아키타입에 토큰 정산 카드 1~2장 추가 검토.

### 3-2. 클레오파트라 — 우수 ★
- 3아키타입(독살·저주·조종) 모두 엔진+페이오프가 가장 깔끔하게 완결.
- 독살: 독 적립 → `POISON_BURST` 정산. 저주: 디버프 → `STATUS_DOUBLE`·`독의 옥좌`. 조종: 매혹 빌드업(임계치) → `매혹의 처형`·`뱀의 의식`.
- **교차 아키타입 페이오프**(독의 옥좌)가 명시적 — 6영웅 중 설계 모범.
- **보완**: 전설 5 + 신 1 = 6장. 다른 영웅 대비 고희귀도가 많음(§4-3 참고).

### 3-3. 이순신 — 보완 필요
- **거북선**: `함포 일제사`(`DAMAGE_PER_TOKEN`)가 정산구인데 **이순신 풀에 토큰 소환 카드가 없음**. 엔진이 빠진 페이오프 — `cards_yi_sun_sin.gd:196` `_fleet_fire`. 교차 영웅(나폴레옹·칭기즈칸 토큰) 의도라면 현재 `battle_manager.gd:1371` 이 owner 토큰만 읽으므로 작동 안 함. **확인·수정 필요.**
- **필사즉생**: 저HP 조건 `CONDITIONAL_DMG` 카드가 4장(`필사즉생`·`위기 돌파`·`사지결단`·`혈전`) — 효과 형태가 거의 동일, 단조로움.
- **학익진**: `FORMATION_BLOCK`(생존 팀원 수 기반)은 팀 인원을 보상 — 팀빌딩 친화적인 드문 카드. ★
- **보완**: `함포 일제사` 토큰 소스 정리, 필사즉생 카드 효과 차별화.

### 3-4. 잔다르크 — 양호
- **신성**(딜+힐), **부활**(`REVIVE` 정산), **순교**(`sacrifice_bank` 누적 → `SACRIFICE_PAYOFF`) 3축 명확.
- 순교가 가장 독창적 — HP를 자원으로 은행에 적립 후 정산. 슬더스 자해 아키타입과 동일 계보, 잘 구현.
- 팀 힐·`도발`(knights_oath) 등 **유일하게 팀 보호에 특화** — 서포트 정체성 명확.
- **보완**: 신성 아키타입이 "성속성 딜" 위주로, 고유 훅(echo/strength)이 카드에 잘 드러나지 않음.

### 3-5. 칭기즈칸 — 보완 필요
- **기동**(드로우→`BLOCK_PER_CARDS_PLAYED`), **몽골 기병**(토큰→`DAMAGE_PER_TOKEN`, 엔진+페이오프 명확 ★), **약탈**(`ON_KILL_DRAW`+마킹).
- **마킹**(`노획`)은 전 영웅 치명타를 올리는 **진짜 교차 영웅 카드** — 좋은 사례. ★
- **보완 1**: 전설 2 + 신 0 = **고희귀도 카드가 6영웅 중 최소**. 프레임워크 목표(6장)에 크게 미달.
- **보완 2**: 기동·약탈 둘 다 draw 중심 — 두 아키타입의 차별점이 약함.

### 3-6. 무사시 — 보완 필요
- **이도류**(2히트 → `bonus_per_hit`·`every_nth` 증폭): 가장 독창적, 잘 설계.
- **무심**(빈 손 조건): "손패를 비울수록 강함" — 드로우와 역행하는 흥미로운 긴장. 단 `void_sword`·`무심검`·`청풍명월`·`오륜의 경지` 가 모두 `hand_size_0` 조건 — 4장 동일 훅.
- **결투**: **10장 중 6장이 `enemy_count_1` 조건 `CONDITIONAL_DMG`**(`혈로 개척`·`정점의 겨냥`·`일도양단`·`마지막 결투`·`격류`·`무쌍 베기`). 효과 형태가 거의 같은 카드의 반복 — 아키타입이 "수치만 다른 같은 카드 6장" 으로 느껴질 위험.
- **보완**: 결투 아키타입의 카드 다양화가 시급. "1대1 조건" 외의 훅(결투 락 활용, strength 정산 등) 추가.

## 4. 횡단 평가 — 종합 약점

### 4-1. ★ 정정 — 교차 영웅 시너지는 "부재" 아니라 "얕음"
> **2026-05-20 정정**: 본 평가 초안은 "교차 콤보 0개" 라 단정했으나 `battle_manager.gd` 감사 결과 **오진**이었다. 아래는 정정된 내용.

교차 영웅 시너지는 **15개 영웅 쌍 전부 작동하는 트리거를 보유**한다 — 13개는 `_apply_synergy_bonus()`(`battle_manager.gd:2650`), 2개는 `CONSUME_MORALE` 핸들러 인라인(1150~1156행, 소모 성공 시 발동). 활성 시너지는 HUD 아이콘+툴팁으로 표시된다(`battle_scene.gd:579`). 시스템 자체는 완전·정합하다.

진짜 약점은 시너지가 **얕다**는 것:
- 전부 **자동 패시브** — 카드·팀 선택으로 키우는 빌드 축이 아니다. 슬더스 §7-2·클옵 §6-3 의 "교차 콤보 = 팀 게임 엔드게임" 은 *빌드 가능성*을 뜻하는데, 패시브 보너스는 그 조건을 못 채운다.
- 일부 보너스가 게임 스케일(카드 ~100딜) 대비 미미하다 (block+3, +4dmg, poison+1).
- 발동 *순간* 피드백이 없다 — HUD 활성 목록만 존재.
→ 과제는 "0에서 만들기" 가 아니라 **"얕은 패시브 시너지를 빌드 가능·가시적으로 심화 + 팀 자원을 읽는 드래프트 가능 교차 카드 신설"**.

### 4-2. 아키타입 내 효과 중복
- 무사시 결투: `enemy_count_1` 조건 카드 6/10
- 이순신 필사즉생: `low_hp` 조건 카드 4/10
- 무사시 무심: `hand_size_0` 조건 카드 4/10
→ "수치만 다른 같은 카드" 가 한 아키타입에 몰리면 드래프트 선택이 무의미해진다. 슬더스 아키타입은 같은 축 안에서도 카드마다 다른 훅(엔진/증폭/정산)을 줬다.

### 4-3. 희귀도 분포의 영웅 간 불균형
| 영웅 | 전설 | 신 | 합 |
|---|---|---|---|
| 나폴레옹 | 2 | 2 | 4 |
| 클레오파트라 | 5 | 1 | 6 |
| 이순신 | ~4 | 0 | ~4 |
| 잔다르크 | ~4 | 1 | ~5 |
| 칭기즈칸 | 2 | 0 | **2** |
| 무사시 | 2 | 1 | 3 |
프레임워크 목표는 영웅당 전설+신 6장. **칭기즈칸 2장은 명백한 미달**, 클레오파트라 6장과 격차가 크다. 칭기즈칸·이순신은 신 카드가 0 — 영웅 간 "정점 카드 체험" 이 불공평.

### 4-4. 신(Divine) 등급이 기능적으로 미차별
`cards_framework_v1.md §4` 는 신 등급에 "강화 단계별 유니크 진화 효과" 를 규정했으나, `card_resource.gd:31` 주석대로 **미구현 + 강화 한도를 전 등급 1강 통일**. 현재 신 카드는 "전설 + 수치 약간" 일 뿐 — 등급이 거의 장식. 신을 가진 영웅/안 가진 영웅 차이도 의미가 흐림.

### 4-5. 카운터 — stsl 고유 메커니즘인데 빌드 불가
연구 문서(슬더스 §7-6, 클옵 §6-7)는 카운터를 **stsl 만의 차별 축**으로 지목했다. 그런데 카운터 카드는 `cards_common.gd` 의 시작덱 1장 고정 — 풀에 없어 추가 드래프트 불가. 가장 독창적인 메커니즘이 **아키타입으로 발전할 수 없는** 상태.

### 4-6. 경미한 문제
- speed 버프 카드(`전격 진군` 등)가 F/A/P/C/Chaos 구조 밖에 1장씩 덧붙음 — 풀 31장(문서상 30장과 불일치, 나폴레옹 등).
- 영웅당 아키타입 3개는 슬더스(4~6개) 대비 적음. 의도된 선택이나, 영웅 내 빌드 분기는 제한적.

> 권고는 평가 결과일 뿐, 실제 적용 여부·범위는 별도 기획 결정 사항.

## 6. 결론

stsl 의 카드 구성은 **단일 영웅 단위에서는 장르 연구 원칙을 충실히 지킨 견고한 설계**다 — 엔진+페이오프 구조, 고유 게이지 정체성, Chaos 슬롯, 희귀도 프레임워크 모두 양호. 클레오파트라가 모범 사례.

stsl 의 핵심 차별점인 **팀빌딩**은 — 15쌍 패시브 시너지로 *기반은 갖췄으나* — 플레이어가 카드·팀 선택으로 키울 수 있는 **빌드 축으로는 미완성**이다. 시너지가 전부 자동 발동이라 의식적 빌드의 대상이 아니다. 연구한 4개 게임(특히 클레르 옵스퀴르)의 결론 — **교차 캐릭터 콤보가 팀 기반 게임의 엔드게임** — 을 충족하려면, 패시브 시너지를 가시화·심화하고 시너지를 겨냥한 드래프트 카드를 추가해 "빌드 가능한" 축으로 끌어올려야 한다.
