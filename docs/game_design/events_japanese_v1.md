# 챕터 2 일본 신화 이벤트 기획 v1

## 이벤트 풀링 구조

`_build_event_pool()` match에 `"japanese": return _EventsJapanese.build_pool()` 분기 추가. `events_japanese.gd` 단일 파일에 10종 통합.

사용 가능한 EventChoice.EffectType: `NONE, GOLD, HEAL, DRAW_UP, REMOVE_CARD, ADD_RELIC, ADD_HERO, ADD_RELIC_GAMBLE`

---

## 이벤트 목록 (10종)

---

### 1. 이세 신궁의 축복

> 아마테라스가 깃든 신성한 거울이 빛을 발한다. 참배자는 영험한 힘을 얻는다고 전해진다.

**선택지**:
| 레이블 | 효과 | 비용 |
|---|---|---|
| 참배를 드린다 | HEAL +40 | NONE |
| 신물을 가져간다 | ADD_RELIC_GAMBLE | HP -20 |
| 그냥 지나친다 | NONE | NONE |

**기획 의도**: 무료 치유 vs 위험한 렐릭 도박. 신성한 장소에서의 선택 — 올바른 방문(치유) vs 신물 탈취(도박+위험).

---

### 2. 오니의 장기판

> 산 속 오두막에서 오니 하나가 홀로 장기를 두고 있다. "심심했는데, 한 판 두겠소?"

**선택지**:
| 레이블 | 효과 | 비용 |
|---|---|---|
| 대국에서 이긴다 (도박) | GOLD +80 OR HP -20 (50/50) | NONE |
| 판돈을 제안한다 | GOLD +40 | GOLD -30 |
| 거절한다 | NONE | NONE |

**기획 의도**: 3선택지 도박 이벤트. 확실한 소득 vs 고위험 고보상 vs 포기. "손오공의 도전"(중국)과 유사하지만 안전 중간 선택지 추가.

---

### 3. 유키온나의 눈보라

> 눈보라가 몰아치더니 아름다운 여인이 나타난다. "길을 잃었군요. 제가 안내해드리죠. 하지만 제 냉기가 당신을 건드릴 수도 있어요."

**선택지**:
| 레이블 | 효과 | 비용 |
|---|---|---|
| 따라간다 | HEAL +30 + DRAW_UP +1 | HP -20 |
| 혼자 길을 찾는다 | GOLD +30 | NONE |

**기획 의도**: 복합 보상(치유+드로우) vs 안전한 소액 골드. 복합 보상이 더 가치 있지만 HP 리스크 존재.

> 구현 메모: HEAL + DRAW_UP 동시 효과는 단일 EventChoice로 불가 시, HEAL 30과 DRAW_UP +1 두 선택지로 분리.

---

### 4. 텐구의 수련

> 붉은 부리의 텐구가 하늘에서 내려온다. "내 검술을 가르쳐주지. 대신 약한 기술은 버려야 해."

**선택지**:
| 레이블 | 효과 | 비용 |
|---|---|---|
| 수련을 받는다 | REMOVE_CARD (랜덤 1장) | NONE |
| 그냥 지나친다 | NONE | NONE |

**기획 의도**: 무료 카드 제거(덱 정제). 한국 "여동빈 검술"(중국)과 동일 콘셉트지만 일본 요괴 서사. 스타터 약한 카드 제거에 유용.

---

### 5. 신사의 오마모리

> 낡은 신사에 기도를 드리니 금빛 부적이 나타났다. 어떤 효과를 가져올지는 알 수 없다.

**선택지**:
| 레이블 | 효과 | 비용 |
|---|---|---|
| 부적을 가져간다 | ADD_RELIC_GAMBLE | NONE |
| 두고 간다 | NONE | NONE |

**기획 의도**: 무료 렐릭 도박. 저주 렐릭 가능성 포함. 한국 "저승의 거래"와 유사하지만 비용 없음. 위험 부담 없이 도박 가능.

---

### 6. 다누키(狸)의 환술

> 통통한 너구리가 동전을 변환하는 마술을 보여주며 씩 웃는다. "내가 특별한 기술을 알려드릴까요? 뭔가 필요하시죠?"

**선택지**:
| 레이블 | 효과 | 비용 |
|---|---|---|
| 환술로 골드를 늘린다 | GOLD +70 | GOLD -20 |
| 환술로 체력을 회복한다 | HEAL +35 | GOLD -40 |
| 동료를 소개받는다 | ADD_HERO | NONE |

**기획 의도**: 3선택지 자원 교환. 골드 차익 거래 / 유료 치유 / 영웅 영입. 팀 상황에 따라 최적 선택이 갈림.

---

### 7. 갓파의 강 건너기

> 강 앞에서 갓파가 손을 내밀며 말한다. "저한테 인사를 드리면 강을 건네드리죠. 머리 숙이시면 됩니다. 단, 저도 하나 가져가겠어요."

**선택지**:
| 레이블 | 효과 | 비용 |
|---|---|---|
| 인사를 드린다 | GOLD +50 | HP -15 |
| 강을 혼자 건넌다 | HEAL +20 | NONE |

**기획 의도**: 갓파의 "머리를 숙이면 머릿속 물이 떨어져 힘을 잃는다" 전설 역이용. 골드+HP 소모 vs 소량 안전 치유.

---

### 8. 슈텐도지의 술판

> 무너진 주점에서 요괴들이 술판을 벌이고 있다. 슈텐도지의 마주(魔酒)가 테이블 위에 남아있다.

**선택지**:
| 레이블 | 효과 | 비용 |
|---|---|---|
| 마주를 마신다 | MAX_HP +50 (랜덤 영웅 1명) | NONE |
| 보물창고를 뒤진다 | GOLD +80 | HP -30 |
| 서둘러 자리를 뜬다 | NONE | NONE |

**기획 의도**: 무료 최대 HP 증가 vs 고위험 골드 vs 포기. 마주의 힘이 최대 HP 성장을 표현. "불로초"(중국)와 유사하지만 취기 테마.

---

### 9. 후지산 신령

> 후지산 정상에서 백발의 신령이 사라지기 전 손을 내밀었다.

**선택지**:
| 레이블 | 효과 | 비용 |
|---|---|---|
| 신령의 인도를 따른다 | ADD_RELIC | GOLD -70 |
| 길을 물어본다 | DRAW_UP +1 | NONE |

**기획 의도**: 유료 확정 렐릭 vs 무료 드로우. 골드 여유팀 → 렐릭 구입. 드로우 중심 빌드 → 무료 선택.

---

### 10. 아마테라스의 귀환

> 갑자기 세상이 밝아지며 따뜻한 빛이 쏟아진다. 아마테라스가 잠시 모습을 드러내며 팀을 비춘다.

**선택지**:
| 레이블 | 효과 | 비용 |
|---|---|---|
| 빛을 받아들인다 | HEAL +60 | NONE |
| 동료에게 빛을 나눈다 | ADD_HERO | NONE |

**기획 의도**: 두 가지 좋은 선택지. 대량 치유(팀 전체 또는 최저 HP) vs 영웅 영입. 일본 신화 최고 신성 이벤트로 "이득만 있는" 이벤트. 런 중반 피로도 해소.

---

## 구현 메모

- **함수명 제안** (`events_japanese.gd`):
  - `_ise_shrine_blessing()`, `_oni_shogi()`, `_yuki_onna_blizzard()`, `_tengu_training()`, `_shrine_omamori()`, `_tanuki_illusion()`, `_kappa_river_crossing()`, `_shuten_doji_feast()`, `_fujisan_spirit()`, `_amaterasu_return()`
- **복합 효과 선택지** ("유키온나의 눈보라"): HEAL + DRAW_UP 동시 부여는 단일 선택지로 불가 시 두 선택지로 분리.
- **HEAL +60 "아마테라스의 귀환"**: 대량 치유. HEAL 대상을 "모든 살아있는 영웅"(HEAL_ALL 방식) or "팀 전체 각각 +20" 방식으로 구현 PR에서 결정. 단일 선택지로 충분한 이득 보장.
- **ADD_HERO 필터링**: "다누키의 환술" + "아마테라스의 귀환" 이벤트는 팀 정원 3명이면 자동 필터링됨 (기존 구현).
