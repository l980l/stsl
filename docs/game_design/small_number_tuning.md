# 작은 정수 밸런스 조정 v2 — 평가 계약

2026-10-14 사용자 승인. 기존 일반 플레이/세이브는 유지하고 작은 정수 후보를 조정한다. 목표는 원본을 무조건 복제하거나 승률을 임의 목표에 맞추는 것이 아니라, 반올림으로 생기는 과강화·독 누적의 편향을 줄이고 명확한 정수 강화를 유지하는 것이다.

## 입력과 판정

- 기존 실제ATB 일반 전투720쌍과 즉시 효과1728쌍을 대조군으로 유지한다.
- 추가 합성 압박 검사: 원본 적 HP×8, 공격 의도×4를 적용한 뒤 후보 단위로 변환한다. 초기 HP×4/공격×2 검사도 모두 승리해 생존 경계를 관측하기에는 약했다. 두 변형에 같은 압박을 주며 실제 몬스터 데이터에는 저장하지 않는다. 다른 의도/힘/독은 그대로다. 시드101·15개 지원 일반 종·8덱·0/1강,240쌍·최대24영웅 입력 차례다. 실제 게임 난이도/챕터 승률로 해석하지 않는다.
- 조정 전후 같은 덱·적·시드·정책·ATB·무치명타 조건을 비교한다. 원본 승리/후보 패배와 그 반대, 제한/미완료, 영웅 입력 차례·정규화 잔여HP를 분리한다. 반복 궤적은 독립 표본으로 합산하지 않는다.
- 사막 기마의 드로우3 효과7/8을 원본7.5/8.1에 가깝게 만들되 드로우0은0, 강화는 조건부 고정+1, 설명은 정수만 쓴다. 여러 드로우 수0~10에서 실제 피해와 미리보기를 검증한다.
- 나일의 분노의 강화로 독을1→2, 즉100% 늘린 후보를 완화한다. 독침도 원본v3의 독15→후보2 때문에33% 강해지는 반복 피해를 조정한다. 직접 피해 보상과3회 독 tick의 합을 함께 검사하며 독 자체의 지속/증폭 규칙은 바꾸지 않는다.
- 정상 전투의 새 패배나 압박 조건의 큰 승패 변화가 발생하면 자동 합격으로 처리하지 않고 원인을 기록한다. 한정된 검사에서 비정상 증폭을 줄이면1차 조정을 종료한다. 시그니처105종/보스/팀 조합·경제·사람 체감은 별도 공백이다.

소스 SHA·원시 결과는 `log/small-number-simulation/`에 보존한다. 테스트는 시작부터 무음·세이브 격리, 성능 프로파일링/기본 수치 적용/커밋·푸시는 하지 않는다.

## 적용한 후보 v2

| 카드 | v1 후보 | v2 후보 |
|---|---|---|
| 사막 기마 | 뽑은 장수당 피해3→4 | 2장당5, 남은1장은2; 드로우가 있으면 강화 추가피해1 |
| 독침 | 피해6→8, 독2 유지 | 피해7→9, 독1 유지 |
| 나일의 분노 | 피해7×5 유지, 전체 독1→2 | 피해6×5→7×5, 전체 독1 유지 |

사막 기마 드로우3 기준은9→12에서7→8로 바뀌었다. 드로우0에서는 강화해도0이다. 예측·예약 피해·실제 피해가 같은 정수 공식을 쓰며 힘/약화/치명타를 추가하지 않는 기존 PER_DRAW_DMG 계약을 보존한다. 받는 측 취약/결투 등은 기존 피해 경로에서 적용한다. 카드 비용·대상·장수·지속·속도는 바꾸지 않았다.

독침의 **실제 v3 원본**은 피해60→80/독15 유지다. 독3회까지의 단독 합은 원본 정규화10.5/12.5, v1은12/14, v2는10/12다. 인게임은 정수이며 위 소수는 비교값이다. 독 증폭·재적용·중도 처치에서는 이 단순 합과 달라질 수 있으므로 보편 등가라고 주장하지 않는다.

나일의 분노의 실제 원본1강은 랜덤 피해65 유지/독10→11이다. 과거 후보의 주석65→72는 기존 GameManager가 MULTI_HIT_RANDOM을 퍼센트 강화한다는 잘못된 가정이어서 정정했다. 새 후보는 매 히트+1이라는 명시 강화를 사용하고 독을 두 배로 만들지 않는다.

압박 검사에서 클레오파트라1강 vs 그리스 사티로스의 후보 승리가 패배로 바뀌어 원본 패배와 일치했다. 원본 전투 궤적의 조정 전후 변화는0/240이므로 다른 기준 조건으로 비교한 결과가 아니다. 일반 전투에는 새 패배가 없었다. 압박 조건의 제한/미완료는 양쪽0/240, 고유 쌍 궤적240개다. 일반 조건 고유 쌍 궤적663개이며 반복57개를 독립 표본으로 취급하지 않는다.

일반 잔여HP 평균 절대 차이는0.05694→0.04028이다. 작은 차이의 평균만으로 전체 균형이 완성됐다고 판단하지 않는다. v2 압박에서도 이순신의 한 사례에 원본 대비 잔여HP−16.7 등 차이가 남아 있고, 칭기즈칸 구간의 원본 패배/후보 승리도1쌍 남는다. 미지원 시그니처105종·정예/보스·다중 적/팀 조합·보상 경제는 미검증이다. 이번 조정은 **3개 카드의 반올림 편향을 줄인1차 튜닝**이다.

## 재현과 검증

```sh
bash tools/run_small_number_simulation.sh
bash tools/run_small_number_simulation.sh --pressure=hard --seeds=101
```

- 기본 플레이는 여전히 원본 수치다. 후보 v2 식별자/클론을 평가기에만 연결했다. 기존 후보 v1 자료는 보존했다.
- 전용 규칙 검사 `tests/run_small_number_tuning.gd`:70통과/실패0. 드로우0~10·0/1강의 실제/설명/미리보기/예약 피해와 취약을 검사한다.
- 전체 회귀4056통과/실패0. 실행별 RNG 조건에 따라 검사 수가 달라질 수 있다. 최종 실행 로그의 엔진 오류/경고0. import 때 기존 중첩 아트 프로젝트 경고는 별도다.
- 일반/즉시 결과: `log/small-number-simulation/run-CKVXc9/{battles,instant}.json`.
- 압박 v1 동결 결과: `log/small-number-simulation/run-N5QPaa/before-frozen.json`.
- 압박 v2 동결 결과: `log/small-number-simulation/run-buggMf/after-frozen.json`.
- 각 JSON의 소스 해시·dirty 상태·시드·압박 배율을 함께 읽는다. 초기4×/2×압박 결과와 개발 중 결과는 최종8×/4×동결 비교에 합치지 않았다.

다음 조정은 원본을 무조건 따라가는 것이 아니라 남은 실패/큰HP 차이의 원인을 카드·몬스터의 최소1 힘/독·방어 반올림으로 분리하는 것이다. 실제 기본 게임 적용은 전체 데이터/세이브 단위 전환 후 별도다.
