# 희생 잔다르크 보상 상향 — 2026-10-17

사용자가 희생 덱의 보상 상향을 승인했다. [방어 수명 대조](block_balance_evaluation.md)의 잔다르크 순교 최대HP손실102는 좁은 starter+reward2 표본이며 덱 전체 붕괴의 증명이 아니다. 이번에는 방어 수명을 되돌리거나 HP 비용을 없애지 않고 보상4장을 상향한다. 다른 영웅·적·회복 카드·시작 덱 정의는 변경하지 않는다.

| 카드 | 기존 → 변경 (강화) | 유지하는 대가 |
|---|---|---|
| 순교의 발걸음 | 희생 누적5 전부 소비 시 총 드로우2→3 (3→4) | 비용1, 누적 최대5 소비·부족 시 드로우1 |
| 최후의 방패 | 이전량에 더하는 기본 방어0→5 (0→7) | 비용1·HP5, 본인 방어 최대10/14 이전 |
| 성흔의 결실 | 기본 광역 피해7→10 (10→13) | 비용2, 희생 누적 최대15 소비해 피해에 가산 |
| 순교자의 빛 | 기본 전체 방어6→8 (9→11) | 비용2·소멸, 희생 누적 최대15 소비해 방어에 가산 |

추가 드로우는 희생 누적을 피해/팀 방어로 정산할 기회를 포기하는 대가다. 방패는 기존 방어가 없어도 사용할 이유를 제공하고, 자기 지정 시 이전 없이 기본 방어만 제공한다. 실제 자해 사망이면 후속 방어는 발동하지 않는다. 기존 동적 효과 설명을 사용하므로 숫자 하드코딩/새 전용 자원/퍼센트/소수는 추가하지 않는다.

## 사전 검증 계약

후속 사용자 요청으로 아래 원래128쌍 계획은 실행 전에 [전18개 덱 실험](archetype_deck_balance_evaluation.md)으로 대체했다. 이 문서의 네 카드 상향/규칙 검사 계약은 유지하며, 전투 결과는 새로운 덱 계약을 기준으로 기록한다.

- 실제 BattleManager의0/1강×기존/작은정수, 희생 누적0/부분/상한, 방패0보유/자기·다른아군/자해사망, 피해예측과 동적 설명·강화·저장 복원을 검사한다.
- 두 쪽 모두 **새 방어 수명 + 작은 정수**다. 이전 버프 전 후보는 테스트 평가기에서 네 카드의 명시된 기존 수치만 복구하고, 다른 게임 로직은 공유한다. 게임에 이전 모드를 추가하지 않는다.
- 4구성(시작10+발걸음/방패2, 시작10+결실/빛2, 시작10+희생 관련7장, 시작10+회복2장 대조군) × 기존 저작4전투 ×HP100/50% ×0/1강 ×시드101/202 =128쌍/256전투. 세 영웅은 Joan/Nap/Yi로 고정한다. 완성17장 덱은 순교의의지/힘/발걸음/방패/결실/빛/성녀의화염을 보상으로 사용하며 시작 덱에 제단의불꽃이 있다.
- 정책은 기존 손패순/첫 생존 적/최저HP 아군(이전은 자기 제외), 치명타끔·유물없음·입력120회 제한이다. 전투별 이전→후 승리/제한/전멸과 공통승리의 잔여팀HP/입력 수 분포·개별 카드 실제사용 수를 보고한다. 초기 상태 일치·미완료0을 요구한다. 대조군은 궤적까지 같아야 한다.
- 합격 후보: 새 패배/제한이 없고, 희생 카드의 보상이 적어도 일부 동일 구성에서 생존 또는 속도를 개선한다. 기존 덱보다 추가 드로우 때문에 나빠진 구성도 숨기지 않는다. 모든 표본 전승이 재미/최종균형/캠페인 합격을 뜻하지 않는다.
- 소스 지문·commit+dirty·시드·개별 paired 궤적/초기 상태 해시를 JSON에 기록하고 중복을 구분한다. 테스트는 무음/Dummy·격리 user://, 실제 저장/볼륨 설정과 원격 Git을 변경하지 않는다.
