# 클레오파트라 카드 기획 v2

> 작성일: 2026-04-20 | 기준: HP 1000 스케일 | 총 40장 (v1 15장 승계 + v2 25장 추가)

---

## 1. 영웅 정체성 + 아키타입 상세

### 클레오파트라 — 이집트의 여왕, 독과 매혹의 지배자

> "싸우지 않고 이긴다. 독으로 녹이고, 유혹으로 무너뜨리고, 저주로 봉인한다."

클레오파트라는 **직접 피해 대신 상태 이상 누적**으로 승리하는 지원형 딜러다.
한 턴에 폭발적인 피해를 내기보다 독 스택을 쌓고, 적의 행동을 비틀고, 디버프를 중첩해 팀 전체의 피해를 증폭한다.
롱게임에 강하며, 적이 많을수록, 라운드가 길수록 가치가 올라간다.

---

### 아키타입 1: 독살 (Poison)

**플레이 패턴**

독 스택을 최대한 빠르게 누적 → POISON_BURST로 한 번에 폭발.
아스프의 독니, 사막의 독무, 나일의 안개 등으로 단일/전체 스택을 쌓고,
나일의 분노, 독사의 마수로 폭발 타이밍에 터뜨린다.

v2에서는 **독 조건부 효과 카드** 비중을 높여 "스택이 몇 이상이면 보너스" 방식의
조건부 딜러 루트가 추가된다. 독 확산(인접 전염), 독 지속 연장 카드도 신설.

**승리 조건**

3~4라운드 이내에 독 15~20 스택 달성 → POISON_BURST 1~2회로 마무리.
나폴레옹·이순신 크로스 시너지로 독 조건부 피해 증폭 가능.

**핵심 효과**

`POISON`, `POISON_BURST`, `CONDITIONAL_DMG` (독 스택 조건), `APPLY_STATUS(poison)`

---

### 아키타입 2: 조종 (Charm)

**플레이 패턴**

CHARM을 2 이상 쌓아 적이 서로를 공격하도록 유도.
유혹·클레오파트라의 입맞춤으로 매혹을 살포하고,
COST_NEXT 카드로 2코 이상 매혹 카드를 저렴하게 연속 사용.
파라오의 명으로 드로우를 보충하며 매혹 루프를 유지.

v2에서는 **매혹 활용 카드** — 매혹된 적에게 추가 효과, 매혹 상태 확인 후 DRAW/ENERGY 회복 — 를 추가해
순수 매혹 살포 루트 외에 "매혹 이후 챙기는" 반응형 조종 루트를 신설.

**승리 조건**

적 2~3기가 매혹 2 이상인 상태 유지 → 적들이 서로를 지속 공격 → 팀 피해 없이 적 자멸.
이순신 COUNTER_BLOCK과 연계하면 반격 루프 추가.

**핵심 효과**

`CHARM`, `COST_NEXT`, `DRAW`, `ENERGY`, `BLOCK`

---

### 아키타입 3: 저주 (Curse)

**플레이 패턴**

WEAK + VULNERABLE을 중첩해 팀 전체 피해를 배수로 증폭.
저주의 시선, 파라오의 독으로 다중 디버프를 쌓고,
나폴레옹의 포격·이순신의 학익진이 증폭 피해를 입힌다.

v2에서는 **디버프 개수 기반 조건부 카드** — 적의 디버프 총 스택이 n 이상이면 추가 피해 — 와
**독+저주 복합 카드** (POISON과 WEAK/VULNERABLE을 동시 부여)를 추가해
독살 아키타입과 자연스럽게 교차하는 혼합 루트를 신설.

**승리 조건**

WEAK 3 + VULNERABLE 3 유지 → 팀 딜러(나폴레옹)가 배수 피해. 적 HP 30% 구간에서 클레오파트라 자체 저주 카드로 마무리.

**핵심 효과**

`APPLY_STATUS(weak)`, `APPLY_STATUS(vulnerable)`, `CONDITIONAL_DMG` (디버프 조건), `DAMAGE`

## 4. 신(Divine) 등급 카드 2장 상세

---

### 4-1. 클레오파트라의 입맞춤 (v1 승계) — 맥락 전환형

| 강화 | 수치 효과 | 유니크 보조효과 | 의도 |
|---|---|---|---|
| 0강 | CHARM 2 ALL, POISON 3 ALL | 전체 매혹 + 독 살포. 조종과 독살의 브릿지 기동. | 조종 아키타입의 대량 매혹 개막. 독살과 상호 연계 씨앗. |
| 1강 | CHARM 3 ALL, POISON 4 ALL | 추가로 WEAK 1 ALL 부여. 저주 레이어 추가로 세 아키타입 연결. | CHARM·독·약화 3종 동시. 나폴레옹 포격 피해 증폭 기반 완성. |
| 2강 | CHARM 3 ALL, POISON 5 ALL, WEAK 2 ALL | 이 턴 종료 시 모든 독 틱 1회 즉시 추가 발동 (정규 틱 별도). | 나일의 분노 직전 이 카드 사용 → 독 틱 2회 소진 후 POISON_BURST. 최대 효율은 독살 빌드 완성 후 가능. |

**수치 계산** (DIVINE, rate 16%): 수치 효과 없음. 유니크 효과로만 차별화.
**운용 팁**: 0강에서도 2코 2에너지로 전장 전체를 뒤흔드는 카드. 2강 독 즉발은 독살 빌드 완성 기준 폭발 배수를 사실상 1.5배로 늘린다.

### 4-2. 세케메트의 저주 (v2 신규) — 누적 강화형 + 조건 해금형

> 세케메트: 이집트 전쟁·역병의 여신. 사자 머리의 파괴자.

| 강화 | 수치 효과 | 유니크 보조효과 | 의도 |
|---|---|---|---|
| 0강 | WEAK 3 ALL, VULNERABLE 3 ALL, POISON 4 ALL | 3코 1장으로 전장 전체에 삼중 디버프 완성. 조종 없이 순수 저주 완전체. | 저주 아키타입의 진정한 마무리 선언. 나폴레옹 전체 공격이 이 턴 즉시 2배 이상. |
| 1강 | WEAK 4 ALL, VULNERABLE 4 ALL, POISON 5 ALL | 추가로 CHARM 2 ALL 부여. 저주 위에 조종을 얹어 적 자멸 루트 병행. | 저주+조종 완전 융합. 디버프 극대화 상태에서 적들이 서로 공격 → 3배 증폭 피해. |
| 2강 | WEAK 4 ALL, VULNERABLE 4 ALL, POISON 6 ALL, CHARM 3 ALL | 이 턴 종료 시 전 적에게 POISON_BURST (독 스택 × 1) 자동 발동. | 독 틱 한 번 + 독 폭발 한 번 + 매혹 자멸의 3중 연타. 게임 마무리 전용 카드. |

**수치 계산** (DIVINE, rate 16%): 수치 효과 POISON은 정수(강화당 +1), WEAK/VULNERABLE도 정수(강화당 +1). CHARM도 정수(강화당 +1).
**운용 팁**: 3코로 코스트가 높다. 나일의 흐름(ENERGY+1)이나 밀납의 덫(COST_NEXT -1) 2장으로 2코로 낮춘 뒤 사용 권장.
0강도 저주 아키타입 완성 선언 카드다. 2강은 클레오파트라 덱이 완전히 갖춰진 후 게임 종료 버튼.

## 7. 크로스 시너지 연동

### 기존 크로스 시너지 (battle_manager.gd 구현 완료)

| 시너지 이름 | 조합 | 발동 조건 | 효과 |
|---|---|---|---|
| 독침 반격 | 이순신 × 클레오파트라 | 이순신 DAMAGE 카드 사용 + 대상에 독 있음 | 대상에 추가 피해 +4 |
| 혼란의 돌격 | 나폴레옹 × 클레오파트라 | 나폴레옹 CONSUME_MORALE 성공 | 대상에 CHARM +1 |
| 철벽 진군 | 나폴레옹 × 이순신 | 나폴레옹 GAIN_MORALE 사용 | 이순신 BLOCK +3 |

### v2 카드와 크로스 시너지 연계 포인트

**독침 반격 (이순신 × 클레오파트라)**

- 파라오의 저주(24), 저주의 낙인(33), 독살의 의식(31)으로 독 스택을 높게 유지
- 이순신이 DAMAGE 카드 사용 시 독 상태 적에게 +4 추가 피해 자동 발동
- 독의 왕좌(38) POWER 발동 후 → 이순신 카드마다 독침 반격 폭발량 증가
- **추천 조합**: 독의 왕좌 → 뱀의 독무 → 이순신 거북선 일격 (독침 반격 × 3회)

**혼란의 돌격 (나폴레옹 × 클레오파트라)**

- 여왕의 포옹(32), 클레오파트라의 입맞춤(15)으로 전체 CHARM 살포 후
- 나폴레옹 CONSUME_MORALE 카드 사용 → 매혹 +1 추가로 발동 임계값(2) 초과 가속
- 세케메트의 저주(40) 1강 이상 — CHARM 2 ALL로 혼란의 돌격과 즉시 연계
- **추천 조합**: 세케메트의 저주(1강) → 나폴레옹 총공세 명령 → 혼란의 돌격 × 전체 적 자멸

**이순신 COUNTER_BLOCK + 독 연계 (기획 방향)**

- 이순신의 COUNTER_BLOCK 피해는 독 있는 적에게 독침 반격 추가 피해 +4를 받음
- v2 저주의 교차로(37)로 전체 독+저주를 깔고 → 이순신 COUNTER_BLOCK → 독침 반격 전체 발동
- 이는 현재 battle_manager.gd의 DAMAGE 타입 체크로 자동 처리됨 (COUNTER_BLOCK이 DAMAGE로 처리되는 경우 확인 필요)

### v2 추가 카드별 시너지 메모

| 카드 | 크로스 시너지 연관 |
|---|---|
| 파라오의 저주(24) | POISON 부여 → 독침 반격 트리거 조건 세팅 |
| 독살의 의식(31) | POISON_BURST 계수 상승 → 나일의 분노 위력 증대, 세케메트의 저주 2강 POISON_BURST 증폭 |
| 여왕의 포옹(32) | CHARM ALL → 혼란의 돌격 조건 선제 충족 |
| 독의 왕좌(38) | 매 턴 독 +1~3 → 이순신 독침 반격 자동 발동 조건 무한 유지 |
