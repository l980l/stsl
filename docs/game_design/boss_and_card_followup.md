# 작은 정수 후속: 보스 패배 원인과 무사시 카드 역할

2026-10-15. 사용자 승인에 따라 ① 봇 판단/누적 소모/보스 난도를 분리하고 ② 회오리 베기·비연의 정수화 차이를 동급 카드와 비교했다. 게임 수치 변경이나 보스 하향은 하지 않았다.

## 평가 계약

- 단위: 실제 씬 캠페인 한 런, 또는 전투 전 체크포인트 한 상태에서 정책별 한 실행. 사람 승률·최적 전략·재미 평가가 아니다.
- 보스 가설: 전투 전 HP/덱/유물, 실제 피해 종류와 카드 선택을 확인한다. 같은 진입 상태에서 다른 정책으로 이길 수 있다면 해당 상태의 클리어 가능성은 관측되지만 적정 난도가 증명되는 것은 아니다.
- 카드 가설: 같은 비용에서 공격/방어/조건부 환급의 역할과 강화 가치가 구분되는지 확인한다. 과거 환산 피해와 정확히 일치시키려고 특정 상태 전용 예외를 추가하지 않는다.
- 모든 실행은 Dummy 오디오, Master 무음, 별도 user://, headless·8배속이다. 성능 프로파일링은 비활성이다.
- 전투 진입 직전에 별도 시드를 설정하는 새 진단 모드는 기존 캠페인 궤적을 바꾼다. 과거 `1PSP8Y`의 정확한 패배 재현이라고 부르지 않는다. 연출도 전역 RNG를 쓰므로 체크포인트/시드가 같아도 이후 치명타·대상·셔플 궤적까지 완전 동일하다고 주장하지 않는다.

## 확인한 봇 오류와 정책 구분

정화 평가는 실제 `poison_dmg`/`poison_dur` 대신 존재하지 않는 `poison` 키를 읽었다. 독은 방어를 우회하는데도 남은 독 피해가 정화 선택 점수에 반영되지 않았다.

- 기본 `corrected`: 독의 남은 피해량과 정화 범위를 평가하고, 사망한 소유자의 보상 카드를 추가하지 않는다. 게임의 피해/HP/보상 후보/승리 조건은 변경하지 않는다.
- `baseline`: 비교용 과거 판단을 보존한다.
- `status-aware`: 정화 수정 외에 적 실제 공격 표시량과 최대 HP 10%의 지속 방어 여유를 고려하는 **실험 정책**이다. 독을 방어로 막을 수 있다고 계산하지 않는다. 일부 전투 개선과 캠페인 패배가 함께 있으므로 기본 전략으로 승격하지 않았다.

정화 배점의 가중치는 최적 해가 아닌 봇 휴리스틱이다. 독 4×잔여3회는 새 단위/옛 단위에서 같은 점수를 얻고, 만료된 독은 0점인 회귀 검사를 추가했다.

## 보스/누적 소모 결과

### 새 캠페인 진단

- `56am0U` / baseline / 시드42: 1막14층 세크메트 패배. 클레오파트라는 이미 12층에서 사망했고 보스 진입 시 나폴레옹만 HP65였다. 클레오파트라 독 피해 이벤트 합계52를 관측했다. 이 실행으로 최종 보스 난도를 판단하지 않는다.
- `4dsUOU` / status-aware / 시드42: 3막14층 요르문간드 패배, 적 HP39. 보스 진입은 세 명 모두 HP100·방어1. 보스전 독 피해 이벤트 합계238, 직접 공격53. 자기 희생 등은 이 합계와 별도이며 과잉 피해를 포함할 수 있어 이를 정확한 순 HP 손실로 표현하지 않는다.
- `J8cVjZ` / baseline / 시드101: 3막14층 패배, 적 HP50. `UP26MD` / status-aware / 같은 시드: 1막14층 패배, 보스 진입 전에 클레오파트라 사망. 같은 시드라도 정책/보상/전역 RNG가 달라 통제된 전후 비교가 아니다. 실험 전략이 언제나 낫다는 주장은 하지 않는다.
- 최종 기본 정책 `ToNECQ` / corrected / 시드42도 1막14층 패배(적 HP243)였다. 정화 키 오류 수정이 안정적 캠페인 완주까지 해결했다는 주장은 하지 않는다. 현재 봇의 경로/성장/생존 판단은 여전히 불완전하다.

## 카드 판단: 둘 다 현 수치 유지

실제 최종 생성 카드 7종×0/1강×힘0/1/3×약화/취약4조합×단독/3인팀 = **336개 고정 상태**, 치명타/권능/적 방어 없음. 미리보기와 실제 피해 일치 및 정수 결과를 검사했다. 별도로 빈 손 환급이 한 차례 한 번인지 검사했다. 771검사·실패0. 같은 상태의 역할 비교이지 특정 공방 합산 점수로 강약을 확정한 것이 아니다.

단독·힘0·상태이상 없음의 실제 수치:

| 카드(모두 비용1) | 기본 | 1강 | 구별되는 역할 |
|---|---|---|---|
| 기본 공격 / 시작 이도 베기 | 피해10 | 12 | 단순 공격 / 다단 |
| 이도 베기(보상) | 피해12 | 14 | 순수 다단 공격 |
| 회오리 베기 | 피해8·방어4 | 피해8·방어5 | 방어형 다단, 강화는 방어+1 |
| 비연 | 피해8 | 피해10 | 마지막 손패일 때 에너지1, 본인 차례당 한 번 |
| 쌍도 기초 | 피해10·취약1 | 피해12·취약1 | 다음 공격 지원(현재 공격 이후 취약 적용) |
| 혈로 | 피해10·생존 적이면 방어3 | 피해13·방어3 | 조건부 공방, 단타 |

회오리 베기는 피해 강화가 없지만 방어 강화가 실제 적용된다. 비연은 매번 무조건 공짜가 아니며 손패·차례 조건이 있다. 현재 비교로 어느 쪽도 모든 역할에서 동급 카드를 지배한다고 결론낼 수 없다. 과거 스트레스의 두 진단 차이(회오리1강 8 대9.6, 비연0강 12 대10.4)는 그대로 남긴다. 힘의 다단 효율과 에코/추가 타격 권능의 장기 조합은 이 즉시 검사 밖이다.

## 재현과 제외 기록

```sh
bash tools/run_live_balance_checks.sh test_campaign_policy run_musashi_role_checks run_small_number_live test_tutorial_integration
STSL_LEGACY_COMBAT=1 bash tools/run_live_balance_checks.sh test_runner
bash tools/run_campaign_bot.sh --headless --chapter=1 --seed=42 --speed=8 --diagnose-battles
bash tools/run_campaign_bot.sh --headless --speed=8 --policy=status-aware --replay-encounter=/absolute/path/to/encounter-c1-a3-n52.json
```

`--replay-encounter`의 clear는 **그 전투 승리**일 뿐 챕터 클리어가 아니다. 새 체크포인트는 신화 순서와 별도 gameplay_hash를 포함하고 규칙 지문이 다르면 거부한다. 초기 체크포인트의 누락된 신화는 같은 폴더의 원래 보고서에서 해당 전투를 확인한 경우에만 복원한다. JSON 숫자 ID를 정수로 복원해 노드 입장 가드를 통과한다.

초기 재생은 노드 ID 타입 또는 신화 복원 누락으로 실패하거나 다른 적과 싸웠다. 해당 중간 기록은 보존하되 위 비교에서 제외했다. 수정 후 8실행의 초기 상태 일치를 확인했다. 새 캠페인에는 기존 누락 BGM 경고가 있으며, 유효 비교 로그에는 스크립트/엔진 오류가 없다.

통합 검사 `log/live-balance/STSL-tutorial-validation-live-kVtV9c/`: 카드771·live1672·튜토리얼321 통과. 과거 단위 전체 회귀 `STSL-tutorial-validation-live-1jmmd4/`: 4052통과·실패0(RNG로 검사 수는 변동). 원시 캠페인 기록은 `log/campaign-bot/STSL-campaign-bot-<이름>/`에 있으며 소스 지문·dirty 상태를 함께 읽는다. 커밋/푸시는 하지 않았다.

최종 정책/카드 재검사는 `STSL-tutorial-validation-live-Qn3S83`에서 통과했다. 새 형식(신화 순서·gameplay_hash 포함) 체크포인트의 재생 `p6Kqsg`는 실제 전투 승리·Master무음·프레임 측정 비활성·스크립트/엔진 오류0이었다. 규칙 지문은 `52e887ff4da8d3e70bf98f8b36fe706fb00ead82b8559eba9cb6339d09ce9232`다.
