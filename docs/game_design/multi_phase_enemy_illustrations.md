# 다중 페이즈 몬스터 일러스트 가이드

> **작성일:** 2026-05-24
> **목적:** `phase_thresholds` 가 정의된 보스·엘리트가 페이즈 전환 시 시각적으로도 변화하도록, 각 페이즈별 일러스트의 차이를 가이드한다. 일러스트 작가·AI 생성 프롬프트 작성용 레퍼런스.
> **범위:** BOSS 18종 (3페이즈 또는 2페이즈) + ELITE 10종 (2페이즈) — 총 28종.
> 일반(NORMAL) 등급도 일부 `phase_thresholds` 가 있으나, 메커니즘이 단순 강화·광폭화에 그치고 작업 규모가 크므로 (~30종) **modulate 색조 시프트만으로 충분**. 별도 일러스트 미작성.

---

## 1. 페이즈 전환의 의미

페이즈는 보스/엘리트의 HP 가 임계치(`phase_thresholds`) 아래로 내려갈 때 발동하는 **두 번째 페이지의 시작**이다. 메커니즘으로는:
- 인텐트 패턴 교체 (`phase_patterns[i]`)
- HP 일정 비율 회복 (`phase_heal_ratios[i]`)
- 자동 상태 부여 (`phase_buffs[i]`)
- `CHARGE_UP` / `DISPEL` / `CHANGE_AFFINITY` / `FORM_SWITCH` / `SUMMON` / `INFLICT_WEAKNESS` 등 신규 액션 등장

시각적으로는 **"적이 진정한 모습을 드러낸다"** 는 서사적 모멘트. 일러스트 변화로 플레이어에게 즉각 위협 상승을 알린다.

---

## 2. 5요소 일러스트 가이드 원칙

각 페이즈 일러스트는 아래 5요소를 차이로 표현한다:

| 요소 | 의미 | 예시 |
|---|---|---|
| **실루엣** | 외형 윤곽 | 머리 수 증가 / 자세 변화 / 무기 변형 / 새 부속 (날개·뿔) |
| **자세** | 동작·포즈 | 정좌→포효 / 방어→공격 / 인간형→짐승형 |
| **표정** | 얼굴·눈 | 평온→분노 / 눈 빛 강도 / 입 벌림 / 핏줄 |
| **색조** | 팔레트 | 채도 상승 / 황금→피색 / 차가운→뜨거운 / 흑백 추가 |
| **이펙트** | 주변 효과 | 후광 / 균열 / 불꽃 / 그림자 길이 / 떠 있는 룬 |

**일관성:** 페이즈 변경 시 캐릭터의 정체성은 유지 (같은 사람·짐승). 위 5요소 중 **2~3개만 강화**해서 "같은 적의 다음 모습" 으로 인식되게.

## 3. 시각 변경 유형 5종 (메커니즘 매핑)

| 유형 | 메커니즘 신호 | 시각 변화 방향 |
|---|---|---|
| **A. 광폭화** | BUFF strength, CHARGE_UP, double_action, 페이즈 2 진입 | 자세 폭주·핏줄·발광 / 갑옷 깨짐 / 표정 분노 |
| **B. 형태 변신** | FORM_SWITCH, turn_modes, dynamic_affinity_pool, 페이즈 1 진입 | 실루엣 재구성 (다리 분리·머리 수↑) / 무기·옷 교체 / 후광 색 변경 |
| **C. 모드 토글** | turn_modes ["A","B"] FORM_SWITCH 매 턴 | 같은 페이즈 내 2가지 자세 ↔ 토글 (셸/공격, 충전/방전) |
| **D. 저주·각성** | INFLICT_WEAKNESS, DISPEL, CHANGE_AFFINITY | 머리 위·발 아래 룬·인장 추가 / 눈 색 변경 / 새 손짓 |
| **E. 소환·분신** | SUMMON, MIMIC | 등 뒤 분신 등장 / 깃발 / 떠 있는 화신 |

## 6. 일반 적 (NORMAL) — modulate 톤만 권장

일반 등급 중 `phase_thresholds` 가 있는 적들 (~30종) 은 메커니즘이 단순 강화 (BUFF strength·강공격 패턴 교체) 라 시각 변화가 작음. **일러스트 추가 작업 불필요**, `modulate` 색조 시프트로 충분:

- HP 50% 이하: `modulate = Color(1.0, 0.85, 0.85)` (살짝 핏빛)
- HP 30% 이하: `modulate = Color(1.0, 0.7, 0.7)` (분노 핏빛)

스크립트는 기존 `phase_buffs` 적용 hook 에 `modulate` 보간 추가하면 됨. 후속 PR 검토.

## 7. 작업 우선순위 + 일러스트 생성 워크플로우

### 우선순위

| 순위 | 대상 | 이유 |
|---|---|---|
| 1 | BOSS 18 × 3페이즈 = 54 일러스트 (오시리스만 2페이즈 → 53) | 보스전 임팩트 최대, 플레이어 노출 빈도 ↑ |
| 2 | ELITE 10 × 2페이즈 = 20 일러스트 | 페이즈 변경의 학습 곡선, 보스 전 워밍업 |
| 3 | NORMAL phased ~30 | modulate 만, 일러스트 미작성 |

### 생성 워크플로우 (AI 또는 작가)

1. **기본 일러스트** (P0) 먼저 확정 — 캐릭터 정체성·색조·자세의 기준선
2. **P1 변형** — P0 를 참조로 5요소 중 2~3개만 변화 (자세 / 표정 / 이펙트 위주)
3. **P2 변형** — P1 위에 추가 광폭화 (실루엣 / 색조 강화)
4. **모드 토글 (FORM_SWITCH)** — 같은 페이즈 내 2가지 자세 모두 필요 (요르문간드르, 진무대제, 라이덴)

### 프롬프트 템플릿 (AI 이미지 생성용)

```
[캐릭터 정체성] in [페이즈별 자세], [핵심 5요소 변화], 
[배경 환경], [색조 팔레트], [후광/이펙트], 
mythology theme [신화], anime/painterly style, full body
```

### 일관성 체크리스트

각 페이즈 일러스트 완성 시:
- [ ] 정체성 인식 (같은 캐릭터인가?)
- [ ] 위협 상승 (P1 > P0, P2 > P1)
- [ ] 5요소 변화 2~3개
- [ ] 신화별 톤 (그리스 = 황금/대리석, 북유럽 = 회색/얼음, 이집트 = 황금/모래, 불교 = 황금/연꽃, 도교 = 오행/구름, 일본 = 흑적/벚꽃)
- [ ] sprite 영역 (80×80 cover 모드) 에서 얼굴이 잘 안 짤리는지
