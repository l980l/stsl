## 지표와 판단

덱별·HP별·강화별·전투별 승리/실제패배/제한 개수를 해당 고정 표본 수와 함께 기록한다. 시간은 벽시계/FPS가 아니라 영웅 입력 수다. 실패를 일찍 끝난 빠른 전투로 취급하지 않고 공통승리에서만 속도를 비교한다. 개별 보상 카드 실제사용 횟수를 수집하며 효과 발동의 유효성/재미로 확대하지 않는다. 최종 HP는 팀합계 최대300, 회복에 따른 초기HP 초과가 가능하다.

덱 크기/희귀도 예산은 맞추되 실전 획득 확률/상점 비용/정책 숙련도는 맞추지 못했다. 전승은 쉬운 표본/충분한 팀 시너지 가능성도 있으므로 균형의 증명이 아니다. 새 패배가 반복되거나 입력 수/HP가 특정 덱에 집중되면 별도 후속 대상으로 남기고 다른 직업 수치는 자동 조정하지 않는다. 사람 플레이·재미·전체 캠페인/전 신화는 미측정이다.

소스 hash·commit+dirty, 고정 입력, 개별 결과/초기/궤적 해시와 중복 수를 `user://archetype_deck_balance.json`에 남긴다. Master무음/Dummy/격리 user://·실제 저장 보존·프로파일링 없음.

```sh
bash tools/run_live_balance_checks.sh run_archetype_deck_balance
```

### 결론과 후속 우선순위

1. **희생 보상4장 상향 유지**: 비용/소비 구조를 유지하면서 기본 표본의 속도/평균HP를 개선하고 새 패배가 없었다. 그러나 극저체력의 생존은 개선되지 않았으며 완성된 최종균형은 아니다.
2. **칭기즈칸 기병 우선 진단**: HP25% 0/4는 동일 영웅의 기동/약탈2/4보다 낮다. 병사 소비→팀 방어/광역 공격과 자동 공격 보존을 구분하는 정책에서 재검증할 대상으로 남긴다. 다른 직업과 파트너가 다른 점도 유지한다. 이번 요청으로 해당 카드/적을 추가 변경하지 않았다.
3. **잔다르크 신성/희생의 저HP·보호 이전 판단**, 이어서 학익진의 보호 대상·무심의 빈손 순서가 후속이다. 다소 느린 회복 덱의 높은 생존을 바로 과도한 강함으로 보거나 느린 무심을 바로 약함으로 판정하지 않는다. 같은 체크포인트에서 선택을 달리하는 대조가 필요하다.
4. **캠페인/전 신화/전문 조작 후속**: 현재4전투·2시드·유물없음이므로 최종보스/모든 몬스터·실전 획득 과정까지 확인한 것은 아니다. 실제 플레이의 재미/선택 만족도는 미측정이다.
