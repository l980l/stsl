# 아키타입 밸런스 덱 고정표

`tests/archetype_balance_decks.gd`는 여섯 영웅의 세 아키타입을 각각 대표하는 18개 고정 덱을 정의한다. 각 덱은 실제 해당 영웅의 시작 덱 10장에, 서로 다른 보상 카드 여섯 장을 더한 16장이다. 이는 추천 빌드나 일반 플레이어의 드래프트 결과가 아니라, 같은 조건에서 역할별 전투 성능을 비교하기 위한 재현 가능한 평가 입력이다.

## 제약과 검증

- 보상 여섯 장은 실제 생산 카탈로그의 해당 영웅 카드이며, 실제 시작 덱 카드와 중복되지 않는다.
- 보상 카드끼리 중복되지 않고, 신성(DIVINE)은 배제한다.
- 덱당 희귀(RARE)는 최대 두 장, 전설(LEGENDARY)은 최대 한 장이다.
- 각 아키타입에는 `archetype_synergy_revision.gd`에서 개편한 두 카드가 모두 포함된다.
- 스크립트는 카드 키, 소유자, 실제 시작 덱 제외, 희귀도 제한, 영웅당 세 덱을 실행 시 카탈로그로 확인한다.

전투 평가에서는 소유 영웅에게만 이 16장을 주고, 파트너 두 명은 각자의 10장 시작 덱을 사용한다. 기본/강화와 체력 100%/50%, 고정 시드 101·202, 동일한 네 전투를 함께 기록한다. 따라서 승률·남은 체력·입력 턴·미완료 여부는 덱 구성 간의 비교 자료이며 플레이 재미나 최적 전략의 증명은 아니다.

## 교차 요소의 취급

시작 덱은 보편 카드와 영웅별 기초 카드를 이미 포함하므로 보상 여섯 장에는 넣지 않았다. 희귀도 제한을 지키면서도 각 아키타입의 생성기·증폭기·정산기를 함께 넣었다. 팀을 대상으로 하는 방어·회복·사기·표식 효과는 실제 3인 전투에서 파트너와 상호작용하지만, 다른 영웅의 보상 카드를 빌려 넣지 않는다. 이로써 아키타입 자체와 팀 규칙의 영향을 분리해 기록할 수 있다.

초기 초안에서 실제 카드 키와 팩토리 함수명의 차이, 희귀도 초과, 신성/시작 카드 혼입을 검증기로 찾아 위 구성으로 수정했다. 전투 실행 전 덱 검증547개가 통과했다. 희귀도는 같은 상한이지 같은 획득 비용의 보장은 아니다. 돌격의 전격 진군와 조종의 유혹의 정체는 예산 안에서 순서/속도를 보조하는 교차 지원 카드다. 미등록 북소리 같은 팩토리는 포함하지 않는다.
