# 방어 수명 밸런스 대조

> 이 문서는 희생 잔다르크 보상 상향 전 방어 규칙 대조 기록이다. 이후 승인된 [보상4장 상향](joan_martyr_reward_buff.md)과 [18개 아키타입 덱 비교](archetype_deck_balance_evaluation.md)는 별도 근거이며, 아래 소스 지문 검증은 이 실험 당시의 파일을 기준으로 한다.

2026-10-17. 가설: 새 소멸 규칙은 기존 방어 축적의 이득을 낮추지만 일부 방어/회복 조합만 과도하게 무력화하지 않아야 한다. 플레이 감각의 재미가 아니라 실제 ATB 생존·체력·행동 수를 측정한다.

## 사전 고정 계약

- 18개 개편 보상2장 패키지 × 저작4전투(이집트3마리, Sekhmet, Osiris, Surtr) × 초기HP100/50% × 시드101 × 기본강화 = 144쌍/288전투. 소유자 시작10+보상2, 나머지2명 시작10. 파트너는 기존 시너지 샘플의 Nap/Yi/Cleo 순으로 중복 없이 선택한다. 서로 다른 팀의 절대 승률을 영웅 간 공정한 랭킹으로 해석하지 않는다.
- 두 쪽 모두 작은 정수·동일 데이터·실제 ATB·치명타 끔·유물 없음·손패 첫 사용 가능 카드/첫 생존 적 정책. 아군은 최저HP, 방어 이전은 소유자 제외. 영웅 입력120회 제한; 제한 도달과 실제 패배를 구별한다. 완성된 아키타입 덱/캠페인 획득 비용 검사는 아니다.
- 전용 BattleManager subclass는 기존 `_execute_intent_effects`를 양쪽에서 그대로 호출하고, 이전 쪽에서만 공격 종료 잔여 방어 제거를 생략한다. 게임 코드에 이전 모드 옵션을 추가하지 않는다. 초기 상태 지문 일치와 미완료0을 무결성 조건으로 삼는다.
- 측정 단위는 고정 초기 구성의 paired 전투. 분자는 승리/패배/제한 개수, 분모는 해당HP/패키지/전투 표본 수다. 추가로 잔여 팀HP 차이·영웅 입력 수 차이·남은 영웅 수·공격 후 버려진 방어 합계를 원시 JSON에 남긴다. 동일 paired 궤적 해시를 중복 제거하여 보고한다.
- 판단: 이전 승리→새 패배/제한을 우선 원인 조사한다. 승리 유지여도 잔여HP 하락이 특정 조합/전투에 집중되면 후속 튜닝 후보로 기록한다. 기존 정책이 새 규칙을 이해하지 못하는 한계를 구별하고, 이번 요청은 점검이므로 게임 수치는 자동 조정하지 않는다. 자동 통과를 재미/전체균형 합격으로 쓰지 않는다.
- 소스 지문/commit+dirty·고정 시드·개별 결과·초기 동일성·궤적 해시를 `user://block_balance.json`에 보존한다. 무음/Dummy/격리 저장. 성능 프로파일링 없음.

```sh
bash tools/run_live_balance_checks.sh run_block_balance
```

### 판단과 다음 조정 후보

1. **규칙을 되돌리거나 모든 방어 카드를 일괄 상향할 근거는 부족하다.** 이순신 방어2패키지의 관측 승리는 유지되고 전투가 전반적으로 급격하게 길어지지는 않았다. 다만 실험 범위 밖 캠페인 안정성은 미확정이다.
2. **우선순위1은 저체력 칭기즈칸/Nap/Yi의 Surtr 후반 생존 경계다.** 방어 생성량만 늘리기 전에 동일 체크포인트에서 공격/자원 소비 순서·아군 보호 대상을 이해하는 정책으로 재검증한다. 현 봇은 손패순이며 새 규칙을 적극적으로 활용하지 못한다. 그 정책에서도 문제가 남으면 기병퇴각의 보호 효율 또는 Surtr 후반 공격 간격/피해를 별도 후보로 비교한다. 어느 쪽도 이번 요청에서 자동 변경하지 않았다.
3. **우선순위2는 잔다르크 회복/순교의 잔여HP 손실이다.** 보유 방어를 다음 차례에 이전/회복으로 쓰기 전에 공격으로 소멸하는 기회 감소를 사람이 이해하고 활용할 수 있는지 확인한다. 큰 HP 손실은 튜닝 신호이지 회복 아키타입 붕괴의 증명은 아니다.
